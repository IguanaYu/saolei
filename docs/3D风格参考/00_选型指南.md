# 3D 风格选型指南（跨项目通用）

> 用途：新项目做 3D 美术前，在这里完成"选风格"这一步。
> 参考图基底：同一座农场 + 同一个角色（老爷爷），12 种风格各 4 个机位——**变量只有风格**，可直接横向对比。
> 配套文档：《低模卡通3D风格子分类调研.md》（理论：六轴特征空间）。

## 使用流程

1. **先看 4 张总览图**（`总览_12风格×*.png`），扫一眼 12 格，圈出 2~3 个候选
2. **进候选风格的文件夹**看 4 张大图：全景（氛围/色板）、角色特写（脸部/描边/明暗）、建筑特写（硬表面）、作物特写（有机形/小物件）
3. **对照本指南的"选型表"**核对：适配的项目类型、实现成本、坑
4. **写六轴坐标再开工**（调研文档 §1 的方法论，防止风格漂移）：
   `A1几何 A2描边 A3光照 A4色彩 A5材质 A6展示` 各轴取值记进项目文档

## 选型表

| # | 风格 | 适合的项目 | 实现成本 | 坑 |
|---|---|---|---|---|
| ① | 软陶玩具棚拍 | 治愈系/模拟经营/儿童向/休闲手游 | **低**（倒角+柔光+粉彩，纯程序化） | 高光控制要留神，过曝就廉价 |
| ② | Synty平滑卡通 | **通用默认**：动作/冒险/RPG/策略，量产管线 | **低**（平滑+锐边+纪律色板） | 色板管理比建模重要，混包必花 |
| ③ | 折纸硬面描边 | 强符号感：卡牌/战棋/独立爆款/宣传海报 | **低-中**（flat直出+描边壳；游戏内用反转法线壳，不用Freestyle） | 描边线宽需按镜头距离分级；高饱和配不好会刺眼 |
| ④ | 赛璐璐三渲二 | 二次元向：JRPG/动作/视觉小说 | **高**（ramp贴图+SDF脸+彩色描边，自定义shader必选） | Blender的Toon节点已被删（5.2），需自建二分管线；AI生图管线多帧一致性差，冲突最大 |
| ⑤ | 手绘纹理 | 大作向：MMO/ARPG（WoW系） | **极高**（光影画进贴图，产能=手绘产能） | 程序化只能近似（噪声双色调）；真做要画师或稳定AI手绘管线 |
| ⑥ | 粘土定格 | 叙事/解谜/短片感项目 | 中（①基础上+凹凸材质） | 要"故意不完美"才成立，太干净就退化成① |
| ⑦ | 纸艺拼贴 | 童书/绘本/叙事解谜/轻恐怖 | 中（Solidify+正反双材质+折痕） | 直角折痕是灵魂，不能用倒角 |
| ⑧ | 体素低模仿 | 超休闲/hyper-casual/病毒传播向 | **低**（Remesh方块化，或MagicaVoxel建模） | 真体素vs低模仿体素要早决定（工具链不同） |
| ⑨ | 复古PSX | 恐怖/怀旧/实验独立游戏 | **低**（低分辨率渲染+限色+最近邻放大） | 恐怖向为主，可爱向需谨慎；顶点抖动要着色器 |
| ⑩ | 等距目录移轴 | **展示层**：不是造型风格，是摄影语言 | 低（长焦+DOF+圆角地台） | 叠加项——叠在①②③上都行，宣传图神器 |
| ⑪ | PBR玩具塑料 | 高管线项目：Supercell/Fortnite系 | **高**（完整PBR+较高建模量） | "伪低模"，面数其实不低；不适合快速原型 |
| ⑫ | 极简色块 | 概念游戏/UI级3D小物/原型期 | **最低**（两三色平涂） | 靠构图与剪影取胜，内容量大的游戏会单调 |

## 按需求快速索引

- **要量产一堆资产** → ②（首选）或 ①
- **要治愈/可爱** → ①⑥，宣传物料叠 ⑩
- **要海报级冲击力** → ③ 或 ⑫
- **要二次元** → ④（预算够再上）
- **要诡异/怀旧氛围** → ⑨ 或 ⑦
- **要超休闲爆款** → ⑧
- **原型期随便来一个** → ⑫ 或 Kenney 风（≈②极简端）
- **只做宣传图** → 任意造型 + ⑩ 展示语言

## 这些参考图怎么再生成

所有图来自 `blender/farm/build_style_matrix.py`（六轴参数矩阵）。给新项目做同风格测试时：

```bash
cd blender/farm
blender -b -P build_style_matrix.py -- <编号> [scene|char|house|crop]
```

`STYLES` 表里每个风格就是一组六轴取值（bevel/smooth/outline/sun/ambient/palette/remesh/toon/...），新项目改基底场景即可复用整套风格管线。
