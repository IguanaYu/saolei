# 扫雷挖矿 · 微信小游戏局外成长循环 · 对标调研

> **版本**：v1.0
> **最后更新**：2026-08-06
> **调研目标**：为扫雷挖矿找到"打不过 → 退出升级 → 回关碾压 → 再卡再升"那种微信小游戏体感的对标产品，提取可复用的模块化设计框架
> **关联文档**：[游戏设计文档.md](../../active/游戏设计文档.md)

---

## 1. 调研背景

### 1.1 玩家体感目标（用户原话）
> "玩一关，打不过但是感觉能过；退出来之后，就能升级；升级之后游戏里有很大的提升，然后很轻松过了；又碰到困难，玩两轮三轮，解锁系统，升级之后又轻松通过了。"

这是一种典型的小游戏式心流：**强烈的近失感 → 局外成长正反馈 → 碾压式回归 → 解锁新系统再卡关**。

### 1.2 当前项目状态
扫雷挖矿已实现 P1-P12，包括：
- ✓ 90 秒单局循环
- ✓ 局外矿石系统（积分 ÷ 10）
- ✓ 局外升级树（起始金币、命数、机器人速度、预开区域、初始机器人）
- ✓ 局外解锁（detector / miner / 充能塔 / 无人机）

**已经搭好了局外成长的骨架，但缺少"卡关-碾压"的体验容器**。本调研就是要把这个容器找出来。

## 2. 品类定位与术语

| 术语 | 含义 |
|---|---|
| **Meta Progression（局外成长）** | 跨局保留的永久养成，与单局内养成（in-run progression）相对 |
| **Roguelite** | 局内有随机/永久死亡 + 局外有成长，区别于硬核 Roguelike |
| **数值滚雪球** | 局外养成累积，回关卡时数值碾压 |
| **近失（Near Miss）** | 玩家"差一点就过了"的失败，是最强动机来源 |
| **关卡制（Stage-based）** | 有明确章节、关卡序号，区别于"自由冲分" |

**本项目品类归属**：**俯视角操作 + 局外养成 + 关卡制 Roguelite**，对标弹壳特工队 / Survivor.io / 向僵尸开炮这一支脉。

按与扫雷挖矿的"操作量 + 局外养成深度"相似度排序：

| 类型 | 代表作 | 操作量 | 局外养成深度 | 与本项目相似度 |
|---|---|---|---|---|
| **A. 割草 Roguelite** | 弹壳特工队、Survivor.io、向僵尸开炮、吸血鬼幸存者、Brotato | 中等 | 深 | ⭐⭐⭐⭐⭐ |

## 4. 关键产品深度拆解

### 4.1 弹壳特工队 / Survivor.io（最贴近的对标）

**基本信息**
- **章节数**：290+（持续更新）
- **单局时长**：8 分钟 / 15 分钟
- **装备品阶**：白→绿→蓝→紫→金（Epic+3）→红（Legend / Legend+N）→ S 级
- **装备获取**：关卡掉落 + 宝箱 + 设计图合成
- **角色（特工）**：S/A/B 等级，每个不同技能

**关卡结构与卡关点（关键数据）**
社区公认卡关节点：
- **第 27 关**
- **第 29-30 关**（普遍墙）
- **第 46 关**（著名难度尖峰）
- **第 71+ 关**
- **第 123 关**（"最难之一"）

**Boss 设计**
- 每章末有主线 Boss（约 14-15 分钟时）
- 中途有精英小 Boss 定时刷新
- 公认最难关卡 Boss：**Triple Elite Mandrill Cavalry**

**解锁节奏**
- 第 6 关：解锁每日挑战
- 第 8 关：解锁回响之战 + 特工赛季

**卡关破局路径**
> "卡住时，回退 2 章刷经验和金币，再回来。"
即 **进度由装备等级决定，而非纯技术**——这就是局外养成的核心价值。

**关键启示**
- ✅ 关卡数量充足（290+），保证长线目标
- ✅ 难度尖峰明确（每 5-20 关一个墙）
- ✅ 卡关后回刷低关变强 → 碾压 → 推进，正是我们想要的体感
- ✅ 系统逐步解锁（第 6 关 / 第 8 关）

---

### 4.2 吸血鬼幸存者（局外成长经典）

**金币升级（局外永久属性）**
优先级推荐：**数量 > 冷却 > 磁铁 > 力量 > 成长**
- 用金币在主界面升级基础属性
- 每项可升多级，越升越贵
- 每级 +X%，累积 5-10 级就有"质变感"

**嵌套解锁链（核心设计）**
```
解锁角色 A → 角色主武器升满级 → 武器合成超武 → 解锁新角色 B → ...
```
这是 VS 最值得借鉴的设计：**解锁不是孤立的，而是环环相扣的链条**。

**典型解锁条件示例**
- 角色解锁：找 500 金币 / 通关特定地图 / 一局获得 5000 金币
- 道具解锁：把 16 个道具全升满级
- 装备解锁：圣水升 4 级 → 解锁烛台
- 关卡血战模式：击败 25 分钟 Boss

**关键启示**
- ✅ 每死一次都给金币，**失败 100% 给奖励**
- ✅ 解锁链嵌套，玩家永远有"下一个目标"
- ✅ 升级属性可视化（伤害数字跳字），变强看得见

---

### 4.3 寻道大千（小游戏赛道第一流水柱）

**养成系统解锁节奏（按主线任务数）**

| 系统 | 解锁条件 |
|---|---|
| 砍树 | 创建角色 |
| 冒险（推图） | 6 个主线任务 |
| 幻境阁 | 10 个主线任务 |
| 座驾 | 19 个主线任务 |
| 福地 | 26 个主线任务 |
| 斗法（PVP） | 28 个主线任务 |
| 血脉 | 153 个主线任务 |
| **法宝** | **开服 26 天 + 156 级** |
| 群英榜 | 等级 70 + 开服 5 天 |

**节奏特征**
- 1→156 级：约 8 天
- 156→182 级：约 3 天（累计 11 天）
- **每个新系统解锁 = 战力大跃升 + 对旧系统二次加成**
- 后期靠每日已解锁系统缓慢提升

**核心启示**
- ✅ **三类解锁触发器**：主线任务数、等级、开服天数——组合使用
- ✅ **新系统解锁即质变**：玩家永远期待下一个系统的开放
- ✅ **加成耦合**：新系统不是孤立的，会反向加成老系统

---

### 4.4 向僵尸开炮（俯视角 + 局外养成最佳实践）

**核心循环**
> "无论输赢玩家均可获得一定养成素材奖励，投入到局外养成当中，从而构成**局外数值强化、局内战斗验证的循环**。"

**局外养成维度**
- 角色装备数值养成
- 武器养成
- 流派构筑（多 build 选择）

**"偏量养成"思路（核心设计）**
> 产品的技能 build 升级过程中，每个技能的**伤害、攻击范围、攻击手段捆绑在一起**升级。
即：**升级不是单维数值堆叠，而是多维度协同提升**，让玩家每次升级都感受到质变。

**节奏参考（同类靶心 Like）**
> 前期（纯游戏时长 7-8 小时）体验顺畅、挫败感较低。局内的高随机设计与局外的策略性设计共同作用，**拉高玩家的体验上限的同时保证玩家的体验下限**。

**关键启示**
- ✅ **失败不惩罚**——这就是"退出升级"心理基础
- ✅ **偏量养成**——升级要捆绑多维度，避免"+5%伤害"这种感知不到的升级
- ✅ **保底下限 + 拉高上限**——局外数值保底能过，局内 build 拉开上限

---

### 4.5 Hades（局外成长理论框架最完整）

**双线成长模型**
- **局内成长**：单局人物强度 + 收益（build、武器临时加成），随死亡丢失
- **局外成长**：解锁内容（武器、信物、镜面天赋、好感度）

**死亡资源化**
> 用长期目标（庞大的天赋树、全图鉴收集、武器进阶）掩盖重复劳动枯燥。

**节奏建议（玩家实战）**
- 前期优先**解锁全武器** → 再解锁**镜面天赋**
- 资源分配的优先级，决定前期爽感

**热度（Heat）系统**
- 通关后开启"逃脱契约"，可加难度因子
- **每次通关都给玩家"再加一点难"的主动权**——长线挑战容器

**关键启示**
- ✅ **死亡是资源**：每次死都给黑暗宝石等局外货币
- ✅ **解锁节奏的玩家可控性**：玩家选先解锁武器还是天赋，建立"我的成长路线"感
- ✅ **通关后内容**：热度系统让通关后还能继续挑战

### 5.3 各模块详细设计要点

---

#### 模块 1: 局内玩法（Core Loop）

| 设计要素 | 推荐值 / 做法 | 参考产品 |
|---|---|---|
| **单局时长** | **3-8 分钟**（最甜蜜点） | 弹壳 8min、向僵尸开炮 5min、Brotato 波次制 |
| **单局目标** | 多样化：清图 / 生存 N 秒 / 击杀 Boss / 得分 | 弹壳每关目标不同 |
| **局内 build** | 局内随机升级（三选一） | 吸血鬼幸存者、Hades |
| **操作反馈** | 高频跳字、特效、音效 | 所有割草 Like |
| **难度递增** | 局内难度曲线（前期缓→后期急） | 弹壳 8 分钟曲线 |

**当前扫雷挖矿问题**：90 秒太短，无法容纳 build 累积感。

---

#### 模块 2: 关卡与章节（Progression Container）

| 设计要素 | 推荐值 / 做法 | 参考产品 |
|---|---|---|
| **章节数** | **50-300 章**，可持续更新 | 弹壳 290+ |
| **关卡目标类型** | 至少 3-5 种轮换（清图 / 限时 / 不踩雷 / 护送 / Boss） | 弹壳每章不同 |
| **难度曲线** | 每 5-20 关一个**难度尖峰**（卡关点） | 弹壳 27/30/46/71/123 |
| **Boss 关** | 每 5-10 关一个 Boss，每章节末大 Boss | 弹壳 |
| **回刷机制** | 卡关时可回退刷低关，**不强制现关反复试** | 弹壳社区共识 |
| **章节地图** | 可视化进度（路径式 / 章节封面） | 寻道大千、Candy Crush |

**当前扫雷挖矿问题**：**完全没有这个模块**。90 秒冲分 = 自由刷，没有卡关容器。

---

#### 模块 3: 局外养成（Meta Progression）

四种子模块：

| 子模块 | 设计 | 参考 |
|---|---|---|
| **永久属性升级** | 用局外货币升级基础属性（速度/伤害/HP/起始资源），每级 +10-20% | 吸血鬼幸存者金币升级 |
| **装备 / 配件系统** | 关卡掉落 + 合成 + 品阶（白→绿→蓝→紫→金→红→S） | 弹壳、向僵尸开炮 |
| **角色 / 流派解锁** | 多角色供选，每个不同 build 倾向 | Brotato、Hades |
| **天赋树** | 大型分支树，玩家自选路径 | Hades 镜面天赋、哈迪斯 |

**关键设计原则：偏量养成**
> 不要做"+5% 速度"这种感知不到的升级。要把多个维度捆绑升级。
> 例如：opener 升级 = 速度 +30% + 范围 +1 + 解锁"群体开墙"——一次升级三种提升。

**当前扫雷挖矿问题**：
- 升级感知太弱（速度 2.0→1.5→1.0，每级仅 +25%）
- 没有装备系统
- 没有角色流派（玩家身份固定）

---

#### 模块 4: 解锁系统（系统逐步开放）

四类解锁触发器（可组合使用）：

| 触发器 | 机制 | 参考 |
|---|---|---|
| **主线解锁** | 完成 N 个主线任务 → 解锁新系统 | 寻道大千 6/10/19/26/28/153 |
| **关卡解锁** | 通关第 N 关 → 解锁 | 弹壳第 6/8 关 |
| **等级解锁** | 角色等级达 N → 解锁 | 寻道大千 156 级解锁法宝 |
| **时间解锁** | 开服 N 天 → 解锁 | 寻道大千开服 26 天 |

**关键设计：嵌套解锁链**
> 解锁不是孤立的点，而是链：
> 完成 detector 解锁 → 用 detector 找到矿脉 → 矿脉触发 miner 需求 → miner 解锁
> 这种链式解锁让玩家永远有"下一个目标"，**避免一次解锁后的空虚感**。

**当前扫雷挖矿状态**：已有 detector/miner/塔/无人机的矿石解锁，但都是**并列孤立**的，不是嵌套链。

---

#### 模块 5: 经济与货币

| 货币类型 | 用途 | 来源 | 跨局 |
|---|---|---|---|
| **局内货币（钱）** | 关卡内购买 | 关卡内行动 | 不保留 |
| **积分 / 战绩** | 排行、转化 | 关卡内行动 | 不保留 |
| **局外货币（矿石/金币）** | 永久升级 | 积分转化、失败奖励 | 永久 |
| **高级货币（钻石/宝石）** | 抽卡、加速、稀有道具 | 付费 / 成就 | 永久 |
| **碎片 / 设计图** | 装备合成 | 关卡掉落 | 永久 |

**关键设计原则：货币 4 类，互不混淆**
- 局内钱和局外矿石必须独立（避免套娃）
- 高级货币要可免费少量获取（保底）
- 碎片机制是装备系统的核心（弹壳）

**当前扫雷挖矿状态**：✓ 已对齐（钱/积分/矿石三货币）

---

#### 模块 6: 失败与激励

| 设计要素 | 做法 | 参考 |
|---|---|---|
| **失败 100% 给奖励** | 失败也给局外货币（约胜利的 50-70%） | 向僵尸开炮、吸血鬼幸存者 |
| **近失补偿** | 差几格就过 → 双倍奖励 + 提示"再升 X 次就过" | 通用做法 |
| **离线收益** | 不在线也按时间累积少量资源 | 寻道大千、咸鱼之王 |
| **每日签到** | 7 日循环签到 | 通用 |
| **每日任务** | 3-5 个小任务（开 50 格、买 3 机器人等） | 弹壳每日挑战 |
| **首通奖励** | 第一次通关给大量奖励 | 所有产品 |

**关键设计：失败体感的三层**
1. **失败给奖励**：基础，必须有
2. **近失补偿**：差一点就过 → 给更多
3. **明确指引**：UI 显示"再升 1 次速度就能过"——告诉玩家路径

**当前扫雷挖矿问题**：失败给矿石 ✓，但**没有近失补偿、没有指引**。

---

#### 模块 7: 社交与长线

| 设计要素 | 做法 | 参考 |
|---|---|---|
| **好友排行** | 每关好友排名 | 微信小游戏标配 |
| **全球排行** | 总榜 + 每周榜 | 所有产品 |
| **PVP** | 异步对战 / 同步对战 | 寻道大千斗法 |
| **公会** | 10-30 人小团体，公会任务 | 通用 |
| **赛季** | 每月赛季，段位 + 奖励 | 弹壳特工赛季 |
| **每日挑战** | 关卡变体（特殊规则） | 弹壳每日挑战 |
| **限时活动** | 节日活动、合作活动 | 所有产品 |

**关键设计：社交是微信小游戏的"免费广告"**
> 微信小游戏 80% 用户通过下拉入口、社交分享主动找到游戏。
> 每个社交模块都是裂变入口。

**当前扫雷挖矿状态**：完全缺失（先做单机体验，后期再加）

#### 模块 8: 商业化（付费）

| 付费点 | 做法 | 参考 |
|---|---|---|
| **月卡** | 30 元 / 月，每日领奖励 | 寻道大千、咸鱼之王 |
| **战令** | 季度付费战令，做任务升等级领奖 | 弹壳、所有产品 |
| **抽卡** | 角色 / 装备 / 皮肤 | 寻道大千 |
| **去广告** | 一次性付费，去激励视频广告 | 通用 |
| **皮肤** | 角色皮肤、地块皮肤 | 通用 |
| **首充礼包** | 6 元超值礼包 | 所有产品 |

**关键设计：免费玩家也能玩到 80% 内容**
> 小游戏的逻辑是：免费玩家制造热度，付费玩家养团队。
> 不要做"付费墙"，要做"付费加速"。

**当前扫雷挖矿状态**：暂不考虑商业化（先做产品本身）

### 6.1 已对齐的模块 ✓

| 模块 | 当前实现 |
|---|---|

|---|---|---|
| **模块 2 关卡章节** | ⚠️ **完全缺失** | **致命**——没有"卡关"容器，无法实现目标体感 |

### 6.3 数值感知问题 ⚠️

当前升级幅度太小：
- 机器人速度 2.0s → 1.5s → 1.0s：每级 +25%（玩家几乎感受不到）
- 起始金币 100 → 110 → ... → 150：每级 +10%（更感受不到）

**对标**：弹壳装备品阶跨越 = +50%~100%，吸血鬼幸存者每级 +10% 但一升就是 5-10 级。

## 7. 改造方向建议（高层路线图）

### 7.1 优先级排序

| 优先级 | 改造项 | 价值 | 工作量 |
|---|---|---|---|
| **P0** | **加关卡章节系统**（模块 2） | 致命，体感基础 | 中 |
| **P0** | **拉大升级质变感**（模块 3，偏量养成） | 高，体感关键 | 小 |
| **P1** | 加近失补偿 + 指引（模块 6） | 高，失败体感 | 小 |
| **P1** | 嵌套解锁链（模块 4） | 中高，长期目标 | 中 |
| **P2** | 装备 / 配件系统（模块 3） | 高，但工作量大 | 大 |
| **P2** | 多角色 / 流派（模块 3） | 中高 | 大 |
| **P3** | 每日任务 / 签到（模块 6） | 中 | 小 |
| **P3** | 排行榜（模块 7） | 中 | 中 |
| **P4** | 商业化（模块 8） | 后期 | 大 |

### 7.2 P0 关卡章节系统的具体建议（高层）

**章节结构建议**：
- 第 1 章：教学关（5 关）—— 只用 opener + marker，介绍扫雷基础
- 第 2 章：矿脉产业链（5 关）—— 解锁 detector + miner
- 第 3 章：充能塔（5 关）—— 解锁塔
- 第 4 章：无人机（5 关）—— 解锁无人机
- 第 5 章：混合挑战（5 关）—— 全系统混合
- 第 6 章+：进阶难度（无限章节）

**关卡目标多样化**：
- 清完所有安全格
- 90 秒内得 X 分
- 不踩雷通关
- 标对 N 个雷
- 用机器人清完 X 格

**Boss 关设计**（每 5 关一个）：
- 高密度雷关（密度 20%）
- 限时关（60 秒）
- 禁标雷关（只能开格）
- 双地图关（同时两张小图）

### 7.3 P0 偏量养成的具体建议

把现有"每级 +10%"的升级改成"每级捆绑多维度质变"：

| 当前升级 | 改造为 |
|---|---|
| opener 速度 Lv1: 2.0s → 1.5s | opener 速度 +30% + 范围 +1（可开 8 邻格的安全墙）|
| 起始金币 Lv1: 100 → 110 | 起始金币 +20 + 起始送 1 个 opener |
| 命数 Lv1: 3 → 4 | 命数 +1 + 踩雷不扣钱 5 秒 |

**关键**：让玩家在升级面板上看到 "**3 项提升**" 而不是 "**1 项 +10%**"。
