> 2026-09-28。范围：鼠标、棋盘目标、开格、标旗、采矿、机器人、HUD 与商店。与[局内交互动效设计 v1](局内交互动效设计-v1.md)配套；本轮制作的是素材与交接规格，场景和输入代码尚未接入。

## 给接入者的约束

1. **先做鼠标与悬停。** Godot 4.6 的 `Input.set_custom_mouse_cursor(image, shape, hotspot)` 可注册静态硬件光标；光标图不做逐帧动画，动画留给棋盘覆盖层。普通箭头建议作为 `CURSOR_ARROW`；放置箭头可作为现有放置流程使用的 `CURSOR_POINTING_HAND`。棋盘准星作为可选 `CURSOR_CROSS`，需要实机比较“箭头 + 角框”和“准星 + 角框”后选一种，别同时堆两层抢数字。[Godot Input 文档](https://docs.godotengine.org/en/4.6/classes/class_input.html)
2. **落点提示必须复用真实放置条件。** `Main._try_place_at()` 当前才判断金币、可走格、机器人占位、基地/探测器特例；把判断抽成无副作用的 `can_place_at()` 供悬停与点击共用。首次基地又有两种规则：普通随机盘可放关闭格，L4 预生成盘只能放已开格。不要凭视觉条件另写一套近似规则。
3. **放置购买发生在落点成功时。** 商店按钮只进入放置模式；光标切换、合法框、取消放置都不能扣钱。Esc/右键取消、打开暂停或覆盖层时恢复普通光标并清除预览。
4. **非法落点和 CD 分开。** 红叉只表示此格不满足放置规则；CD 拦截继续用已有鼠标旁圆环。普通扫雷右键插旗无需预告“正确/错误”，保留推理信息口径。
5. **按动作结果发特效。** 岩屑只在安全格实际打开后产生；三枚形状用同一张蒙版表重复利用。金币闪点用于卸货或较大收益，`+1` 开格只用现有金币图标和短跳字。并发预算见动效设计稿。

## 仍需代码实现的项目

按优先级：① 光标注册与退出状态恢复；② 棋盘悬停/合法落点判定和覆盖层；③ 修正连锁开格失败仍发奖励信号、补撤旗状态事件；④ 接开格、插旗和卸货的帧图/跳字；⑤ 实机调节光标对比度、CD 环位置与视觉密度。以上均未在本轮修改玩法代码。

验收样例：连续移动鼠标扫过已开数字与未开岩壁、在 L4 首次基地阶段尝试开/关格放置、在占用格上尝试部署机器人、CD 中快速点击、Esc 取消部署、一次大连锁和两台矿工接连卸货。每种情况下光标、角框与实际结果必须一致。
