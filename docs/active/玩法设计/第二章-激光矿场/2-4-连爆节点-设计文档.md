## 1. 定位与教学目标

把连爆做成玩家主动利用的可见中立建筑。玩家先根据数字保护爆炸范围里的钻石，再用一次激光启动整串节点，**把之前的标记准备兑换成大面积破墙**。

本关的新增重点是引爆时机与范围风险，不增加隐藏爆炸砖，也不把原来的雷换成另一种雷。

## 2. 参数

| 项目 | 原型初值 |
|---|---|
| 地图 | 固定 16×16，32 枚钻石，预开 80 个安全格 |
| 初始三层墙 | 42 格 |
| 时限／目标 | 210 秒内达到 320 分 |
| 开局资源 | 180 金；开墙、标记机器人各 1；宽束折光机器人 1 |
| 连爆节点 | 6 座，分成两组各 3 座；都位于预开安全格 |
| 爆炸范围 | 节点周围 3×3，包含八邻格；命中相邻节点则继续引爆 |
| 节点奖励 | 自身 0；只结算真实开格、拆墙和击杀 |
| 继承 | 充能、折光配置购买、筑墙工、动作预算与全部钻石规则 |

静态最高分 304，至少补 16 分动态收益。节点只是扩大一次操作覆盖，不额外凭空生成分数或钻石。

## 3. 连爆规则

- 激光、折光副束或其他节点爆炸可触发；节点触发后消耗，不在敌人补墙时重生。
- 爆炸对范围内墙体削 1 层，对敌人造成 1 伤害，触发其他节点；本身不给普通机器人充能，也不伤害友方机器人。
- 一轮射击中，同一节点只触发一次。同一格被激光与多个爆炸重复覆盖，合计仍最多削 1 层；三层墙不能靠紧挨三座节点一轮炸开。
- 旗格与已转化资源全程保护；未标记钻石被爆炸误打只得低收益。节点范围公开，隐藏钻石不在预览中突出显示。
- 机器人不会主动把中立节点当作普通墙拆掉。玩家决定是否引爆；副束意外触发也按同一预览规则处理。

## 4. 地图设计要求

- 第一组节点放在主基地容易直射的已开区域，相邻节点中心落在彼此八邻范围内。周围首先以可确认安全的普通墙为主，让玩家看清连爆顺序。
- 第二组节点靠近未开工作面，已有数字能推理出若干需要保护的钻石。玩家有准备空间，再引爆会比直接盲打更有收益。
- 两组之间不连通，一次引爆不会无预告地清掉全图。预览应沿可见节点关系显示本次整条链的范围，而不是只画第一座。
- 至少一组邻近敌人补墙地面，让玩家能选择立刻开新面，或等新墙与敌人聚集后使用。
- 加固墙外观和钻石位置独立，节点只占预开安全格，不透露周围未开格的真实内容。

## 5. 关内流程

| 阶段／触发 | 局面与反馈 | 引导 |
|---|---|---|
| 开局 | 第一组节点轮廓可见，鼠标预览显示整串影响区 | 「击中节点，相邻节点连爆。」 |
| 首次引爆 | 节点依次闪光消耗，墙体按同轮削层，奖励只跟真实工作跳字 | 无额外倍率提示 |
| 第二组进入玩家注意范围 | 预览覆盖未知格，数字与旗子仍清楚可见 | 「先标记，再引爆。」 |
| 首次爆炸误打，若发生 | 钻石碎裂给低分，不扣命 | 沿用 2-1 的低收益提示，不增加新惩罚 |
| 中后段 | 剩余节点与筑墙工形成时机选择，折光单位也可启动连爆 | 不新增敌人招式 |

## 6. 取舍与边界

玩家可以先让标记机器人处理范围，再用节点节约动作；也可以急着打开地面，接受尚未保护钻石的低收益。需要逐格保证安全的工作交给推理与标记，节点只负责放大已经准备好的操作。

- 两个分支同时击中同一节点只启动一次，节点不能因销毁动画尚未结束而反复爆炸。
- 连爆顺序用于表现，不能在节点动画间让敌人新墙插入同轮结算或让机器人移动改变已快照的命中。
- 爆炸不跨地图边界，边缘节点的实际裁切范围与预览相同。
- 节点不用完也允许达标；节点已经全部消耗后，普通激光、机器人和敌人波次仍能继续供应工作。
- 本关没有引光柱，不引入中立建筑损坏扣分；节点本来就是供玩家消耗的设施。

## 7. 验收与试玩观察

- 第一组能完成至少三座连续触发，第二组不会被第一组无预览地引爆。
- 直接激光、宽束、散射启动节点均得到同样规则，连爆没有自动标记钻石的例外。
- 重叠爆炸只削 1 层，节点和墙体奖励无重复；误打不扣命，旗格保留。
- 观察玩家是否在第二组前先补标记、能否预判整条链；若连爆让三层墙失去存在感，先查去重和范围，再调数值。
