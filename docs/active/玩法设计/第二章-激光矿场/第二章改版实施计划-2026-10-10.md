## 2. 关键设计决策（D1-D8，评审可推翻）

| # | 决策 | 理由 |
|---|---|---|
| D1 | **矿石落脚=预开安全格（已开地面），足迹格保持已开态**，同连爆节点先例 | 已开格永不进 Solver 目标集 → opener 不会试图拆它；「不可破坏」只需结算跳过足迹格；挡路/挡施工走 facility_cells 现成门 |
| D2 | **爆发方向=随机 3 个互异八向**。八向相邻夹角 45°，任意互异三向两两 ≥45°>30°，约束天然满足 | 用户拍板 #4 的「>30°」在八向口径下免费获得；实测嫌太粗再升 16 向 |
| D3 | **触发源只认束格（主/副）；爆发格/爆炸格不级联**——不触发第二块矿石、不引爆第二台过载、爆炸格不再入节点链 | 沿「副束不激活第二台折光」先例（总纲 §6.2）；链式随机嵌套的结算不可读 |
| D4 | **矿石爆发格与过载爆炸格内的 opener/marker 照常充能**（拍板 #8）；**s5 连爆的「爆炸不充能」原样保留** | 两条口径并存：s4 换过载后已无节点，同屏不冲突；s5 冻结不动。总纲修订时把「爆炸不充能」改为「连爆节点爆炸不充能（历史口径，2-5 冻结）」并在新两关文案写明充能 |
| D5 | **s3 折光退场**（preset/start_robots/商店键全撤）；**s4 连爆节点与折光都退场**；两关盘面重摆。折光/连爆**代码与注册全部保留** | 单关单星机制的章法（2-1 激光 / 2-2 充能 / 2-3 矿石 / 2-4 过载）；提案 §7「重排」口径。已知后果：s5 的折光从此无前置教学——s5 本就搁置待重设计，接受并记录 |
| D6 | **束止于过载机器人**（挡光，提案建议口径，实测后调）；过载**不走放置流**，直购直出基地出厂 | 拍板 #10 与提案 §5「建议束止于机器人」 |
| D7 | **过载巡逻固定步速 2.2s/格，不吃充能/升级轨/黏液外的新乘数**；到达高分工位（低数字×靠墙）停留 3 拍 ≈6.6s 再走 | guard Q2 先例（固定速度便于盲测归因）；停留拍给玩家「等它走到位」的读秒空间（提案实测后调项的 v1 答案） |
| D8 | **爆发形状**：矿石=核心格出发 3 条 `beam_cells` 线各 ≤3 格（边界裁切、剔矿石足迹自身）；过载=3×3 + 四正方向各 +1 格 = **13 格**（边界裁切，拍板 #6） | 全部复用 LaserGeometry 整数几何，无浮点 |
