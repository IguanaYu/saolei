## 1. 定位与教学目标

把第一章的单格开矿变成沿线开矿，让玩家学会**先保护钻石，再连续削掉一条线上的墙**。本关只教基础激光、三层墙和钻石记分，不加入敌人或增幅装置。

离关时应理解：点得越远，影响的格子越多；三层墙每枪少一层；钻石仍要根据数字由玩家或机器人标记；未标记打碎只给少量分，不扣命。

## 2. 参数

| 项目 | 原型初值 |
|---|---|
| 地图 | 固定 12×12，18 枚钻石，预开 40 个安全格 |
| 初始多层墙 | 18 格耐久 3；其余未开格耐久 1；外壳与钻石位置独立 |
| 时限／目标 | 180 秒内达到 140 分 |
| 发射点 | 左侧中部的主基地，暂定固定 |
| 开局资源 | 100 金，开墙与标记机器人各 1 台 |
| 商店 | 既有开墙、标记机器人与原升级；本关不开放护卫、折光或额外基地 |
| 手动预算 | 5 次免费动作，之后 3 秒补 1 次，上限 7 |
| 奖励 | 安全开格 +1；正确标记 +5；误打钻石 +1；削层不加分 |
| 结束 | 达标解锁 2-2；到点未达标结算收益并允许重玩 |

预开不计分，带旗格和已转化钻石受所有破坏效果保护。本关没有生命伤害。

## 3. 地图设计要求

地图尚未烘焙，以下是制作约束，不是已存在的盘面。

- 主基地周围预开区容纳两台机器人，能读到边界数字。基地至近处教学线先布置 3～4 格可推理安全的普通墙，方便比较近点与远点。
- 第二条教学线布置连续三层墙，至少能让一枪同时削到两块。墙的三个阶段轮廓清楚，不以钻石真值分配墙皮。
- 布置至少一组能用已有数字确定的钻石，且相邻安全格形成有价值的射击路径；玩家标记后能放心穿线。不得直接画出隐藏钻石位置作为教程答案。
- 后半区兼有长直线和短线：长线覆盖更多格子，但需要先处理旗子；短线方便精确控制。不要做成唯一正确射线的谜题。
- 三层墙不会被零连开直接打开；普通安全区可沿用零连开，帮助机器人建立工作面。

## 4. 关内流程

| 阶段／触发 | 局面与反馈 | 引导 |
|---|---|---|
| 开局 | 展示基地炮口与点击位置之间的预览线，机器人进入预开区 | 「点远处，沿线开墙。」 |
| 首次发射 | 一束激光穿过多格，奖励只在真正开格时出现 | 用线上的墙依次破碎说明效果 |
| 首次削加固墙 | 墙由 3 层变 2 层，显示裂纹和剩余层数 | 「三层墙，要打三次。」 |
| 首次正确标记 | 钻石主要奖励跳字，带旗格在后续射线上保留 | 「钻石先标记，收益更高。」 |
| 首次误打，若发生 | 钻石碎裂，只显示 +1，不扣命 | 「未标记打碎，只有少量分。」 |
| 后半局 | 玩家安排长线、补刀和机器人作业 | 不再弹新规则 |

教学按动作触发，不用固定秒数强迫玩家误打钻石。说明弹层期间暂停关卡计时。

## 5. 决策与难度来源

多层墙不增加隐藏信息，只增加处理次数。玩家可沿同一条线连打，也可先削一层，换去标记另一片，再让开墙机器人接手确定安全的目标。不会因为点得远自动拿到正确标记奖励。

尚未开的安全格为 `144 - 18 - 40 = 86`。全正确标记的静态上限为 `86 + 18×5 = 176`；全误打上限为 104。达到 140 分至少需要正确标记 9 枚，不能只靠把钻石全部扫碎过关。实际能否在时限内完成还需要地图验解和试玩。

## 6. 边界处理

- 多层钻石格被标记时，和普通未开格一样直接走标记规则；不要求先破壳看到钻石。错旗保护不等于判对，玩家可撤销。
- 三层墙前两次命中不露数字或钻石；第三次才打开或误打底层目标。
- 激光经过旗子时不伤它，并继续影响后方；预览不改变颜色提示旗子真假。
- 相同位置被重复射击、机器人与玩家同帧完成工作，都只领取一次底层开格奖励。
- 若误打过多，所有可得分目标都已耗尽且未达标，提前正常结算并提示重玩；不偷偷补钻石或抬高误打奖励。
- 空射仍消耗一次动作；剩余动作不足时不发射，不凭隐藏目标内容决定是否扣动作。

## 7. 验收与试玩观察

- 在同一教学线比较近点和远点，预览与命中格完全一致；经过带旗格的射击不破坏旗子。
- 三层格经 3 次独立射击才完成；零连开、和弦与机器人作业均遵守耐久入口。
- 正确标记 +5、误打 +1 且不扣命；反复撤旗重标不刷奖励。
- 地图有连续的可推理推进路径，不靠教程直接告诉玩家钻石坐标。
- 观察玩家是否主动先标记再射、能否看懂墙层数、固定基地是否让近点操作别扭。通过后再制作 2-2 的动态造墙内容。
