## 1. 定位

2-3 的星机制：一块「多点几下就能持续开区」的本地工具。中立、不可破坏、无限次触发——
玩家的决策从「新单位放哪里」（折光版）变成「**推进到哪块矿石旁值得停下连点**」。
它也是未来「持续刷砖敌人/地图特性」的预留克星（现有筑墙工已是雏形，本关保留筑墙工+[1,1,3] 序列）。

## 2. 规则（拍板口径）

| 维度 | 规则 | 落点 |
|---|---|---|
| 形态 | 中立设施，2×2 足迹落预开安全格，挡路（facility_cells）挡光（束止于足迹） | `special_ore.gd` / `facility_manager.setup_ores` |
| 触发 | 玩家激光束（主/副）踩中足迹即触发；无新增代价（拍板 #2），走既有发射预算与 CD | `laser_manager.compute_shot_geometry` |
| 效果 | 3 个随机互异八向 ×≤3 步爆发（互异=两两 ≥45°>30° 天然满足，拍板 #4）；斜向 2 宽阶梯带 | `SpecialOre.burst_cells` |
| 次数 | 无限次（拍板 #3）；每轮重掷方向，`consumed` 概念不适用 | 同上 |
| 结算 | 沿激光语义（开格/削层/碎钻/削覆盖墙/伤敌）；足迹格永不结算 | `fire()` 跳足迹 |
| 充能 | 爆发格内 opener/marker 照常充能（拍板 #8，=激光经过同效） | `fire()` 充能集扩展 |
| 旗格 | 旗格免疫（附1 统一口径） | `fire()` 既有跳过 |
| 级联 | 爆发格不触发其他矿石/过载/节点（D3，沿「副束不激活第二台折光」） | 触发源只认束格 |
| 预览 | 不画随机爆发格（每轮重掷画了必误导），画足迹描边 | `ore_marks` |

## 4. 教学（Ch02S3Director）

聚光一句「射中特殊矿石，向三面爆发。」（事件 `ore_burst` 推进）；第二次触发时 toast
「这块矿石可以反复触发。」——无限次是矿石与一切一次性设施的核心差异。
