## 3. 工作包分解

### WP1 激光几何静态类（全章唯一几何源）

新建 `scripts/laser/laser_geometry.gd`（`class_name LaserGeometry`，纯静态，无节点依赖——预览、结算、Python 烘焙模拟三方共用同一套规则，这是设计 §11"预览=实际命中"的结构保证）：

1. `static beam_cells(from: Vector2i, to: Vector2i) -> Array[Vector2i]` — **超覆盖 Bresenham**（supercover）：返回格心连线触及的全部格子；恰好穿过格点时横/竖两格**都**收入（固定顺序：先横后竖），去重保序。起点（基地格）不含、终点含。
2. `static octant_dir(from: Vector2i, to: Vector2i) -> Vector2i` — 方向八向量化（2-3 散射/宽束与 2-5 引光用；本 WP 先落函数与单测）。
3. 单元测试 `tmp/test_laser_geometry.gd`（headless `-s` 模式，参照 tmp 测试模板）：横/竖/斜/穿角/同格/相邻格全枚举断言，并导出一份坐标表供 Python finder 移植对照（**Python 侧必须逐 case 对拍**，规则分叉=预览与烘焙断言失效的根源）。

> 算法选型记录：格心到格心的整数线用超覆盖 Bresenham，不用 Amanatides-Woo 体素步进——后者为浮点射线通用设计，supercover 的"线触及的所有格"语义直接可教（角落双格=激光擦过两格各削一层）。既有知识，本轮搜索配额断（WebSearch 限流 2026-10-13 恢复、参考站 eugen.dedu 连接拒绝未实抓），落地前用单测对拍兜底。

### WP3 LaserManager：发射 / 预览 / 结算管线 v1（直射）

新建 `scripts/laser/laser_manager.gd`（Node2D）挂 BoardRoot（Main.tscn 显式命名 `LaserManager`；参照 RobotManager/EnemyManager 层级惯例），main.gd 持引用。

1. **输入分流**：[grid.gd `_on_cell_left_clicked`](../../../scripts/grid.gd#L877-L908) 头部加 `if laser_mode: laser_fire_requested.emit(coord); return`——`laser_mode` 由 `grid.configure` 从 LevelData 读入；右键/和弦/双击路径不动。点基地格自身（束长 0）不发射不扣动作；越界与 UI 点击本就不进此路径。
2. **发射入口** main.gd：`_try_fire_laser(target)` → `GameState.is_player_blocked()` / CD 层不足 → `cd_blocked.emit`（复用 CDRing 抖动语言）→ `consume_player_action()`（空射照扣，设计 §6）→ `laser_manager.fire(base, target)`。发射点 = `GameState.bases[0]`（首轮原型单基地，总纲 §5.1）。
3. **结算管线**（总纲 §5.3 定序，本 WP 落直射版、按多束架构预留——后续关只扩不重构）：
   - ① 几何快照：`LaserGeometry.beam_cells(base, target)`；
   - ② 逐格结算（同一格本轮至多一次，天然满足"每枪削同一格 1 层"）：**旗格跳过且光束继续**（保护不阻断，设计 §4.3）→ 未开且 hp>1：`damage_wall` 岩屑 → 未开且 hp==1：破墙后尝试开格——安全格走 `open_cell(coord, "player_laser")`（首开 +1 分 +1 金、零连开、波纹全现成），未标钻石走 **碎钻**（WP4）→ 已开格：2-1 无事（2-2 起充能/敌人在此挂钩）；
   - ③ 奖励跳字（开格批次跳字/碎钻 +1）、`fx_laser_flash` 光束闪光；
   - ④ 本轮结算完 → `_update_objective_progress()`（REACH_SCORE 达标即 win 走现有 [main.gd:1355](../../../scripts/main.gd#L1355) 管线；"先结算完再判达标"的时序在此定型，2-5 破柱依赖）。
4. **预览**：新建 `LaserPreview`（Node2D，Grid 子节点，仿 `ProbePreview` [grid.gd:101-112](../../../scripts/grid.gd#L101-L112) 程序绘制）——接现成 `cell_hovered/unhovered` 信号（[grid.gd:37-57](../../../scripts/grid.gd#L37-L57)），悬停时高亮整条束穿格（半透明描边）+ 束线虚影；只画公开几何，旗格样式不变（不验真假，设计 §4.5）。
5. **光束视觉**：effects_layer 新 `fx_laser_flash(segments: Array)`——Line2D 或 `_draw` 双层（外层粗半透明辉光+内层细芯，红橙暖色系入色板），0.15s 淡出，挂 EffectsLayer 吃 `clear_all` 自动清场；破墙岩屑复用 `_fx_shards`（[effects_layer.gd:240](../../../scripts/effects_layer.gd#L240)）。
6. 埋点：`result_stats` 记 `shots_fired / layers_peeled / diamonds_shattered / beam_avg_cells`（总纲 §11 节奏观察四件套，2-1 起就有）。
