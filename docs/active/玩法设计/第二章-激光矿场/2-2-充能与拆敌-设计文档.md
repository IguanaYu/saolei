# 第二章 2-2：充能与拆敌

日期：2026-10-08。版本：v0.1。状态：设计初稿，未实现／未试玩。关卡槽位：`ch02_s02`。

上游：[核心思路与章节总纲](00-核心思路与章节总纲.md)。前置：[2-1 激光开矿](2-1-激光开矿-设计文档.md)。数值和地图结构为原型提案。

## 1. 定位与教学目标

让同一束激光兼任生产支持和敌人处理。玩家开始寻找**既能扫到作业机器人，又能拆墙或打敌人的路线**，而不是把所有动作都花在补墙上。

首次加入：普通机器人充能、能被激光击破的筑墙工，以及在已开地面上反复出现的覆盖墙。这三项围绕同一个循环出现：机器人作业 → 敌人补墙 → 玩家激光拆墙并提速机器人。

## 2. 参数

| 项目 | 原型初值 |
|---|---|
| 地图 | 固定 14×14，24 枚钻石，预开 60 个安全格 |
| 初始三层墙 | 24 格；其余初始未开格耐久 1 |
| 时限／目标 | 180 秒内达到 220 分 |
| 开局资源 | 100 金，开墙与标记机器人各 1 台 |
| 充能 | 6 秒内移动与作业速度 ×2；重复命中刷新，不叠倍率 |
| 筑墙工 | 耐久 2；12 秒首出，之后每 25 秒尝试补 1 只，上限 2 |
| 补墙 | 每只每 6 秒一块，耐久 1；每只保有上限 4，全场上限 8 |
| 商店 | 既有作业机器人、升级与护卫；不开放折光、额外基地 |
| 继承 | 激光、钻石保护、动作预算与奖励全部沿用总纲 |

拆完每代新墙 +1 分／金，击破每只敌人 +10 分、+5 金。静态最高分 232，动态得分提供容错，不把本关做成必须放着敌人存活才能过关。

## 3. 地图设计要求

- 左侧预开作业区里，两台机器人最初的确定任务方向大致一致，玩家容易看见一次射线给它们充能；后续自然分开，不全程排成现成的一列。
- 第一次敌人出现位置靠近已经打开的生产区，与基地间存在至少一条可直接命中的射线。裂隙提前 2 秒亮起，不能突然从未开钻石格冒出。
- 设置两处可反复施工的地面，使补墙影响通行但不封住基地唯一出口。敌人轮廓、施工轮廓和新墙耐久保持可见。
- 补墙只落在已开安全格，不盖住旗子、已转化资源或机器人当前格；数字仍可读。
- 保留一片未开区供推理标记推进，让手动对抗与自动工作同时有事可做。

## 4. 关内流程

| 阶段／触发 | 局面与反馈 | 引导 |
|---|---|---|
| 开局 | 两台赠送机器人开始工作，激光预览标出其所在格 | 「扫到机器人，短时加速。」 |
| 首次充能 | 外圈电弧、6 秒消退环，走路和工具动作加快 | 无需重复文字说明倍率 |
| 12 秒，出现前预警 | 第一只筑墙工在已开区域边缘出现，开始施工 | 「它会在已开处补墙。」 |
| 首次命中敌人 | 敌人耐久从 2 变 1，清晰受击反馈 | 「激光也能击破敌人。」 |
| 首次拆掉覆盖墙 | 新墙 +1，底层格不再重复跳开格奖励 | 用收益反馈说明可反复得分 |
| 中后段 | 波次有空档；玩家可清敌、买护卫或拆墙提速 | 不再新增敌人类型 |

首次充能未完成也照常进入敌人阶段，不能强制卡住流程；引导只保留轻提示。

## 5. 决策与敌人循环

充能效果只改变效率：标记机器人不会凭空知道钻石，开墙机器人每次仍削 1 层。玩家可以等待两台机器人靠拢，一枪同时支持它们；也可以在敌人施工前补第二枪，减少短期阻塞。

敌人优先在最近 10 秒被玩家激光拆开的合法地面施工，范围与上限见总纲。杀敌后留墙仍可拆；后续波次继续出现。放任敌人会得到更多拆墙机会，也会消耗动作和机器人时间，两边都应有收益与代价。

自动应对包括开墙机器人接手已知安全的覆盖墙，以及购买护卫处理敌人。不要把全部新压力都交给玩家逐格补点。

## 6. 边界处理

- 激光扫过普通机器人不造成伤害、不停束；射线经过多台可分别充能。
- 同一轮射击重复经过同一机器人仅刷新一次；最高倍率仍为 ×2。暂停时充能计时也暂停。
- 筑墙工同一轮只受 1 伤害，不能依靠主束重复采样瞬杀。
- 施工目标被打开、机器人走入或被占用时重新检查，无法施工则跳过；不强行覆盖单位。
- 墙建在已开格上不会重新制造钻石或重置底层开格奖励。拆墙奖励按新墙实例结算一次。
- 当前敌人全灭时仍保留后续波次；新墙数量到上限即停建，不继续堆墙。
- 敌人只有造墙和移动，不暗中偷分、扣命或修改原数字。

## 7. 验收与试玩观察

- 测出充能后移动、作业间隔均减半，结束后准确恢复；升级与充能的组合按总纲生效。
- 一枪能同时拆墙、给机器人充能并伤敌；各自反馈可辨认。
- 连续运行到时限，墙数量不超过上限，基地至少有一条出口，数字和底层状态不被施工改写。
- 开墙机器人真的会拆覆盖墙；护卫能处理筑墙工，不能只停留在文案。
- 比较「持续拆墙」「优先杀敌」「买护卫后专注标记」三条路线，观察是否某一路完全无效；目标分与波次只在试玩后定案。
