# 钻石效果系统：实现与验收

日期：2026-10-23。状态：四类效果首版已开发；按用户要求先提交当前代码，**整体尚未最终验收**。原开发计划：`钻石效果系统-开发计划-2026-10-22.md`。

## 首版规则（WP0）

以下为执行原计划建议所采用的**工程默认值**，不是新增用户拍板记录。地图和参数可继续试玩调整。

| 规则 | 当前实现 |
|---|---|
| D1 激活 | 正确标记后，被第二章点击激光主束/折光副束/钻石空间效果命中才激活，标记本身不放技能 |
| D2 次数 | 每颗每局一次；入队即锁定，重开重置；撤旗重插、动画未完再射击均不能刷新 |
| D3 连锁 | 可接力射击开始时已正确标记的其他效果钻石，迭代队列收敛 |
| D4 范围 | 含中心 3×3，剪掉盘外和异形洞区；中心保留钻石和旗 |
| D5 未标钻石 | 继续走 Grid 的碎钻通道，不自动保护或激活 |
| D6 双射线 | 八方向不放回抽两个，射程默认 3；共用 LaserGeometry 几何、整枪旧设施账本和对象伤害去重 |
| D7 金币 | 默认 10 金币，来源 `diamond_effect_gold`；不增加目标分，原正确旗奖励仍只给一次 |
| D8 精灵 | 默认 3 次作业、1.5 秒间隔、20 秒寿命、同时 8 只；满员请求 FIFO 排队；无确定目标等待至寿命结束 |
| D9 信息 | 正确旗后显示四种形状角标及说明，已消费以缺角和斜杠区分；未调查格不暴露类型 |
| D10 旧设施 | 旧矿石/过载/旧节点爆炸不触发钻石；新范围不新增旧设施级联；新射线遵从旧束规则，同枪每个旧设施只放一次 |

精灵只使用 Solver 的公开数字推理输出，作业前再次核验，不读取隐藏雷位筛目标。它与机器人共享目标锁，却不进入机器人数量、购买价格和升级阶梯。作业每开一格仍是基础 +1 金币/+1 分，分别记为 `diamond_explorer` 来源。

一枪只消耗原有的一次动作。空间命中、充能、敌人伤害、柱受击完成后统一提交金币和召唤，再允许主场景判胜；不等待精灵寿命结束才结算。结束、退出、重开、换盘清掉精灵、排队请求和目标锁。没有新增局内断点存档。

## 实现位置（WP1–WP5）

| 文件 | 职责 |
|---|---|
| `scripts/diamond/diamond_effect_manager.gd` | 配置验证、四处理器注册、状态/旗快照/队列、独立 RNG、奖励提交和公开预览 |
| `scripts/diamond/explorer_manager.gd` | 临时单位、公开推理、共享锁、并存上限与待召队列、同步生命周期、飞行绘制 |
| `scripts/diamond/diamond_icon.gd` | 四种图标与已消耗形状 |
| `scripts/laser/laser_manager.gd` | 主/副束接入、额外射线、同枪旧设施账本、空间/机器人/敌人/柱去重 |
| `scripts/main.gd` | 初始化/清理、整枪判胜门、精灵奖励来源、悬停说明和表现连接 |
| `scripts/cell.gd`、`effects_layer.gd`、`grid.gd` | 角标、范围/双束/金币/召唤反馈和公开预览 |
| `scripts/data/level_data.gd`、`level_database.gd` | 按关卡的显式配置与第二章首版地图接入 |
| `scripts/autoload/game_state.gd`、`scripts/ui/results_panel.gd` | 初始与 reset 统计、独立账目、结算展示及盲测记录 |
| `scripts/ui/rules_panel.gd` | 四种效果的操作说明 |

配置例子：

```gdscript
lvl.diamond_effect_seed = 42
lvl.diamond_effects = [
    {"coord": Vector2i(2, 3), "effect_id": "gold", "params": {"gold_amount": 10}},
    {"coord": Vector2i(3, 3), "effect_id": "area_3x3", "params": {}},
    {"coord": Vector2i(3, 2), "effect_id": "split_two", "params": {"ray_range": 3}},
    {"coord": Vector2i(4, 2), "effect_id": "explorer",
        "params": {"actions": 3, "interval": 1.5, "lifetime": 20.0, "max_active": 8}},
]
```

坐标必须指向现有未开钻石。非法坐标、重复定义、未知效果、未知或不合法参数会报告，不随机换成其他效果。配置复制到局内状态，不写回共享 LevelData；效果消耗不改雷位/数字。种子 0 也可复现；悬停不抽签。

## 仍需真人试玩的事项

工程验证不能代替主观玩法验证。金币 10、射程 3、精灵次数/间隔/寿命以及上述稀疏配置是可运行的起点；尚未声称经济平衡定稿、随机远开体验通过、玩家能无解释辨认连锁或所有分辨率均已逐项人工试玩。应观察误碎钻石、购买时间、精灵有效作业/等待与遮挡反馈后再调整。这些状态与原计划的已实现代码分开记录。
