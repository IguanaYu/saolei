# 第二章 2-3：折光机器人

日期：2026-10-08。版本：v0.1。状态：设计初稿，未实现／未试玩。关卡槽位：`ch02_s03`。

上游：[核心思路与章节总纲](00-核心思路与章节总纲.md)。前置：[2-2 充能与拆敌](2-2-充能与拆敌-设计文档.md)。以下配置、价格与范围为原型提案。

## 1. 定位与教学目标

首次给玩家一台专门增幅激光的新单位。**玩家选择机器人的位置，让一束直射变成宽束或三向散射。** 本关只扩展输出范围，不增加伤害倍率、储能或中立设施。

离关时应理解：要先射中折光机器人才能增幅；宽束适合成片墙，散射适合分叉；范围变大也更容易误打尚未标记的钻石。

## 2. 参数

| 项目 | 原型初值 |
|---|---|
| 地图 | 固定 14×14，24 枚钻石，预开 64 个安全格 |
| 初始三层墙 | 30 格 |
| 时限／目标 | 210 秒内达到 250 分 |
| 开局资源 | 180 金；开墙、标记机器人各 1 台；预设宽束折光机器人 1 台 |
| 宽束配置 | 宽 3 格、长 6 格；每格每轮仍只削 1 层 |
| 散射配置 | 主轴与左右 45° 共三束，各长 6 格；每格每轮最多削 1 层 |
| 新单位商店 | 同一种折光机器人，宽束／散射各 100 金、各限 1 台；赠送计入上限 |
| 筑墙工 | 沿用 2-2；新墙按「1 层、1 层、3 层」固定序列循环 |
| 继承 | 普通机器人充能、钻石标记、动作预算与奖励沿用总纲 |

静态最高分 228，比目标少 22；必须从补墙与击杀中补足一部分分数，强化重复生产循环。

## 3. 新单位交互

- 原型为驻点单位，落在已开安全格；购买前选配置，落点前预览出射范围。右键继续标记，不承担切换模式。
- 主束到达第一台折光机器人后终止，由其光束替代后半段。出射方向沿入射方向，不能在本关凭点击终点任意拐弯。
- 普通机器人被副束扫到也能充能，敌人也能受击，墙体受同样削层规则约束。
- 同一轮只激活第一台折光机器人，副束经过其他折光机器人不会继续放大。两种配置是部署选择，不做无限串接。
- 新单位不参与扫雷解答或标记；它提供的是覆盖形状。每种配置的输出轮廓与普通机器人的充能外圈必须容易区分。

## 4. 地图设计要求

- 预设宽束机器人位于主基地能直接命中的已开驻点，前方有宽 3 格的墙带，第一次增幅能明显比直射多影响格子。
- 提供第二个可放置驻点，出射方向面对两条分叉区域，适合购买散射配置。已有数字要足以让玩家保护至少一部分钻石。
- 两个驻点覆盖区域部分不同，主基地可以分别射中，避免主束总先命中同一台而另一台永远无法激活。
- 敌人施工区在两种输出形状中都有可影响的地面，不能让新单位只在首次清墙时有用。
- 宽束区域仍有三层墙，强调变粗只扩大范围，不等于伤害三倍。

## 5. 关内流程

| 阶段／触发 | 局面与反馈 | 引导 |
|---|---|---|
| 开局 | 展示赠送宽束机器人，预览入射线与宽束轮廓 | 「射中折光机器人，激光变宽。」 |
| 首次增幅 | 一条窄束进入，三格宽输出；同轮只削每格一层 | 用前后宽度直接展示效果 |
| 首次看到分叉工作面 | 散射配置按钮与候选驻点轻提示 | 「散射适合分开的目标。」 |
| 放置散射配置 | 落点预览不显示隐藏钻石，确认后加入场景 | 不强制花钱，允许只用赠送配置 |
| 中后段 | 玩家在直射、宽束、散射之间选线，穿插标记与充能 | 不追加新机关 |

## 6. 取舍与边界

- 扩大范围前先看数字、标记钻石；宽束和散射都不能自动保护未标记钻石。
- 激光没有命中折光机器人时就是普通直射；不能点击它周围空地就自动触发。
- 分支交叉、多束经过同一格、覆盖三层墙的多个像素，都只算本轮 1 层；同敌人最多受 1 伤害。
- 一束经过普通作业机器人再进入折光机器人时，先充能普通机器人，再正常增幅，不互相抢效果。
- 本关不设置引光柱，出射方向稳定沿入射方向，便于先建立增幅模型。
- 驻点不可放在旗格、资源格、中立设施或其他单位上；放置确认前不扣钱，非法落点不吞单位。
- 静态得分不足目标时仍有后续敌人波次；不能让击杀当前敌人造成永久停产。

## 7. 验收与试玩观察

- 宽束与三束的预览格集合和实际命中完全一致，边界与斜向命中采用统一栅格规则。
- 宽束覆盖面增加，单格削层不变；三层墙仍需三轮有效伤害。
- 同一新单位只有两种配置，不靠额外的中立棱镜实现本关主要机制。
- 一枪增幅可同时打开多格、充能普通机器人和打敌，但所有钻石保护规则一致。
- 比较赠送宽束单用、追加散射、普通机器人升级三条投入路线；观察玩家是否理解选位置与选形状的关系，再调整价格和范围。
