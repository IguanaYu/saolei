## 2. 核心循环 30 秒验证

一个游戏日 ≈ 现实 90 秒~2 分钟(倒计时以 分:秒 显示,如 5:52;社区普遍说法 1.5~2 分钟,后期可能更长)[L1-L2,精确数值待实机]:

```
顾客上门(带订单气泡) → 看单 → 切肉(点/滑烤肉架) → 拿饼 → 按单加配料(黄瓜/酱等) → 放烤盘压烤 → 取出 → 包装 → 交付
                              ↘ 侧线:炸薯条(削土豆→炸→装盒)/ 倒饮料(拖杯→接→给)——按单并行
顾客吃完把钱留在桌上 → 玩家必须逐堆点击收取(忘收=当天收入 0)[L2] → 打烊结算 → 花金币升级 → 下一天
```

30 秒内可完成 2~4 单完整制作+收取,循环成立。循环的"摩擦"全部来自:订单要求的**工序数 × 并发顾客数 × 干扰事件(小偷/乞丐/烤糊/忘收钱)**。

## 3. 工作站全集与操作

场景为**单屏固定俯视视角**,无走动(与胡闹厨房的根本差异:压力不来自移动,来自点击编排)[L2]。

| 工作站 | 手动操作 | 备注 |
|---|---|---|
| 旋转烤肉架 | 多次点击/滑动切肉下落(切肉刀决定每次切出的量) | 核心站,升级刀→加快→自动切 [L2-L3] |
| 饼皮台 | 点击取饼;升级减少点击次数(3→2→1 次) | [L2]TapTap 攻略明确"点击次数 3/2/1" |
| 配料格(黄瓜、沙拉酱等 4 格) | 按订单点击加料 | 自选配料升级会增加格子→组合爆炸 [L2] |
| 烤盘/压烤机 | 放入卷好的饼,计时,**需手动取出**;忘记=烤糊报废 | 升级 1~2 级反而更易糊,满级"不会烧焦"+容量到 6 个 [L2-L3] |
| 炸薯条锅 | 削土豆→下锅→时机取出→装盒;可提前批量预制囤放 | 自动化后整线托管 [L2] |
| 橙汁机 | **手动拖杯子**到机器→接→递给顾客;3 级后自动化(杯子自动) | "不升杯子的手动拖动我真的醉了"[L1-L2] |
| 可乐机 | 类似橙汁,第 19~20 天解锁 | [L2] |
| 包装台 | 卷饼→包装;自动包装机升级后省一道点击 | [L2-L3] |
| 收银/餐桌 | 顾客把钱**留在桌上**,玩家逐堆点击收取;升级后硬币自动拾取(并入监控满级) | 忘收=当日收入归零,最强注意力惩罚 [L2] |
| 顾客区(右侧排队) | 看订单气泡、交付;顾客有耐心,超时愤怒离开 | 有"小蛋糕"道具可自动安抚愤怒顾客 [L2] |
| 特殊角色 | **老头员工**(画面左侧,爱睡觉;做错的卷饼可丢给他吃=垃圾桶) / **乞丐**(第 10 天解锁:要薯条,吃完不给钱,需"揍一顿"才付钱) / **小偷**(第 20 天解锁:偷桌上金币,发现后"揍一顿"拿回) | 三者都是"注意力税"[L2-L3] |

## 4. 压力机制分类 ⭐

### 4.1 时间压力
- **顾客耐心条**:顾客等待超时会愤怒离店(丢单);存在恢复手段(小蛋糕道具,自动给愤怒客)[L2]。
- **烤糊机制**:烤盘内卷饼过时不取=烤糊报废(原料+劳动双损)。注意:**这是唯一"越升级越危险"的站**(1~2 级烤更快、糊得也更快)[L2-L3]。
- **日倒计时**:一天约 90~120 秒,硬上限;"在有限时间榨最大产出"驱动全盘节奏 [L2]。
- **无高峰波次设计**:顾客流大体连续,压力梯度靠订单复杂度与并发数自然上升 [推测:资料中未见明确"午高峰"波次机制,均以"顾客越来越多"描述]。

### 4.2 顺序压力(工序链)
- 主链强顺序:**切肉→饼→配料→(卷/压烤→取出)→包装→交付**,不可乱序;烤盘环节还插入"时机判断"(何时取)。
- **可预制囤货**:薯条可提前炸好一批放着、烤肉可提前切好囤料——存在"闲时备料、忙时组装"的编排层,这正是自动化接管的前置结构 [L2]。
- 饮料不可预制(接了就要给),是后期手动残留的"即时响应"点 [L1-L2]。

### 4.3 并行压力
- 多顾客同时排队,每人订单 = 主食配料组合 ×(薯条?饮料?)× 个性化配料(若解锁自选配料,组合数爆炸)。
- 社区共识:自选配料/多口味是"给自己上强度"的收藏向升级,追求效率的玩家反而**不点**口味类科技 [L2](Steam 指南甚至推荐不点酱汁/橙汁/比克/饮料机等科技让顾客"配料全都要"以简化——反证组合数是主要压力源)。
- 胡闹厨房的并行压力靠多人协作+走动;沙威玛把并行压缩到**单屏点击调度**——"先做哪单、先收哪堆钱"即全部策略 [L2]。

### 4.4 注意力/移动压力
- 无走动、无视野限制(单屏);注意力压力替代了移动压力:**桌上散落的金币要收、小偷要盯、乞丐要揍、烤盘要掐表**——四个"眼皮子底下"的并行监控点 [L2]。
- **忘收金币 = 当天收入 0** 是最狠的一条:惩罚不是数值减少,而是劳动成果清零感,迫使玩家把"收钱"内化为肌肉记忆节拍 [L2]。
- 干扰型角色按天数投放(第 10 天乞丐、第 20 天小偷),等于在玩家基础循环熟练后**注入新的注意力税**,且随天数升高频次上升(后期小偷"三四秒来一次"为半升级状态的夸张说法)[L1-L2]。

## 5. 升级与自动化树 ⭐

### 5.1 自动化引入顺序(社区共识排序)
多方攻略高度一致 [L2-L3]:

1. **前期(约 1~10 天)**:先靠"橙汁+地瓜"攒钱(操作简单、客单价高)→ 升**切肉刀+土豆机**(提速,仍手动)。
2. **第一台"真自动化"**:**送老头出国留学(2100 金币)**→ 老头从"睡觉的垃圾桶"变成自动补货员(酸黄瓜、沙拉酱、橙汁、番薯自动补充)。几乎所有攻略把它列为**性价比第一、最优先**——补料是最琐碎、最无决策含量的劳动 [L2-L3]。
3. **中期**:卷饼皮+包装机升级(点击次数 3→2→1)→ 自动包装 → 饮料机杯子升级 → 饮料机 3 级=自动化 → 削土豆/炸薯条一步到位自动化 → 自动切肉。
4. **后期**:烤盘(要么不动要么攒钱拉满,满级 6800 金,容量 6+不烤糊)、监控拉满(小偷绝迹+硬币自动拾取)、装修扩张(提客流与客单价)、价格升级、自选配料(自选难度)。

### 5.2 自动化的规律(按社区优先级反推的"痛点解决顺序")
1. **先消灭纯重复无决策劳动**(补料、包装、削土豆)——玩家最先受不了的是"没有任何选择的点击";
2. **再消灭等待型劳动**(自动切肉、自动炸薯条——掐时机的活);
3. **再消灭注意力税**(监控=小偷消失+金币自动收,相当于"把惩罚机制整个买断");
4. **最后才买"给自己上强度"的内容**(自选配料、多口味)——自动化完成后的自嗨内容。

### 5.3 自动化后玩家剩什么?(新瓶颈的制造)
- 全自动后玩家剩余职责:**看单装配(选配料组合)、交付、防突发(未拉满监控前的小偷/乞丐)、以及升级/定价策略**。装配组合本身始终手动——即"识别+组合决策"不可外包,这与本项目"机器人量产、玩家保留关键决策"的张力完全同构 [L2 归纳]。
- 自动化不断**把瓶颈推向下一个站**:切肉自动了→包装变瓶颈→包装自动了→收钱/小偷变瓶颈→监控拉满→玩家只剩装配。教科书式的"瓶颈迁移"设计 [L2 归纳]。
- **半升级陷阱(反模式,但值得注意)**:烤盘 1~2 级更易烤糊;监控只升 1 级小偷反而更频繁。社区结论:"**要么不升,要么一步拉满**"——升级体验有断层坑,本项目的准则 3(体感断层)应吸取其教训:中间档必须也是纯收益或明显改观 [L2-L3]。

### 5.4 体感断层(升级前后的可见差异)
- 老头:睡觉吃白食 → 站起来满场补货(画面与流程双断层,2100 金最优投资的原因)。
- 饮料机 3 级:拖杯接饮料 → 杯子自动出现(操作整段消失)。
- 监控满级:小偷从画面绝迹 + 桌上金币自动入账。
- 烤盘满级:容量 6 + 永不烤糊(从"最危险"变"最省心")。
以上均为 [L2](多攻略描述的画面/流程变化一致)。

## 6. 菜单解锁与复杂度曲线

| 时间 | 解锁 | 同时带来的 |
|---|---|---|
| 开局 | 基础卷饼(肉+饼+基础配料) | 核心循环 |
| 前期(花钱) | 橙汁、地瓜/红薯 | 收入↑,操作简单(社区称"攒钱神器") |
| 中期(花钱) | 薯条+番茄酱 | 收入↑,新增一条可预制工序线 |
| 第 19~20 天 | 可乐机 | 收入↑,新增即时饮料线 [L2] |
| 中后期 | 石榴糖浆、自选配料、多口味卷饼 | 收入↑↑,但组合爆炸、难度自选 [L2-L3] |

规律:**每个新菜品=新收入×新工作站×新订单组合数**,且**高价高利的解锁往往伴随最高操作成本**,玩家可以(部分)选择不买来控制难度(见 4.3 的"不点口味科技"流派)——复杂度是**可购买的、自选的**[L2]。

## 7. 变现设计

- **Steam**:23~27 元买断,无内购无广告;好评率约 82%"特别好评",玩家梗:"手游广告里那种游戏被真做出来了" [L3]。
- **国际手游**:免费下载 + IAA(激励广告)。大量第三方"无广告版/破解版"的存在反证正版广告密度不低;速通帖提到"额外 50% 收入"(疑似看广告或成体系的收益加成)[L1,具体广告点位未能文献确认 → 标注待实机]。

## 8. D1 体验弧(资料推断,均标注)

- **0~10 分钟(D1~D5 左右)**:只有卷饼主链。教学式极简:切肉→饼→料→烤→包→给。单日 2 分钟,一天能玩十几个游戏日 [L2]。
- **第一次"忙不过来"**:大概率在**第 10 天乞丐解锁 + 顾客并发上来**之后——主链尚未自动化、又添"给乞丐薯条+揍他"的分支注意力 [推测:乞丐 10 天/小偷 20 天为 L2,首个忙不过来点为基于解锁表的推断]。
- **第一次"理顺了"**:攒到 2100 金**送老头出国留学**后——补料全自动,玩家第一次感到"有人替我干活"。社区把它列为第一优先的事实说明这是最普遍的爽点锚 [L2]。
- **中段**:每次自动化把瓶颈推向下一站,"忙不过来"与"理顺了"以 1~2 天为周期交替,直到监控拉满、烤盘满级后进入"装配 + 数钱"的收尾期,复杂度选择权(自选配料)交给玩家 [L2 归纳]。
- 通关约数十天(现实数小时);TapTap 投票显示 52% 玩家日入 500+ 金币(后期) [L1-L2]。

## 9. 对"自动化编排机制"的设计启示(纯事实归纳,对照本项目四准则)

1. **自动化按"劳动的决策含量"分层接管,而不是按工序顺序**:零决策劳动(补料/包装)最先自动化,时机判断其次(炸/切),注意力监控第三(防小偷/收钱),**组合决策(看单配料)永不自动化**。对应张力表述:"机器人扫得越多,玩家每一步手动越必须是机器人做不了的事"——沙威玛把这条执行到了"只剩装配"。
2. **压力=工序数×并发×注意力税,自动化逐项做减法,但总量守恒**:每自动化一站,并发和干扰上升把压力补回来(菜单解锁+顾客增多),玩家始终处于"忙"与"顺"的窄通道——这正是心流报道("停不下来")的机制根源 [L2]。
3. **可预制囤货是自动化的前置结构**:薯条/切肉可闲时备料,意味着"忙时压力"可以被"闲时劳动"对冲——给玩家的编排策略留了空间(先炸几份再开张),本项目机器人的"调度优先级"可直接类比。
4. **惩罚要"看得见、归自己"**:忘收钱=当日收入 0、烤糊=报废、小偷=亲眼偷走——所有损失都发生在玩家眼前且归因于自己没注意到,而非数值暗削。注意力税的公平性来自可见性 [L2]。
5. **升级的"一步到位"原则(反面教训)**:半升级反而加压(烤盘 1~2 级、监控 1 级),社区结论"要么不升要么拉满"。本项目准则 3(体感断层)应定义为**每档都是纯增益的断层**,避免沙威玛式的中间档陷阱。
6. **复杂度可以作为商品卖、且允许玩家拒买**:"不点口味科技"流派证明把组合爆炸做成可选购买,既服务收集党又保护效率党——本项目的机器人/关卡机制也可做"自选压力档"。
7. **单屏无移动≠低压力**:它用四个并行监控点(烤盘/钱堆/小偷/乞丐)替代了走动压力,证明"编排压力"可以在纯点击空间里做满——对微信小游戏(小屏、低操作精度)是直接利好。
8. **第一台自动化的定价与投放位置定义 D1 记忆点**:2100 金"老头留学"是全体玩家的共同记忆锚——第一件自动化必须(а)画面断层极强(睡觉→干活)(b)接管最琐碎的劳动(c)价格需 1~2 个游戏日的攒钱目标 [L2]。
