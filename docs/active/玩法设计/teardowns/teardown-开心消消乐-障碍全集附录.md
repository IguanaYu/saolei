## 2. 存在性弱确认/未检得规则的线索

- **圣诞袜、南瓜、竹子、雪堆、布谷鸟**:多轮定向检索(4399/九游/小米/太平洋/TapTap/萌娘)均无专门条目。圣诞袜/南瓜大概率是**节日限定关卡皮肤化障碍**(规则复用"周围消除 N 次"模板)[推测];竹子/雪堆/布谷鸟存在性本身未获来源支持,暂记"未检得,疑似口口相传的别称"(如雪堆=雪块别称、独眼怪=大眼仔别称、布谷鸟疑与鸡窝/闪电鸟混淆)[推测]。

## 3. 五族分布统计表

| 族 | 成员数 | 代表机制 |
|---|---|---|
| A 禁止族 | 8(牢笼、灰毛球、褐毛球、黑毛球、银币、魔法藤、绳索、木箱、蜂蜜黏附) | 禁交换/覆盖/分割;高级形态附"必须用特效"的工具强制 |
| B 重复族 | 18(冰块、雪块、云层、宝石、鸡窝、魔法冰柱、魔法石、萌豆、气鼓鱼、封印石板、染色宝宝、星星瓶、木桩、荷花苞、魔法罐、重力磁场、花藤、蛋糕、蘑菇、大眼仔) | "围绕它消 N 次"是全游戏最大的机制家族,常带充能→释放的 B→E 兑换结构 |
| C 路线族 | 9(金豆荚、飞碟、蜗牛、传送门、传送带、移动地板、魔法阵、钥匙锁链、翻转地格) | 强迫通道/顺序;演化方向是"每步自动改变棋盘拓扑"的动态棋盘 |
| D 再生族 | 5(毒液+章鱼、流沙、含羞草、树叶、黑毛球跳跃) | 不作为即受罚;后期变体是"打掉 A 才生成 B"的二次污染 |
| E 有益障碍 | 9(道具礼盒、雪怪、海洋生物、大眼仔、闪电鸟、染色宝宝、星星瓶、花团、萌豆) | "假障碍"=付费/操作奖励内嵌进棋盘,B 族充能后兑换自动效率 |
| F 其他/待定 | 6(水晶球、翻转地格※、魔法阵※、染色蛋、石门、金花+节日限定) | 随机变色与时序翻转是四族外的新维度 |

※ 翻转地格/魔法阵兼具 C 与 F 性质。

**四族之外的新类型观察**:①**随机信息族**(水晶球每回合变色)——约束的不是操作而是"计划的可能性",玩家无法做超过 1 步的规划;②**动态棋盘族**(传送带/移动地板/翻转地格/魔法阵)——棋盘拓扑本身按回合数变化,可勉强归 C(强迫适应路线)但烈度更高;③**二次污染链**(木桩→树叶→金花、蜂蜜罐→蜂蜜)——D 族的"惩罚"从每步蔓延改为"破障奖励触发新障碍",把再生从时间轴移到因果轴。若为扫雷增量项目借鉴,B 族的"充能→释放"与 E 族"假障碍"是最值得复用的两个结构。
