# 设计简报:玩法解构与扫雷机制设计

> 生成于 2026-08-22。本文是本轮"解构消消乐/沙威玛 → 设计扫雷小机制"工作的总纲,
> 后续所有 teardown 和机制分析都回溯到这里的战略张力。

## 1. 设计目标类型

- **做新功能(主)**:为现有"扫雷 + 机器人"核心循环设计一批小机制——操作约束型(消消乐式)+ 自动化压力型(沙威玛式)
- **学习参考(辅)**:沉淀一套"解构任意游戏玩法机制"的可复用方法论

## 2. 平台与品类

- **平台**:微信小游戏(见 P0改造方案-微信小游戏体感.md)
- **显性品类**:休闲益智(扫雷)× 增量放置
- **隐性混合**:扫雷推理 + 机器人供应链编排 + 局外增量成长
- **参考类型**:三消休闲(操作约束机制)、烹饪/烤肉模拟(自动化编排压力)、放置挖矿(增量成长曲线)

## 3. 核心体验目标

- **主导动机**:Achievement(力量、成长)为主,Mastery(策略)为辅
- **核心情绪**:**爽快**(机器人左右开弓、格子成片揭开、数字飙涨)+ **成长满足**(从手忙脚乱到流水线自动化)
- **反情绪**:烦躁(手忙脚乱劣化为重复劳动)、被坑(纯随机惩罚)、无聊(纯观看、没有参与感)

## 4. 商业约束

- **变现**:IAA 激励广告为主 → 机制偏向短循环、高频正反馈,每个广告点都是"解决当下痛点"
- **受众**:休闲大众(扫雷有国民认知度,但硬核扫雷玩家极少)
- **体感**:微信小游戏标准体感(短会话、随时可停、低操作精度要求)

## 5. 战略张力(最重要)

### 手动掌控 × 自动效率

- **来源**(用户原话):"扫雷本质不依赖机器人也可以做到,但核心想法是扫得更快,机器人左右开工""更多的事忙不过来,所以需要机器人"
- **目标象限**:偏自动效率的中间带——机器人承担量产,玩家保留关键决策手(破局、模糊推理、编排调度)。类比沙威玛:自动化解决重复劳动,但玩家仍是流水线的瓶颈处理者
- **掉单极的后果**:
  - 只握"自动效率" → 观看式放置,扫雷玩家的身份感/技巧感消失,爽快失去来源
  - 只握"手动掌控" → 机器人是摆设,增量成长线失去意义,退化为普通扫雷
- **张力表述(后续所有分析引用)**:
  > 机器人扫得越多,玩家的每一步手动操作就越必须是机器人做不了的事。

## 7. 维度侧重

- **gameplay-loop(主)**:机制深度、节奏、循环分解
- **feature-benchmark(主)**:操作约束机制横向对比(消消乐系)、自动化编排机制横向对比(沙威玛系)
- uiux(辅):小游戏体感下的操作成本

## 8. 项目硬性设计准则(P14 brainstorm 定下,所有新机制必过)

1. **决策改变(否决项)**:机制必须改变玩家决策,不只是数字更大
2. **可交互(否决项)**:机制必须能被玩家行为影响——能应对/预防/利用
3. **体感断层(质量分)**:升级前后要有肉眼可见的画面差异
4. **聚焦核心(质量分)**:强化"扫雷+挖矿+机器人编排"循环,不开无关分支

## Framing Principle

本游戏的灵魂张力是**"手动掌控 × 自动效率"**:机器人负责量产扫雷,玩家负责机器人做不到的事。
每个新机制必须同时回答两个问题——
(1)它如何制造"忙不过来/不敢乱点"的**压力**(消消乐式操作约束);
(2)机器人或玩家升级后,如何**用新方式化解这种压力**(沙威玛式自动化编排)。
只制造压力不给出路 = 挫败;只给自动化不制造压力 = 无聊。
