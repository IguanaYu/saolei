# 玩法解构方法论 v1

> **本项目玩法设计最高准则(2026-08-22 起,用户确认)**:后续所有玩法设计——新机制/新关卡规则/新升级/新敌人/新特殊格子——一律以本文为准。新机制必须过 §5 验证四问;添乱者实体必须过 §4 压力源设计六问。修订本文须更新版本号并记录变更,不静默改。
>
> 来源:从消消乐(操作约束)与沙威玛传奇(自动化编排)的拆解中提炼,2026-08-22。
> 证据标签:(T-消) = teardowns/teardown-开心消消乐.md,(T-沙) = teardowns/teardown-沙威玛传奇.md。
> 用途:给任意一款游戏,按这套流程把它的机制拆成可复用的设计零件。

---

## 0. 一句话核心

**机制 = 对核心操作(或核心资源)的定价。操作本身永不变,变的是价格。**

- 消消乐 60 余种障碍,没有一种改变"交换相邻两格"本身,全部作用于这次操作的**位置、次数、顺序、可用工具**(T-消 §9.1)
- 沙威玛的每个工作站/升级,没有一种改变"点击一个工位"本身,变的是每次点击的**收益、等待、风险**(T-沙 §5)

解构一款游戏 = 找到它的"原子操作",然后列出这游戏给这个操作定过的所有价格表。

## 1. 五步解构流程

### Step 1 — 找原子操作

问:**玩家每 30 秒重复的那个唯一动词是什么?**

| 游戏 | 原子操作 | 备注 |
|---|---|---|
| 消消乐 | 交换相邻两格 | 一次滑动,结算极大(自动连锁) |
| 沙威玛 | 点击一个工位 | 单屏无走动,全是点击调度 |
| 扫雷(我们) | 开格 / 标雷 / 和弦 / 指挥机器人 | 注意:我们有 4 个原子,且多了"信息"这个资源维度 |

判断标准:如果一句话说不清原子操作,这游戏的核心循环还没凝练好。

### Step 2 — 列操作的"可定价维度"

对每个原子操作,问它有哪些维度**可以被机制修改**:

- **位置** — 这个操作允许发生在哪
- **次数** — 这个操作要重复几次才生效
- **顺序** — 这个操作必须排在别的什么之前/之后
- **工具** — 这个操作允许用哪些手段(有的手段被禁/被降档,有的专属)
- **时机** — 这个操作拖过某个时间点会怎样

再加两个**资源维度**(不是所有游戏都有,有就是富矿):

- **信息** — 玩家做操作时看得见多少(扫雷的数字是隐藏信息的显影;消消乐没有这个维度)
- **注意力** — 需要玩家同时盯几件事(沙威玛的钱堆/小偷/烤盘/乞丐四个监控点)

### Step 3 — 减法定价:约束四族(来自消消乐)

| 族 | 约束什么 | 消消乐成员 | 扫雷对应 |
|---|---|---|---|
| **A 禁止** | 禁止在某位置执行操作 | 牢笼、毛球、蜗牛 | 锈锁格(玩家禁开,机器人特解) |
| **B 重复** | 强迫对同一位置操作 N 次 | 冰块、雪块、蘑菇 | 岩壳格(两次开格) |
| **C 路线** | 强迫操作沿特定通道/次序 | 传送门、金豆荚、藤蔓叠放 | 矿车轨道(在指定列开格推进) |
| **D 再生** | 不作为即受罚,每步隐性征税 | 毒液、流沙、黑毛球 | 蔓延尘雾(定期吞掉已开的数字) |

关键观察(T-消 §3.18):**四族全部是对原子操作做减法,操作本身恒定**。雪块的高明在于它同时降档了玩家的最强工具(特效只消 1 层)——**工具降档是比位置禁止更高级的约束**。

### Step 4 — 加压定价:压力四源(来自沙威玛)

约束是静态的税,压力是动态的速率。问:**什么在逼玩家把原子操作做得更快?**

| 压力源 | 沙威玛的实例 | 机制本质 |
|---|---|---|
| **时间** | 顾客耐心条、烤糊、日倒计时 | 资源会自己变坏 |
| **顺序** | 切肉→饼→料→烤→包→交付;薯条可预制 | 工序链 + 可预制囤货的编排空间 |
| **并行** | 多顾客并发 × 配料组合爆炸 | 需求同时到达 |
| **注意力** | 钱堆忘收=归零、小偷、乞丐 | 隐形的监控税 |

两条铁律(T-沙 §9):

- **压力总量守恒**:每自动化一站,新内容(菜单/客流)把压力补回来,玩家始终在"忙↔顺"窄通道里。压力不是要消灭的东西,是要维持在心流带宽的东西。
- **可预制囤货是编排策略的前提**:忙时压力能被闲时劳动对冲,玩家的调度才有意义。

### Step 5 — 救赎路径设计(两款游戏共同的秘密)

**每个约束都必须内嵌一条"兑换出口":接受约束的代价,换一段自动效率。**

- 消消乐:雪怪(消四周冰柱→自动清障)、魔法石(周围消 3 次→持续释放)、星星瓶(攒满→强力释放)——"先吃 B 族约束,后兑换自动效率"的直兑换结构(T-消 §3.11-3.13、§9.2)
- 沙威玛:整个升级树就是救赎目录——2100 金送老头留学(补料全自动)、监控拉满(小偷绝迹)(T-沙 §5)

反向同理:**每个奖励都必须用操作定价**。消消乐的特效不是随机掉的,是玩家摆出 4 连/5 连/L/T 型"买"来的;两个特效组合还要**再花一次手动交换去点燃**——"自动效率必须由一次手动操作点燃"(T-消 §5)。

## 2. 自动化的分层律(当游戏有自动化时)

自动化不是"替玩家玩",是**按劳动的决策含量从低到高逐层接管**(T-沙 §5.2):

```
决策含量:  零决策劳动 → 时机判断劳动 → 注意力监控 → 组合决策
接管顺序:  最先自动     其次           再次         永不自动
实例:      补料/包装    自动切肉/炸薯条  监控/收钱     看单装配
扫雷对应:  opener/marker确定性开标  detector验证  充能塔补能   模糊推理/破局(玩家)
```

配套规律:

- **瓶颈迁移**:每接管一层,瓶颈移到下一层。这不是 bug,是节奏引擎——升级的体感断层就来自"瓶颈换位置了"(T-沙 §5.3)
- **第一台自动化 = 全体玩家的记忆锚**:必须(a)画面断层极强(老头:睡觉→满场跑)(b)接管最琐碎的劳动(c)定价为 1-2 局的攒钱目标(T-沙 §9.8)
- **半升级陷阱(反模式)**:沙威玛烤盘 1-2 级反而更易糊,社区结论"要么不升要么拉满"——中间档必须也是纯增益(T-沙 §5.3)

---

## 3. 引入节奏律

- **约束烈度梯度**:温和的(重复/路线)先出,烈性的(禁止/再生)大幅后置。消消乐:冰块第 8 关→雪块 16 关→毛球 106 关→黑毛球 241 关(T-消 §8)
- **组合替代新机制**:长线难度靠"约束族的笛卡尔积"(单关混装 3 种障碍),不是无限发明新机制。这是消消乐 9000+ 关的内容产量来源(T-消 §9.5-9.6)
- **复杂度可购买可拒买**:沙威玛"不点口味科技"流派——把组合爆炸做成玩家自选的压力档,同时服务收集党与效率党(T-沙 §6)

## 4. 压力源设计六问(添乱者清单)

适用于任何"会主动找麻烦的实体"(虫群/小偷/毒液/敌人)。2026-08-22 从虫群机制设计中提炼。

| 问 | 判定 | 依据 |
|---|---|---|
| **① 伤什么?** | 伤害标的选择:抽象分 < 经济 < 劳动成果 < 信息显示。痛感必须"看得见、归因自己" | 沙威玛铁律:忘收钱=归零而非暗扣(T-沙 §9.4) |
| **② 从哪来?** | 无源随机掉落=不可预防(准则 2 不及格);有巢/裂缝=可清剿可绕行 | 毒液有章鱼(T-消 §3.5) |
| **③ 谁免费治它?** | 机器人应有**不可靠的默认解**(路过顺带消灭),可靠解必须**花钱买断**(哨兵塔/监控拉满) | 免费的全自动解会杀死整个机制(张力崩向自动极) |
| **④ 玩家怎么治它?** | 至少两档:**指挥档**(1 下标记,机器人优先处理)+ **亲自档**(连点 3 下,紧急下场)。玩家手动=编排优先,打工最后 | 张力轴:"玩家做的必须是机器人做不了的事" |
| **⑤ 什么节奏来?** | 持续掉落=噪音麻木;**脉冲波次**(20-30s/波),波间留纯主线窗口 | 忙↔顺交替的窄通道(T-沙 §9.2) |
| **⑥ 能碰哪层?** | 棋盘真值(雷位/数字/已开真实性)=**绝对禁区**;可碰层枚举:标记物(吃旗/假旗)、显示层(遮数字)、经济层(偷矿)、劳动成果、进度物(矿车)、机器人(停工,烈度最高后置) | 数字恒定不变量的推论 |

第 ⑥ 问的深层版:压力源攻击的往往是**人机协作协议**——旗子是玩家与 marker/detector 之间的通信接口,吃旗/假旗攻击的是接口本身,比抢注意力带宽更深地拥抱核心玩法。

## 5. 验证四问(进入实现前的过滤器)

1. **决策改变**:这个机制让玩家面对同一局,会做出和以前不同的选择吗?(否决项)
2. **可交互**:玩家能主动改善这个机制的结果吗——能应对/预防/利用?惩罚必须"看得见、归因于自己"(T-沙 §9.4)(否决项)
3. **体感断层**:机制被升级化解的前后,画面/流程有肉眼可见的差异吗?且每档都是纯增益?(质量分)
4. **聚焦核心**:机制是加深核心循环,还是在旁边开了个无关 minigame?(质量分)

## 6. 反模式清单(从两游戏 + 本项目推演)

| 反模式 | 来源 | 为什么有毒 |
|---|---|---|
| 破坏核心不变量(如扫雷中途生雷,数字会变) | 本项目推演 | 摧毁玩家已建立的推理信任,扫雷的数字必须恒定 |
| 纯随机惩罚(雷随机引爆) | 本项目 memory | 违反可交互(准则 2) |
| 忘收就归零的隐形税 | 沙威玛的忘收钱 | 沙威玛靠可见性能勉强成立;休闲小游戏里直接变"被坑感" |
| 半升级更糟 | 沙威玛烤盘/监控 1 级 | 升级必须每档纯增益 |
| 自动化吞噬核心决策 | 推演(沙威玛从不自动化装配) | 自动化碰到"组合决策"层 = 玩家失业 = 张力崩塌 |
| 机制修改原子操作本身 | 消消乐的反面假设 | 操作恒定是 60 种机制共存的前提;改操作 = 换游戏 |

## 7. 套用示范:扫雷挖矿(一段话版)

扫雷的原子操作是**开格/标雷/和弦/指挥机器人**,独有资源维度是**信息**(数字)和**注意力**(多线)。
用约束四族定价操作:A 禁止→锈锁格、B 重复→岩壳格、C 路线→矿车轨道、D 再生→蔓延尘雾;
用压力四源加压:时间→倒计时矿脉(烤糊的同构)、注意力→尘雾、并行→多矿脉窗口;
每个约束配救赎:岩钻(机器人一次破壳)、支撑柱(延长矿脉窗口)、防尘升级、矿车直达;
自动化分层已有雏形(opener/marker 管零决策,detector 管验证),**模糊推理永不自动化**,反而给玩家发"破局钻头"加深手动极。
引入顺序按烈度梯度排进 12 章,长线靠组合(岩壳+轨道、尘雾+倒计时)。
