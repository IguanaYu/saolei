# 机器人与敌人微动画设计 v1

> 日期：2026-10-02  
> 状态：已直接接入实际项目 `E:\godot\扫雷`，九角色场景与暂停／退场检查通过；见[图片交付说明](美术生产/机器人与敌人微动画-图片交付-v1.md)。  
> 用户要求：每种角色一个简单的轻微循环，像保安两个灯交替亮那样；钻机在动就够了。

## 设计方向

**一个角色，一个局部循环。** 用现有造型，只让最有辨识度的小部件动起来。整台角色保持稳定，动画持续轻轻播放，不区分待机、移动、工作，不新增专门的履带、开火、采矿或卸货动画。

## 制作清单

| 角色 | 唯一动画 | 动作设计 |
| --- | --- | --- |
| 开凿机器人 | 钻头轻转 | 钻头上的亮暗纹路交替，产生旋转感觉；钻头安装点和机身固定 |
| 标旗机器人 | 小旗轻摆 | 旗杆固定，旗端左右轻摆，隔一小会儿摆一下 |
| 探测机器人 | 探头扫描 | 亮点在顶部圆形探头内部来回扫，探头外形固定 |
| 矿工机器人 | 前端工具轻动 | 沿现有前端工具做一个小幅往复，像钻机轻轻运转；机身和背斗固定 |
| 保安机器人 | 两灯交替 | 延续用户喜欢的灯光感觉，让它持续交替；不叠加其他动作 |
| 织网虫 `web` | 附肢轻动 | 身体中心固定，两侧附肢微微收拢、张开 |
| 锁匠虫 `lock` | 锁齿起伏 | 背部突起轻轻升降一次，主体固定 |
| 减速虫 `slow` | 慢蠕动 | 身体上沿慢慢鼓起、落下，底边固定，感觉偏黏稠 |
| 史莱姆 `slime` | 轻呼吸 | 上半身轻鼓起、塌回，底边固定，比减速虫稍有弹性 |

先做以上 9 种。保安复用已有动画感觉，小敌人优先调整已有两帧，只有动作不足时补一帧。四台基础机器人则补最少的局部变化帧。

其他敌方元素可后续各补一个同样简单的循环：虫巢只让洞内亮点缓慢亮暗；大 Boss 只让口部或腹部轻呼吸；触手只让根部亮芯微亮暗。先看第一批放进棋盘后的效果，再决定是否补这些。

## 强度与节奏

- 常驻动画以 2–3 帧为主；机身、脚底和安装点不动。
- 钻头、工具先试每 0.25–0.35 秒切帧；灯光先试每 0.6 秒交替；旗摆和敌人呼吸约 1.5–3 秒一轮。均为设计初值，以游戏里自然、轻微为准。
- 同类角色错开循环起点，避免一排一起闪、一起鼓起来。
- 保持现有颜色，亮点只留在部件内部，不增加大光晕；扫雷数字始终清楚。
- 暂停、教学冻结、结算时同步停住；现有出场、死亡、Boss 出招等表现优先，简单循环不能覆盖它们。

## 资源与验收

当前运行图来自 `visual_v2/runtime/`。已用 PIL／NumPy读取：机器人画布为 24×24、小敌人为 22×22；四台基础机器人的现有移动图各只改变了履带上的 2 个像素。本次制作优先改变角色识别部件。

保持现有画布、基准点和最近邻采样。新增帧先检查透明边界、变化区域和固定锚点，再看真实棋盘中的连续片段；像素范围以工具实测为准。本次按用户要求在实际项目直接修改，已执行 Godot `--headless --editor --import --quit`。

验收只抓三件事：**小部件看得出在动；机身稳定且不遮数字；暂停和角色退场后没有残留循环。** 九角色实际场景的帧尺寸、循环、暂停／恢复和死亡清理已通过运行检查，棋盘上的具体观感由试玩确认。

## 调研参考
