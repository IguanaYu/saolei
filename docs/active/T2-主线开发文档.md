## 一、T2 是什么

T1 已完成基础玩法（扫雷 + 4 种机器人自动化 + 局外矿石 + 升级树），但缺少微信小游戏留存的核心循环——**"打不过 → 退出升级 → 回关碾压 → 再卡再升"**。T2 的使命就是把这套循环做出来。

### T1 → T2 状态对照

| 维度 | T1（已完成） | T2（进行中） |
|---|---|---|
| 玩法循环 | 90s 单局冲分 | 关卡章节（60 关 / 12 章 / Boss） |
| 升级感知 | 每级 +10-25%（弱） | 偏量养成（每级 2-3 项提升，质变感） |
| 解锁链 | 矿石一次性买断，并列孤立 | 嵌套解锁链（用 A 触发 B 需求） |
| 失败反馈 | 仅"矿石÷10"基础层 | 三层失败激励（基础 + 近失 + 连续补偿） |
| 心理学应用 | 无 | Hook 模型 / 目标梯度 / 近失效应等 |
| 单局时长 | 90s 固定 | 60-180s 关卡化配置 |

### 单局时长决策（已确认）

**90s 起步，180s 上限，关卡级别独立配置**。

P13 落地时已把 `time_limit_sec` 写入每个 `LevelData`，`game_state.gd:9` 的 `90.0` 只是 fallback（关卡模式不会用到）。每关按节奏规划：

| 关卡位置 | 时长 | 用途 |
|---|---|---|
| 教学关（章首 1-2 关）| 120-150s | 给学习留空间 |
| 普通关 | 90-120s | 标准节奏 |
| 限时冲分关 | 60-90s | 紧张感 |
| Boss 关 | 75-120s | 高强度 |

## 四、P14 偏量养成（下一个 Sprint，详细方案）

> 完整方案：[P0改造方案-微信小游戏体感.md §3](P0改造方案-微信小游戏体感.md#3-p02-偏量养成升级质变)

### 问题诊断

当前 `game_state.gd:201-208` 的 `get_speed_interval` 是 `+25% / +33%` 的速度提升，玩家几乎无感。`save_system.gd:10-20` 的局外升级（start_money / start_lives / global_speed / expand_zone / start_robot）也是每级 +10-25% 弱感知。

### 偏量养成原则

每次升级捆绑 **2-3 项提升**，让玩家在升级面板看到"3 项变化"而不是"1 项 +X%"。

### 改造后的升级表（节选）

**opener 觉醒（3 级，质变化）**：

| 等级 | 当前 | 新设计（偏量） |
|---|---|---|
| Lv0 | 2.0s | 2.0s |
| Lv1 | 1.5s（-25%） | **1.4s + 范围 +1（可开 8 邻格的安全墙）** |
| Lv2 | 1.0s（-33%） | **0.8s + 一次开 3 格 + 链式连锁深度 +1** |
| Lv3（满级质变）| — | **0.5s + 一次开 5 格 + 概率触发"开格 +1 钱"** |

**起始金币（5 级）**：

| 等级 | 当前 | 新设计 |
|---|---|---|
| Lv1 | 100 | 100 |
| Lv2 | 110（+10） | **130 + 送 1 个 opener** |
| Lv3 | 120（+10） | **170 + 送 opener + marker** |
| Lv4 | 130（+10） | **200 + 送双机器人 + 起始预开扩一圈** |
| Lv5 | 150（+20） | **250 + 全套 + 自动建第一个基地** |

完整表见 [P0改造方案-微信小游戏体感.md §3.3](P0改造方案-微信小游戏体感.md#33-改造后的升级表)。

### 实施要点

1. 扩展 `UpgradeDef`（如有）支持 `effects: Array[Dictionary]` 多效果
2. 改造 `save_system.gd` 的 `unlocks` 字段升级上限（部分 2→3 或 2→5）
3. 改造 `game_state.gd:reset_state` 应用多 effects
4. 升级面板 UI 显示多行效果（"⚡ 速度 +30% / 🎯 范围 +1 / ✨ 新增连锁深度"）

### 验收指标

| 指标 | 目标 |
|---|---|
| 升级面板平均停留时间 | ≥ 30s（玩家在权衡） |
| 升级后回头通关率 | ≥ 60% |
| 试玩反馈"感觉到变强" | ≥ 3/5 玩家 |

| "解锁系统期待感" | 60% 解锁后使用 | 解锁后使用率 |
| "失败后再试" | 50% 近失玩家重玩 | 近失后重玩率 |
