## 1. 实现

| 卡点(调研 §3.1) | 处置 |
|---|---|
| init_empty_grid 矩形双循环 | 加 `Grid.shape_rows`(行字符串掩码,'1'=有格 '0'=洞)+`shape_has()`;空掩码=矩形原路径 |
| 布雷候选矩形枚举 | `MapGenerator.generate_excluding` 加 `shape_mask` 可选参数:候选与数字循环都只算掩码内格——**雷数守恒**(雷不落洞被丢弃),数字天然正确(雷全在形状内,邻计数不受洞影响) |
| 盘边取点(巢/Boss) | s07 不配虫害/Boss,整类绕过;`_in_bounds` 已在前序提交改为 `grid.cells.has`(天然形状无关) |
| 视觉边框矩形 | CaveEnv 掩码模式下**逐格逐边拼段**(形状内格检查四邻,缺侧画 FRAME_T/B/L/R 段,拐角自然交汇);L 形 64 段 |

**数据链:** `LevelData.shape_mask` → main 赋值 `grid.shape_rows`(duplicate,普通关默认空数组零影响)→ configure 建格。

CLEAR_ALL_SAFE 打折线 115/155(74%),200s,玩家自放基地(洞区被 cells.has 拒绝),数值原型占位。

**下游零改动验证:** 邻居/洪水/Solver/寻路/胜负/探测全部 cells.has 驱动(调研 §1.5 结论兑现)——
