# 弹窗按钮顺序排查清单 v1（2026-10-03）

## 结论与规范

- **规范（用户拍板 2026-10-03）**：确认/主操作按钮在**左**，取消在**右**——Windows PC 惯例（[确定][取消]、[是][否]、[退出][取消]）。
- macOS/移动端才是"取消在左"，本项目原先误用了移动端排法。
- 全项目同类问题**只有一处根源**：共用组件 `scenes/ui/ConfirmDialog.tscn`，已修复（对调 CancelButton/ConfirmButton 节点顺序），9 个调用点一次全部生效。
- headless 验证：`tmp/test_confirm_order.gd` → PASS（确认在左、取消在右）。

## 三、后续守则

- 新增确认/成对按钮时一律：**主操作在左、取消在右**；已在 `confirm_dialog.gd` 头部注释记录，勿改回。
- 若做移动端移植再考虑按平台翻转（macOS/iOS 取消在左）。
