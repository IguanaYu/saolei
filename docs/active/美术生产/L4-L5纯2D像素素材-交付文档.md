## 二、交付文件与复现方式

- **运行素材**：`visual_v2/runtime/boss/`、`enemies/`、`robots/`、`tiles/overlays/`、`fx/`、`ui/icons/`。
- **整套预览**：`visual_v2/review/l4_l5_sprite_sheet.png`。
- **可重建源脚本**：`visual_v2/build_l4_l5_sprites.py`。在项目根目录 `saolei` 运行 `python visual_v2/build_l4_l5_sprites.py`，会重建本批 PNG 和预览图，不改动原有棋盘、背景或四台基础机器人素材。
- **造型参考**：`visual_v2/source/boss_concept_sheet.png`，只用于 Boss 设计参考，不被游戏加载。概念稿由内置 imagegen 生成，提示词核心为“暗紫岩甲、牙形岩刺、琥珀眼、抓住棋盘边缘、七姿态一致、透明 2D 像素画”；正式运行帧由源脚本在原生像素尺寸绘制，以保证帧间比例与格子对齐。

所有运行 PNG 均为 RGBA 透明图。游戏中的 `Sprite2D` 和 `TextureRect` 使用最近邻过滤，避免像素边缘被平滑。新增图片后先让 Godot 完成导入，再运行游戏。
