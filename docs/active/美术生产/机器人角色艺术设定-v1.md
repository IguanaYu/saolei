> 日期：2026-09-28

## 0. 设计总纲（家族公约，五车通用）

1. **工具即角色**：机器人没有脸、没有五官。性格全部由"轮廓比例 + 车身色 + 专属工具 + 动效习惯"表达。它们不是拟人宠物，是一支各司其职的工程车队。
2. **家族设计语言**（统一，制造"同一车队"感）：双履带底盘 · 单体积座舱 · 同色系浅色舱盖 · 钢灰工具件 · 履带统一深灰。
3. **三通道识别**（优先级从高到低）：**剪影 → 车身色 → 工具**。任何新素材（图标/皮肤/宣传图）必须先过"纯黑剪影测试"：涂黑后仍能认出是谁。
4. **尺寸节奏**：刻意错落，合影不许同高——最矮（opener）· 最高（marker）· 附件最大（detector）· 最方厚（miner）。
5. **发光纪律**：只给"职能光"（detector 雷达、miner 矿石），不给装饰灯。光=信息，不是美化。
6. **表面纪律**：车身哑光（rough≈0.75），工具钢件带金属度，磨损/划痕留给贴图阶段。洞窟暖光下不做高反光车漆。

### 车队色彩体系

## 1. opener 开墙型 ——「破城锤」

- **玩法**：打开确定安全的墙。先锋，干最脏最累的活。
- **性格关键词**：厚重 · 埋头苦干 · 不回头。
- **剪影**：全队最矮最宽的楔形 + 车头一根占脸的巨钻。没有脖子没有脑袋，就是一台往前拱的机器。
- **比例**：高 0.55 × 宽 1.0（1 : 1.8），重心压进履带，永远像要往前冲。
- **标志元素与玩法映射**：大战锤钻=开墙方式本身；钻头朝向=它的行进意图，玩家看钻头就知道它要去啃哪面墙。
- **动效建议**：钻头常转（慢速待机）；啃墙瞬间车身前倾 + 高频抖动 + 碎屑迸溅；行走时履带滚动、车身轻微起伏。
- **48px 识别**：橙色矮块 + 一根灰色大尖锥。
- **AI/美术 prompt 关键词**：`low-poly orange mining vehicle, huge front drill, no cabin windows, treads, chunky, industrial, warm cave`

## 2. marker 标雷型 ——「立旗官」

- **玩法**：给确定是雷的墙插旗，立旗为证。
- **性格关键词**：谨慎 · 仪式感 · 有点傲慢的宣告者。
- **剪影**：全队最高（2.9 : 1 的瘦高比例），窄身 + 高杆大黄旗。旗就是它的头。
- **比例**：高 1.45 × 宽 0.5。全队唯一垂直元素。
- **标志元素与玩法映射**：旗=危险标记本身；旗面朝向暴露它下一个目标；棋盘上一面旗=一句"这我包了"。
- **动效建议**：旗面常飘（Godot 顶点动画/骨骼）；插旗瞬间旗杆顿地一沉；转向时旗面滞后甩动（跟随延迟）。
- **48px 识别**：一根杆 + 橙色三角旗，全队唯一"高个子"。
- **prompt 关键词**：`low-poly red robot, tall flag pole with big banner, signal tower, treads, minimal`

## 3. detector 检测型 ——「敢死侦察」

- **玩法**：找旗→移动→检测 3 秒→成功变矿脉 / **失败自爆**。全队唯一会死的车。
- **性格关键词**：神经质 · 敏感 · 悲壮的宿命感。
- **剪影**：中等车身背着一面**比车身还大**的前倾雷达碟。碟是它的全部。
- **比例**：高 1.0 × 宽 0.6，碟直径 0.64 > 车宽——附件大于本体=职能大于生命。
- **标志元素与玩法映射**：雷达碟=检测行为本身；碟面前倾角度=正在工作；它头顶没有旗、身后没有货，只有一台随时陪它殉职的仪器。
- **动效建议**：碟面常速扫描；检测时加速旋转 + 碟面脉动发光；**自爆序列：狂转→红光闪烁→爆**（全队唯一红光时刻——是光不是漆，与 marker 的红漆区分）。
- **48px 识别**：一大片薄荷绿圆盘。
- **prompt 关键词**：`low-poly green rover, oversized satellite dish, scientific vehicle, glow accents, treads`

## 4. miner 矿工型 ——「驮骡」

- **玩法**：采掘→满 20 货回基地卸货换钱。全队的经济来源。
- **性格关键词**：沉稳 · 满载 · 闷声发财。
- **剪影**：厚重方身 + 背后**冒尖的蓝晶矿筐** + 前铲板。像一头驮满货的骡子。
- **比例**：高 0.95 × 宽 0.75，全队最"方"，上下几乎等宽。
- **标志元素与玩法映射**：矿筐=货舱=钱包；**筐里的货量直接可视化载重**（空车→满车蓝晶从无到冒尖），玩家一眼读出"这车赚了多少"。
- **动效建议**：空车轻快、满车车身下沉 + 履带声更沉；行走时蓝晶互相磕碰微动；卸货时整车后倾倒矿。
- **48px 识别**：棕色方块 + 背上青色尖刺。
- **prompt 关键词**：`low-poly brown hauler robot, cargo basket full of glowing cyan crystals, front plow, treads`

## 5. guard 保安型 ——「雇佣枪手」（L4 · 3D 待建，方向提案）

- **玩法**：商店 80 限购 1、花钱买断的清道夫；4 格射程一枪一个（虫>锁>网>黏液）。
- **性格关键词**：冷酷 · 昂贵 · 独狼。
- **设计方向**（与四小强拉开层级）：全队唯一无彩色车身 + 金线装饰（贵）；细长枪管替代工具臂；独眼探照灯替代面罩（唯一保留"眼"的车——因为它是狙击手，眼=准星）；定点站桩姿态。
- **动效建议**：探照灯锥形扫视（搜索感）；开火后座 + 枪口焰 + 弹壳；击杀目标后灯回中。
- **注意**：此为提案，需与 L4 美术现状核对后立项。

## 6. 合影与图标构图约定

- **车队合影**：站位必须高低错落——opener 蹲前、miner 居中、detector 靠后、marker 的旗占据最高点。禁止一字等高排开。
- **48px 图标**：允许做"剪影 + 主色"两色简化版（小地图/头像用），细节全部舍弃只留大形。
- **色彩纪律**：新角色加入时先查本表——暖调橙红棕留给功能车，冷色留给特殊职能，无彩色留给付费单位。
