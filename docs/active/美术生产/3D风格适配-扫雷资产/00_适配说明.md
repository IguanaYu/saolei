# 扫雷资产 × 12 子风格适配说明

> 2026-09-28。同一套 Blender 低模模型（四款机器人 + 水雷 + 旗 + 翻开/未翻开格 + 数字1-8 + 水晶 + 岩石），
> 按《低模卡通3D风格子分类调研》的六轴特征空间逐风格调参渲染，变量只有风格。
> 生成脚本：`tmp/blender3d/build_style_matrix_ms.py`（Blender 5.2 headless，`blender -b -P` 全自动）。

## 实现备注

- 全部程序化生成，无 AI 生图，无贴图文件（S05 的"手绘"是程序噪声双色调，S04 的"二分"是渲染后量化）
- 描边壳用反转法线（`new_from_object` 取评估网格后必须 `materials.clear()`，否则壳继承本体材质隐形——本批踩过的坑）
- S04/S09 是渲染后处理（numpy 三档量化+Sobel / 降采样+限色），如果选它可以再升级为真 shader
- 单件图均为透明底，可直接进 Godot 当 UI 图/宣传图；GLB 导出管线在 `build_assets.py` 里已验证，选定风格后可一键补导出
