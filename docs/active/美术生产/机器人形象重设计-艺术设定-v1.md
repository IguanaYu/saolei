# 方向 A 「蒸汽矿务局」

## 家族语言
- **共同底盘**：黑铁小履带 + 立式铜锅炉（圆柱）+ 黄铜汽包 + 铆钉色环。
- **职能色环**：锅炉中段一圈漆环 = 职能色（橙/红/绿/棕）。家族一致、职能一眼可辨，且**只在环上用色**，其余全是铜铁本色——比现版"整车涂色"更克制、更复古。
- **蒸汽即生命**：所有车都冒汽（待机小汽泡、干活大喷汽），汽量=工作强度，玩家不用看血条就知道谁在卖力。
- **等级感**：越贵重的车黄铜件越多。guard 若加入此线 = 全黄铜车身。

## 四车设定

### A-opener「冲锤七号」
- 剪影：矮宽锅炉 + 车头**蒸汽冲锤**（黄铜活塞杆 + 黑铁方锤头）。
- 性格：直性子老工人，干活只会一招——撞。
- 标志动效：锤头每击一次回收蓄压（活塞杆伸缩可见），配白色蒸汽喷出；开墙瞬间锤头亮橙一帧。
- 48px 识别：铜色矮墩 + 前伸的方锤。

### A-marker「灯塔车」
- 剪影：全队最高，细铁桅杆 + 顶端**红玻璃信号灯** + 锥形灯罩 + 横臂小旗。
- 性格：一丝不苟的信号员，旗语讲究。
- 标志动效：插旗判定时信号灯亮起旋转（灯塔扫射光）；红光=此处有雷的"官方公告"。
- 48px 识别：一根杆顶着发光红点。

### A-detector「罗盘车」
- 剪影：锅炉顶上**大铜环罗盘**（水平悬浮环 + 长指针）+ 侧伸潜望镜。
- 性格：神神叨叨的勘探员，永远在测量。
- 标志动效：罗盘指针平时缓摆；锁定旗子后指针猛地指过去并高频抖动；检测 3 秒=指针画满一圈；自爆=指针疯转到脱出、罗盘碎裂。
- 48px 识别：头顶一个铜环。

### A-miner「矿斗机车」
- 剪影：车尾驮**开口矿斗**（斗里蓝晶可见）+ 后置小锅炉 + 车钩。
- 性格：搬运工气质，走哪都哐当响。
- 标志动效：矿斗货量可视化（空斗→冒尖）；卸货时整个矿斗倾翻。车钩=随时可以"挂钩加车厢"的扩展位（皮肤/升级卖点）。
- 48px 识别：车尾一斗蓝晶。

### 本方向专属氛围
- 音画一体：全队汽笛、金属哐当、锅炉嘶嘶——音效设计空间最大。
- 升级 = 机械改装（更大锤/双灯/更大斗），皮肤 = 不同矿务局涂装（色环换色+徽章）。

# 方向 B 「晶核共生体」

## 家族语言
- **无轮悬浮**：下半是岩石浮座，底部一圈蓝晶辉光缝隙——它们不走路，是**贴地漂行**，全队天然带"非机械"的飘逸感。
- **胸口晶核**：每台胸口一颗悬浮蓝晶=它的"心脏"。核色统一蓝，职能差异体现在**头顶/背上长出的晶体**。
- **岩石质感**：外壳粗粝不规则（顶点扰动），与晶体的规整几何形成"野蛮包裹精致"的对比。
- **世界观钩子**：机器人=蓝晶唤醒的洞窟守护者。开采蓝晶=在收割"同类"的心脏——给 miner 的"驮骡"人设加一层悲剧底色，也让 L3 蓝晶主题关有叙事支点。
- **发光纪律**：只有晶体会发光，岩石永不发光。光=生命/能源。

## 四车设定

### B-opener「破岩者」
- 剪影：双岩拳（各三根晶爪前伸）+ 低伏重心，像一只扑向岩壁的蟹。
- 性格：沉默的力士，话少活重。
- 标志动效：双拳交替凿击；凿击时晶爪亮一下；漂行时身体前倾。
- 48px 识别：两只前伸的晶爪钳形。

### B-marker「警晶哨兵」
- 剪影：头顶一根**红色警示晶柱**（略微歪斜，像刚长出来）+ 一根小侧晶。
- 性格：警惕的哨兵，报险是本能。
- 标志动效：插旗=警晶从岩壳里"生长"弹出（scale-up + 微光脉冲）；红晶脉动频率=危险等级。
- 48px 识别：一根发红光的尖刺。

### B-detector「共鸣者」
- 剪影：**七颗小晶锥环绕身体公转**（晶体星环），胸口晶核最大。
- 性格：敏感的通灵者，靠"听晶体的声音"找雷。
- 标志动效：待机时晶环慢转；检测时晶环加速+逐颗点亮；成功=全环齐闪蓝光变矿脉；失败=晶环炸散（自爆的视觉语言：它的"朋友"先离开）。
- 48px 识别：一圈小亮点围着一颗大亮点。

### B-miner「晶脉采集者」
- 剪影：背上**一座小晶山**（5-7 根锥晶簇），比本体还高。
- 性格：背负者。采得越多背得越高，沉默又悲壮。
- 标志动效：晶山随载货**逐根生长**（0→冒尖的进度条即视觉化）；卸货=晶山"剥落"融入基地。
- 48px 识别：一坨发光蓝尖刺。

### 本方向专属氛围
- 移动不用轮子=**动画体系整体改变**（悬浮摇摆、晶体叮咚声），工程成本最高但辨识度也最高。
- 与 L3 蓝晶关、E2 蓝晶主题天然联动；guard 若加入=被玩家"驯化"的野生共生体（岩壳上有人类加装的金色锁链/铭牌）。

# 方向 C 「圆滚滚齿轮社」

## 家族语言
- **一个圆身一对大轮一只灯眼**：软陶质感的圆胖车身 + 超比例大轮子 + 唯一的圆形灯眼（无嘴无鼻，情绪全靠灯眼：亮=专注、闪=惊、暗=待机）。
- **职能色整车涂装**：延续现版橙/红/绿/棕，但提到糖果饱和度，奶油色轮毂统一。
- **小配件大性格**：每车一件萌化大工具，尺寸夸张到"小孩子戴爸爸的帽子"。
- **物理喜剧**：圆身允许 Q 弹挤压拉伸（squash & stretch），转弯侧倾、急停翘轮。

## 四车设定

### C-opener「钻钻」
- 鼻子就是钻头：圆橙身前伸出一根银钻鼻，思考时钻头小圈空转。
- 动效：开墙=身体拧成麻花蓄力→弹射撞击；轮子扬灰。
- 48px：橙色圆球+银色尖鼻。

### C-marker「小旗手」
- 头顶小旗+旗杆圆帽：插旗时踮轮起立、郑重其事地立旗，旗子比它自己还大。
- 动效：旗面像书包带一样被风带得乱飘；确认有雷时灯眼瞪圆闪红。
- 48px：圆球+旗杆三角。

### C-detector「大眼睛」
- 灯眼升级成**凸出的大圆镜片**（放大镜式雷达眼）+ 小天线。
- 动效：检测=镜片伸出、内部光圈收缩对焦；失败自爆前镜片裂开（全队唯一的"受伤"演出）。
- 48px：圆球+大圆镜片。

### C-miner「背篓工」
- 背着藤编背篓装蓝晶 + 车头小铲板；满载时轮子被压得半瘪（视觉化载重）。
- 动效：走路一颠一颠，背篓里晶体叮当；卸货=原地后翻倒出。
- 48px：圆球+背篓尖刺。

### 本方向专属氛围
- 最适合微信小游戏传播：圆身+灯眼天然适合做表情包/周边；数值反馈（载重/检测）全部萌化演出。
- guard 若加入=戴警帽的圆身巡警，帽檐压住灯眼。

## 推荐与建议

1. **主打推荐 A 蒸汽矿务局**：与现有暖色矿洞+木石UI承接度最高（同一世界观只换"科技树"），职能色环方案比现版更克制耐看，音效设计空间最大，迁移成本中等。
2. **若主打差异化传播选 B**：三方向里辨识度与叙事深度最强，蓝晶世界观一以贯之，但要接受动画体系重做（悬浮）与冷暖色撞车的风险（需把场景暖光压暗一档）。
3. **若主打小游戏 casual 受众选 C**：成本最低、亲和力最高，但"工程车队的专业感"会完全让位给"萌"。
4. 混搭红线：三个方向**不可混用**（蒸汽锅炉+悬浮岩壳=风格灾难）。选定后其余方向的个别点子（如 B 的"警晶生长"、C 的"灯眼情绪"）可作为选定方向内的动效参考，但视觉语言必须单一。
