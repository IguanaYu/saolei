# 低多边形 × 卡通风格：子风格深度调研

> 2026-09-28。起因：Blender 建模预热期，先弄清"低模+卡通"这个大方向下有哪些子分类，再决定走哪条路。
> 参照事件：第一版做的"硬面折纸感"（尖棱+硬光+黑描边+高饱和）vs 参考图的"软陶/玩具感"（圆倒角+柔光+粉彩+无描边）——这个落差本身就是本调研的核心线索。

---

## 0. TL;DR

- 行业没有"官方分类表"，但各家风格指南（pixune 21 种游戏美术风格、aesdes 低模美学论、RetroStyle 低模指南）收敛出的共识是：**"低模+卡通"不是一个风格，而是一个多维特征空间，子风格 = 各轴取值的组合**。
- 你上次踩的坑（5 点差异）恰好就是其中 5 条最重要的轴：**几何处理、描边、光照模型、色彩饱和度、展示语言**。把它们当"旋钮"看，任何子风格都能被坐标化描述。
- 最常用的子风格约 **12 个**（见 §3），其中与"资产目录/游戏道具"最相关的三个大族：**软陶棚拍风**（你的参考图）、**Synty 系平滑卡通**（商业资产包主流）、**折纸描边风**（你的第一版）。

---

## 1. 方法论：子风格 = 特征空间里的坐标点

单看名字会以为"低模卡通"下有几个并列门派，实际调研下来（aesdes、pixune、RetroStyle、Blender 社区讨论）更像调音台：每个轴独立取值，知名游戏/资产包 = 一组预设。好处是：

1. 看到任何参考图，能逐轴拆解出"它旋到了哪里"（你上次那张软陶参考图就是这么被拆开的）；
2. 做新资产时先定坐标，避免做到一半风格漂移；
3. 跨风格迁移成本低——改一两根轴就是新子风格。

## 2. 六根轴（= 你那份 5 点差异的扩展版）

| 轴 | 一端 | 另一端 | 关键问题 |
|---|---|---|---|
| A1 几何处理 | 尖棱硬面（flat shading，每个面片可见，"结晶感"） | 圆润倒角（bevel + 全平滑着色，"软陶感"） | 棱是圆的还是方的？着色是 flat / smooth / 平滑+标记锐边（混合式，当今卡通风最常用） |
| A2 描边 | 无描边（靠色块和倒角分离物体） | 黑描边 / 彩色描边 / 后处理边缘检测 | 轮廓是材质分离（无描边）还是线条语言（漫画描边） |
| A3 光照模型 | 赛璐璐二分（明暗硬切 + ramp 渐变贴图 + 边缘光） | 柔光棚拍（大面积柔光箱 + 环境光 + 软接触阴影）／硬太阳光；或干脆光影画进贴图（手绘）／全套 PBR | 阴影是"画出来的"（二分/手绘）还是"算出来的"（柔光/PBR） |
| A4 色彩 | 粉彩低饱和（奶糕感） | 高饱和撞色（糖纸感）；纯色平涂 ↔ 渐变纹理 ↔ 手绘纹理 | 色彩是氛围（粉彩）还是符号（高饱和） |
| A5 材质隐喻 | 无（纯几何+纯色，"抽象低模"） | 强材质：软陶/粘土（哑光+指纹）、纸（折痕+单面）、玩具塑料（清漆高光）、毛毡布料 | 观众是否应该"想象出一种实物材质" |
| A6 展示语言 | 游戏内视角（第一/第三人称） | 等距 45° 微缩地台 + 圆角底座 + 压印标签 + 移轴景深（"目录照"语言） | 这是摄影语言而非造型语言，可叠加在任何风格上 |

> 补充一根隐形轴：**多边形预算的自我意识**——是"真诚的低模"（面数真的低且炫耀它）还是"伪低模"（面数其实不低，只是造型圆润概括，如 Fortnite/Supercell 系）。

## 3. 子风格清单（12 个常用预设）

每个给：六轴坐标 → 一句话气质 → 代表作 → Blender 侧要点。

### ① 软陶/玩具棚拍风（clay render / toy catalog）— 你的参考图
- **坐标**：圆倒角+全平滑｜无描边｜柔光箱+接触阴影｜粉彩｜软陶哑光｜等距地台目录照
- **气质**：设计玩具的产品照，温柔、无攻击性，天然适合"资产目录"排版
- **代表**：各类 clay render 圈、Tiny Glade（近似）、Claybook、乐高概念渲染
- **Blender**：Bevel 修改器 + Weighted Normal + shade smooth；大 Area Light 当柔光箱；世界光 + AO + 接触阴影；纯色 Principled（粗糙度高、高光弱）

### ② Synty 系平滑卡通（smooth flat-color，无描边）— 商业资产包主流
- **坐标**：平滑+局部锐边混合｜无描边｜简洁方向光+环境光｜饱和但不刺｜无材质隐喻｜游戏内视角
- **气质**：干净、量产、跨包统一性极强的"工具风"；Synty 被评价为"低模+用心的配色贴图，不算特别卡通"
- **代表**：Synty POLYGON 系列（付费标杆）、Quaternius Ultimate 系列（免费近似）、KayKit、Kenney（最简最方块）
- **Blender**：少量倒角、贴图走纯色+轻渐变（synty 特征是"几乎纯色但有极轻的明度渐变"），色板管理比建模更关键

### ③ 折纸/硬面描边风（flat + black outline）— 你的第一版
- **坐标**：尖棱 flat shading｜黑描边｜硬光+AO｜高饱和｜无／纸的隐喻若隐若现｜任意
- **气质**：图形感强、符号化、接近"3D 化的 2D 插画"；2D 里的 Tiny Swords 就是这个味道
- **代表**：Oceanhorn、For The King（近似）、大量 itch 独立小品；2D 对应物是 Tiny Swords 系资产
- **Blender**：flat shading 直出；描边用 Solidify+反转法线壳（游戏内最通用）或 Freestyle（仅 Blender 渲染用）

### ④ 赛璐璐三渲二（anime cel / NPR）
- **坐标**：中高模也可，低模亦可｜彩色描边（肤色区域描边不上黑，原神的 LightMap alpha 技巧）｜明暗二分 ramp + 边缘光 + SDF 脸部阴影｜动画色板｜无隐喻｜游戏内视角
- **气质**："做成动漫"而不是"做成玩具"，是低模卡通里技法最重的一支（自定义 shader 必选）
- **代表**：原神、星穹铁道、Hi-Fi Rush（GDC 讲了定制延迟管线+SDF 网点/排线）、风之杖、罪恶装备
- **要点**：Blender 侧 Toon BSDF 只是入门；真做要 ramp 贴图（暖顶冷底的昼夜双 ramp）、Fresnel 边缘光、脸部 SDF 阴影贴图。Godot 生态有现成 toon shader 可参考
- **注意**：这支对"贴图/Shader 一致性"要求极高，和你现有 AI 生图管线（CogView 多帧一致性弱）冲突最大

### ⑤ 手绘纹理风（hand-painted）
- **坐标**：低模任意着色｜可无描边（WoW）可有描边（无主之地）｜**光影不靠渲染，画进贴图**｜绘画性色彩｜无｜任意
- **气质**：信息量最高、最"耐看"的一支，但产能完全取决于手绘（或 AI 手绘）能力
- **代表**：魔兽世界、火炬之光、无主之地（手绘+描边混合）、Firewatch（环境向）
- **与本项目的关系**：CogView 能出"手绘风单图"，但同一资产多视角贴图一致性差——按你已记录的 AI 美术能力边界，此支只适合单件英雄资产，不适合批量

### ⑥ 粘土定格风（claymation）
- **坐标**：圆倒角+平滑+**故意的不完美**（指纹、压痕）｜无描边｜柔光定格摄影感｜实物色｜强粘土隐喻｜任意
- **气质**：比 ① 更进一步——不只是"渲染得像粘土"，还要"过程像捏的"；动画常配定格感（12fps/8fps）
- **代表**：The Neverhood（真粘土拍摄）、Claybook（可形变粘土渲染）、Armikrog、Don't Open the Doors
- **Blender**：Subdivision + 噪声位移做指纹/凹凸，或程序化 lumpy clay 材质；动画上故意 stepped 插值

### ⑦ 纸艺/折纸风（papercraft / origami）
- **坐标**：尖棱（纸只会直角折）｜常无描边（靠纸的正反面色差）｜平光｜剪纸色板｜**强纸张隐喻**（折痕、单面、纸偶关节）｜任意
- **气质**：手工书/立体书，叙事感强；折痕=倒角的反面
- **代表**：Tearaway、Paper Mario、Tengami（立体书）、Flat Kingdom、Hirogami（2025 新作）
- **Blender**：纸厚度用 Solidify；折痕靠 edge crease；正反双材质

### ⑧ 体素风（voxel / voxel-inspired）
- **坐标**：立方块构成｜无描边｜平光或柔光｜明快色板｜"积木"隐喻｜等距居多
- **辨析**（社区共识）：真体素 = 体素工具建（MagicaVoxel、Teardown 引擎级）；Crossy Road 其实是**低模手搓的体素观感**，不是真体素——"低模仿体素"本身就是一个子风格
- **代表**：Crossy Road（低模仿体素）、Minecraft/Teardown（真体素）；Kenney 有大量体素包
- **Blender**：Remesh(cubes)/阵列，或直接用 MagicaVoxel 建再导 GLB

### ⑨ 复古 PSX 风（haunted PS1）
- **坐标**：低模+低保真贴图｜无描边｜顶点光照｜限制色板+抖动带｜无｜任意
- **特征技法**：顶点抖动（snap to grid 的 wobble）、仿射贴图扭曲、低分辨率渲染+抖动
- **代表**：OK/NORMAL、Iron Lung、itch.io "Haunted PS1" 社区（已成完整独立游戏生态，恐怖向为主但也有可爱向）
- **Blender/Godot**：贴图降分辨率+nearest 采样；Godot 里顶点 snap 用着色器实现

### ⑩ 微缩景观/等距目录风（diorama / isometric）— 展示语言轴的极值
- **坐标**：造型轴任意（通常叠在①②③上）｜任意｜任意｜任意｜"沙盘模型"隐喻｜**45° 等距+圆角地台+压印标签+移轴景深**
- **气质**：把任何东西拍成"收藏品目录照"；这正是你参考图第五点（展示）对应的独立风格——它可以叠加，而不属于某一种造型
- **代表**：Townscaper、Monument Valley、Alto's Odyssey、Diorama Builder；Tiny Glade 的宣传物料大量使用此语言
- **Blender**：正交相机 45° 俯角、圆角地台（bevel 圆盘）、Array 阵列排版打目录

### ⑪ PBR 卡通风（stylized PBR / toy plastic）— "伪低模"
- **坐标**：面数不低但造型概括｜无描边｜真 PBR 光照（但参数夸张）｜高饱和｜**玩具塑料清漆隐喻**｜游戏内视角
- **气质**：Supercell/Fortnite 系"高级感卡通"，本质是写实管线+卡通造型；pixune 把 Fortnite 归入 Cartoon/Toon 3D 而非 Low-Poly
- **代表**：Fortnite、Clash Royale/Brawl Stars、Ratchet & Clank、马里奥奥德赛
- **对本项目**：依赖完整 PBR 管线和较高建模量，低模预热期不建议，列出仅为完整

### ⑫ 极简色块风（minimal flat）
- **坐标**：极简几何｜无描边｜平光甚至无光影｜两三个色｜无｜任意
- **气质**：卡通的边界情况，靠构图与剪影取胜
- **代表**：Superhot（白+红）、Thomas Was Alone（纯色棱柱+叙事）
- **价值**：适合 UI 级/图标级 3D 小物，量产成本最低

### 混合样本（证明"轴"的存在）
- **A Short Hike**：低模平滑 + 像素贴图（3D 造型 × 像素材质隐喻）
- **Untitled Goose Game**：≈②的光照色板 + 更平的材质，无描边粉彩
- **无主之地**：⑤手绘 + ③描边 + ④二分的混合体（社区常年争论它算不算 cel-shaded，因为它其实是手绘纹理+描边）

## 4. 资产包生态对照（做"资产目录"的直接参照系）

| 包 | 风格坐标 | 授权 | 备注 |
|---|---|---|---|
| Synty POLYGON | ②平滑无描边，轻渐变贴图，色板纪律极强 | 付费 | 商业标杆；评价是"低模+用心的贴图思维，不是纯卡通" |
| Quaternius Ultimate | ≈Synty 但更圆润 Q 弹，带绑定量大 | CC0 | 免费里最接近 Synty 质量 |
| KayKit (Kay Lousberg) | ②系，角色比例更卡通 | CC0 | 角色动画友好 |
| Kenney | ②的极简端：最方块、最玩具、几乎纯色 | CC0 | 原型期王者；有大量体素包 |
| itch.io PSX 包 | ⑨复古 | 各异 | 恐怖道具成套生态 |

社区共识：不同作者的比例/色板/着色不兼容，混包必花——反过来说明"风格=一组严密的轴取值"，风格漂移在资产生产里是致命错误而非玄学。

## 5. 轴 → Blender/Godot 旋钮速查

| 轴 | Blender 旋钮 | Godot 侧 |
|---|---|---|
| 倒角/着色 | Bevel 修改器(harden normals)、Weighted Normal、shade smooth + Mark Sharp（混合式）、Auto Smooth 角度 | 导入时保持法线；尖锐边随 GLB 导出 |
| 描边 | 反转法线壳（游戏通用）／Freestyle（仅 Blender 出图）／后处理 Sobel | 反面壳用着色器 `cull_front + invert`；或屏幕空间边缘检测 |
| 柔光棚拍 | 大面积 Area Light + 世界光 + AO + 接触阴影 | 简化为 hemispherical + 方向光软阴影，实时够用 |
| 赛璐璐二分 | Toon BSDF 起步 → ramp/边缘光/SDF 需自定义 | Godot toon shader 生态现成 |
| 粘土感 | 噪声位移指纹、lumpy clay 程序材质 | 位移烘成 normal map |
| 纸艺 | Solidify 厚度 + crease 折痕 + 正反双材质 | 直接 GLB |
| PSX | 低分辨率渲染 + nearest | 顶点 snap 着色器 |
| 目录展示 | 正交 45° + 圆角地台 + Array 排版 | 同 Blender，渲染出图用 |

## 6. 与本项目（扫雷+像素风）的关系（仅备忘，不展开）

- 你手里的参考图 = **①软陶棚拍 × ⑩等距目录展示语言** 的组合；第一版跑偏成 ③。下次开工前先写下六轴坐标再动手，可避免复发。
- 现有游戏是 2D 像素风。若 3D 低模资产将来要进游戏而非仅做宣传目录，需提前决定融合策略（A Short Hike 式"3D 造型×像素贴图"是已被验证的融合点，且与你 pixel-forge 管线兼容性最好）。
- ④⑤两支与 AI 生图管线冲突（多帧一致性），①②③⑧⑫全部可程序化+纯色材质直出，与现有工作流兼容。
