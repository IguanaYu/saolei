# 调研：2D 游戏脚下阴影怎么做（2026-10-02）

> 需求：给机器人加"一点脚下的阴影"，找回落地感。本文调研其他 2D 游戏的做法并给出本项目落地方案。
> mock 对比图（真实地板+真实皮肤，5 方案）：[脚下阴影-mock对比-2026-10-02.png](脚下阴影-mock对比-2026-10-02.png)

## 0. 本项目现状（PIL 实测，可信度 A）

- 机器人皮肤 24×24px（bbox 几乎满幅），格子 28px，`Robot` 为 Node2D(z_index=5) + `Skin` Sprite2D
- 4 个机器人场景（Miner/Guard/Detector/Robot.tscn）**互相独立、不继承**，但脚本都继承 `Robot` 基类 → 阴影在基类代码里建节点才能一处覆盖全部
- 地板 `floor_V2.png` 平均亮度 44/255（暖棕 53,41,31），未开区 `cave_bg` 只有 22/255 → 地板暗，阴影是"压暗 8~11 个亮度级"的克制量级，纯黑 35% 就够读出
- 机器人 move 帧自带弹跳（履带滚动+弹跳烘在帧里）→ **阴影不能烘进皮肤帧**（会跟着跳），必须是独立贴地节点

## 1. 其他游戏的四档做法

### 档1：椭圆 blob（绝对主流，即"那种感觉"）
半透明深色椭圆贴在脚底，身体遮住上半，只露下缘月牙。塞尔达 LttP、星露谷、Enter the Gungeon、Nuclear Throne、Moonlighter、Eastward、RimWorld 棋子、Minecraft 实体影全是这一族。
- 常规参数口径：宽 ≈ 身宽 60~80%，纵横比 ≈ 2.5:1~3:1，alpha 25~50%，锚点在脚底中点
- 格子制战棋（Into the Breach / Wargroove / Advance Wars）用得更克制：alpha 更低、比身体小，避免干扰格位读数 —— 咱们这种"格子是玩法主体"的游戏应对齐这一支
- 有跳跃的游戏（Minecraft/Hollow Knight/宝可梦跳台）会让影子随离地高度**缩小+变淡**，落地感来自"影子留在地面、身体离开"

### 档2：方向性投影（伪 3D，工程感）
Factorio：所有实体多一张向**东南偏移**的剪影影（假定光源在西北），alpha ~50%。缺氧也用"偏移影+接触影"双份。立体感/工程感最强，但每个实体多一张影子资产、量大声，适合以"工厂"为主角的游戏。咱们的暖矿洞光感其实兼容 D 方向，但机器人是主角小品件，不必上整套。

### 档3：引擎级真实投影
Godot 的 `PointLight2D/DirectionalLight2D` + `LightOccluder2D`（官方文档实抓）：逐像素投影、PCF5/13 软化，但文档明说 PCF13 只能配极少量灯，且像素风要像素化阴影还得自己写 shader snap LIGHT_VERTEX。对"脚下一点影"是杀鸡用牛刀，Hades/Dead Cells 量级才值得。

### 档4：烘焙进 sprite 帧
小像素游戏常见做法，但见 §0——move 帧带弹跳会穿帮，且换皮肤不通用。排除。

## 2. 像素美术规范要点（对 24px 小件）

- **硬边或两级 alpha 优于平滑径向渐变**：渐变会引入调色板外中间色+缩放脏边；两级（核心 ~40% / 边缘 ~20%）是"柔和"的像素正统
- 抖动网点边（棋盘格镂空外环）更复古，配咱们的矿洞风也协调
- 尺寸对齐像素网格；阴影色不一定要纯黑，用"地板色加深版"保色调统一（暖棕地板 → 深暖黑 (8,5,3)）
- 暗地板上别追求强对比：37% alpha 在 lum44 地板上 ≈ 压暗 8.5 级，刚好像是"有一点点"

| 对照无阴影 | 45.7 | — |
| A 硬边椭圆 α37% | 37.2 | -8.5 |

视觉模型方向性初评（非判定证据）：B/C 观感最自然，A 略"贴纸感"，D 立体感最强但有"站偏"感 —— 与像素美术惯例一致。

## 4. 落地方案（推荐 B；C 为备选）

1. 程序化生成共享贴图 `visual_v2/runtime/robots/shadow_blob.png`（约 17×8 两级 alpha 椭圆，色 (8,5,3)），全机器人/未来敌人共用
2. `robot.gd` 基类 `_ready()` 里 `add_child` 一个 **`FootShadow`（Sprite2D）**，`z_index = -1`（z_as_relative 默认开 → 只压到兄弟节点之下、仍随 Robot z=5 压过格子），位置 (0, +9) 左右
   - 节点显式命名 FootShadow，避免 get_children() 误匹配（AGENTS 约定）
   - 四个独立 tscn 不用挨个改，基类一处生效
3. 新增贴图后先跑 `--headless --import` 再启动（AGENTS 约定）
4. 扩展位：被击飞/震退（snap_to 有 pulse）时可按"离地高度"缩放淡化（Minecraft 公式）；敌人/巢/Boss 复用同一贴图即可
