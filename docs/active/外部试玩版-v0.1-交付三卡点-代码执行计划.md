### 调研（Godot 官方文档 exporting_for_windows / EditorExportPlatformWindows）

- exe 图标走预设 `application/icon`（回退链：预设 icon → 项目 `windows_native_icon` → `config/icon`），且 **`application/modify_resources=true` 才会把图标/版本信息写进 exe**；项目设置里的图标会被自动转 ICO。
- `binary_format/embed_pck=true` → 单 exe 内嵌 PCK（本项目 ~20M 资源，远低于 3.89GB 上限），分发给 5-10 人最省事。
- `--export-release` 导出不弹控制台黑窗（控制台 wrapper 是 debug 侧选项 `debug/export_console_wrapper`，保持 0）。
- `exclude_filter` 逗号分隔 glob，把非游戏目录挡在包外。
- 行业通行做法：小范围盲测发「单 exe + 说明文件」的 zip，不做安装包。

### 3c. 引导期间计时不暂停（L2+ 引导吃倒计时）

**现状**：main.gd:505 `_process` 在 `game_active` 时无条件 `time_left -= delta`；TutorialGuide 只是覆盖层不暂停游戏（设计上引导步骤靠真实输入推进——`board_click/base_placed/robot_bought/upgrade_panel_opened`，所以**不能** `get_tree().paused` 整树暂停，会吞掉推进事件）。L1 无时限无感，L2–L5 引导期间倒计时照跑，盲测者白白损失开局时间且与「限时 120s」的承诺感冲突。

**调研**：教学/对话覆盖期间冻结计时器是主流做法（不在时间压力下教学）；计时冻结要"看得见"——HUD 倒计时静止本身就是可见反馈。

**改动**（main.gd `_process` 顶部，一行守卫）：
```gdscript
func _process(delta: float) -> void:
    if not GameState.game_active:
        return
    # 引导=教学停摆：计时/CD/机器人/敌虫全冻结（剧本步骤等的是玩家输入事件，
    # 输入不走 _process，不受影响；todo 卡点三）
    if tutorial_guide.visible:
        return
    GameState.elapsed += delta
    ...
```
- 口径说明：`elapsed` 是埋点「实际用时」，一并冻结更准（`_time_used()` 的两个口径 total−time_left / elapsed 保持一致）；心跳音效随 time_left 静止自然不触发。
- 已核对 L1–L5 剧本等待的事件全部来自玩家输入/购买（main.gd:89-94 转发表），无「等机器人干活」类事件，全冻结安全；**若后续剧本加入机器人行为等待事件，需回来放开 robot_manager.tick**。
- 引导跳过/完成的瞬间恢复计时，无需额外代码。
