# 化石障碍(2×2 永久多格障碍)— 实施计划 v1

**日期:** 2026-10-04
**性质:** 执行计划(调研已完成,见 [可行性调研-异形地图与多格障碍-v0.md](玩法设计/可行性调研-异形地图与多格障碍-v0.md) §4/§8)
**设计定调:** 化石=纯难度件,2×2 占位、**永久、不可清除**;透明口径(数字照常数 8 邻雷,化石格无雷不显示数字);点击不耗 CD。
**里程碑:** v1 试玩版已存档于分支 `milestone/v1-playtest`(75afe7c);本工作全部在 main 进行。

## 1. 范围

**做(引擎 C 切片 + L4 落位):**
1. 化石数据链:FixedBoards 增 `"fossils"` 键(2×2 原点)→ LevelData.fixed_fossils → apply_fixed_board 铺设为 Cell 状态位
2. 拦截:开格/标旗/和弦/洪水连开/Solver 候选 全部跳过化石格;点击化石=无效操作不耗 CD(走现有障碍分流 kind=="" 路径)
3. 胜负分母:count_safe_remaining/count_safe_total 剔除化石格(与锁格不同,锁不走分母剔除的教训见调研 §8.1)
4. 敌虫阻挡:find_path_free_step 把化石格当墙;预置 hazard/虫巢裂缝候选过滤;玩家自放基地拒绝化石格
5. 美术:56×56 化石像素贴图(程序化,暖色矿洞风),切 4 块 28×28 quarter overlay
6. L4 落位:选一块满足约束的 2×2(全非雷/非预开/不围口袋/西侧未开区)
7. 文案:规则页+随包试玩说明补化石一句;第四关设计文档 216→212、77%→75.5% 同步
8. 顺手独立提交:修 `main._in_bounds` 轴反活 bug(每日挑战非方形盘放不了基地,调研 §6)+ level1_director board_size 轴反

**不做(明确出界):**
- 不做化石清除/奖励交互(定调:纯难度件)
- 不做 L3 对外落位(L3 仅作临时白盒验证,不入库)——正式内容只在 L4
- 不做异形地图(B)/竖长地图(A)、每日挑战化石、随机盘化石生成
- 不做 Boss 关化石适配(boss 抛锁候选过滤做掉——一行防御,防未来踩雷,但 L5 不放化石)

## 3. L4 落位约束(选坐标逐条过,源自调研 §8.3)

1. 4 格均非雷(雷位表核对,否则数字变、烘焙验收作废)
2. 不在 preopen 57 格内;不邻虫巢裂缝/预置 hazard 位
3. 不与盘边围出机器人不可达口袋(2×2 全内格+四邻不构成封闭圈)
4. 西侧未开区优先(preopen 集中在中右);挡机器人直路=难度,不堵探测要道
5. 候选校验脚本:输出 4 格坐标+雷/预开/邻域检查结果(中间产物先打印再定稿)
