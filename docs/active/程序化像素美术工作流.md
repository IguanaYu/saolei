# 程序化像素美术工作流（2026-08-15 定稿验证）

> 本流程在「岩壁风格系统（22 套）+ 洞窟环境包 + UI 视觉稿」三轮实战中跑通，
> 与 [AI美术生产指南](AI美术生产指南.md) 互补：**AI 负责参考图/画风探索，程序化负责可量产的无缝纹理与变体**。
> 配套守则：[调试复盘-贴图溢出与视觉模型陷阱](调试复盘-贴图溢出与视觉模型陷阱.md)（像素自检优先于视觉模型结论）。

## 一、流水线（6 步，每步有明确产物）

```
① 调研同类游戏 ──→ ② 程序化生成素材 ──→ ③ 同局面 mock 对比图 ──→ ④ 像素级自检
                                                                        │
⑥ Godot 接入 + headless 验证 ←────────── ⑤ 用户肉眼拍板 ←──────────────┘
```

1. **调研**（AGENTS.md 要求）：搜同类游戏的画法 + 业界标准技术。
   案例：发现 Dome Keeper 正式版从"独立石块"演进为"连体岩壁"，微软扫雷冒险模式=泥土+散碎石——
   共同规律：**好看的游戏从不让"一格=一颗石头"**。
2. **程序化生成**：PIL + torus 噪声（见下节），脚本放 `tmp/gen_*.py`，产物进 `assets/tiles/`。
3. **mock 对比图**：同一局面只变一个维度（画法/色调/密度），竖排面板 + 标题条。
   用户"光说图看不懂"，**必须出图让他挑**（`tmp/mock_*.png`）。
4. **像素自检**（视觉模型结论只是方向性线索，下结论必须用像素工具）：
   - 无缝性：wrap 边界差分 ≈ 内部相邻差分（`seam < max(inner*2.2, inner+6)`）
   - 透明件：mode=RGBA 且透明占比合理
   - 网格感：连体纹理做列/行亮度剖面峰检测，`56px(=28*2)` 周期峰应为 0
   - 对比面板公平性：各面板已开区 crop 逐像素 diff=0
5. **用户拍板**：肉眼 > 一切。用户说"不好看"而数据说"没差异"时，默认信用户。
6. **接入验证**：改代码 → `--headless --import`（新 PNG 必须）→ `--headless --quit-after 3`
   grep ERROR=0 → 正式跑给用户玩并盯日志。

## 二、核心技术

### 1. torus value noise（无缝纹理的根基）
网格坐标 modulo 包裹，左右/上下边缘天然连续 → 任意尺寸可平铺。
多层不同频率叠加（fbm）出岩石质感：`fbm(size, [6,12,24,48], seed)`。
参考实现：`tmp/gen_tiles.py` → 已复用于全部 wall/floor/cave_bg。

### 2. 装饰件无缝化：9 宫格 wrap 复制
在纹理上画椭圆/点时，同时画到 `(x±size, y±size)` 九个位置，跨周期边界无缝。
参考：`gen_assets_pack2.py` 的碎石、`gen_assets_pack3.py` 的星点/岩浆纹。

### 3. "连体" vs "随机"两种铺法（cell.gd）
- **连体**（岩壁）：atlas region 按 `(coord % 12) * 28` **确定性**取块 → 相邻格取相邻区块，整片连续
- **随机**（洞底）：atlas region 随机取块 → 微妙变化打破重复，但不要求连续
- 平铺条（边框）：随机走位锯齿 + **线性纠偏首尾闭合**（`jagged_edge()`），长度方向可平铺

### 4. 配色派生
一套主题只定义 wall 的 lo/hi 两端色：
- 洞底 = 岩壁色板压暗（lo×0.78, hi×0.56）→ 数字可读性自动达标
- 背景再压暗一档 → 层次感（cave_bg < wall < floor 亮度）

## 三、Godot 接入坑清单（都踩过）

| 坑 | 修法 |
|---|---|
| AtlasTexture 默认 expand_mode 撑爆控件 | TextureRect 显式 `expand_mode=1` |
| atlas 块边缘渗色 | `AtlasTexture.filter_clip = true` |
| 新 PNG 不 import 直接 load() | 先跑 `--headless --import` |
| `load()` 不存在路径刷 ERROR 日志 | 先 `ResourceLoader.exists(path)` |
| Cell._ready 里用 coord，但 coord 在 add_child 后才赋值 | Grid 里 **coord/wall_style 在 add_child 之前设置** |
| 中文路径图片无法走视觉模型 CDN | 视觉链路只作参考，结论靠本地像素工具 |
