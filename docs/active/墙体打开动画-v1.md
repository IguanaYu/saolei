# 墙体打开动画 v1

日期：2026-10-03。已直接接入实际项目 `E:\godot\扫雷`。

开墙时取当前格原有的岩壁纹理，切成四块，按整像素轻微错开、下落并在 0.22 秒内淡出。覆盖层限制在本格内；洞底和数字立即显示，Cell 本体、碰撞区和数字不做缩放或亮度脉冲。岩壁装饰同步淡出，已有小岩屑继续沿用。

玩家、机器人和连锁展开共用此表现；连锁格保留原有波纹延迟。基地、矿脉和坍塌接管时移除覆盖层。新节点明确命名 `WallOpenFx`、`WallQuarter0` 至 `WallQuarter3` 和可选的 `WallDecoCover`，挂在 Cell 下，忽略鼠标。

实现：`scripts/cell.gd` 的 `_play_wall_open()`。`scripts/effects_layer.gd` 的延迟岩屑改为绑定所属 Cell 的 Tween，重开时随旧格取消，避免访问已释放格子。

运行检查覆盖四种岩壁主题、切片来源、暂停、清理、特殊格接管、机器人开格、连锁错峰和开局重置。日志见 `tmp/wall_open_render_verify.log`。

实机截图逐像素检查先从关闭帧独立检测四块矩形，再比较开始、中段、后段和结束帧。当前截图尺寸 2560×1440，各矩形实测为 `(105,435,315,645)`、`(525,435,735,645)`、`(945,435,1155,645)`、`(1365,435,1575,645)`；四个矩形之外的变化像素均为 0。测量脚本：`tmp/measure_wall_open.py`。这些是本次截图的坐标，不能作为其他窗口尺寸的固定边界。

调研参考：[Factorio FFF #343](https://www.factorio.com/blog/post/fff-343) 的地表与装饰碎屑依据原材质反馈；本项目直接复用当前格纹理以跟随墙体主题。[Godot Tween 文档](https://docs.godotengine.org/en/stable/classes/class_tween.html) 的绑定节点与回调用于安排短时动画和销毁。
