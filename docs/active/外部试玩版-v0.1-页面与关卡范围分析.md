# 扫雷挖矿：外部试玩版 v0.1 页面与关卡范围分析

> 盘点日期：2026-09-28。依据当前 `Main.tscn`、UI 场景与脚本、`level_database.gd`、第 1–4 关设计文档和 `visual_v2/review/` 验收截图。截图是留存的验收图，页面内容以当前代码为准。本文件是分析建议，未改动游戏规则或页面。

> **2026-10-01 复核**：§二 建议的信息架构**已基本落地**——主菜单（继续试玩·第 N 关/选关/规则/设置/退出）、单章 5 关选关页、关前卡（可跳过）、规则页、结算账单分项、试玩完成页均已实装；章节页/每日挑战/签到/档案已无入口；DEBUG 加钱与 F5 换肤已移除；设置页全部真实生效（含音频）。**未落地的建议**：反馈入口（`feedback_url` 空=隐藏）；选关页 L1–L4 简介与"本关新增"字段留空（`level_database.gd` 仅 L5 配了 `short_name/intro_line/mechanic_tags`）。§一 的"当前问题"列为当时基线，仅作历史记录；§三 表已更新为现行值。

## 结论

当前项目已经有完整的长期运营型外壳，但封闭试玩要验证的是“扫雷判断、投资机器人、观察自动扫雷、调整投资”的短流程。建议试玩包只呈现本次确实可玩的关卡、有效的设置和必要的反馈；所有展示给玩家的解锁承诺应在包内兑现。

**必须先统一的范围冲突**：上游执行计划确认“第一关亲手购买四类机器人并看到检测、采矿”“约 5 关”“挖矿局 90 秒”；已实现的第 1–4 关却是“L1 仅开墙/标雷、无时限；L2 90 秒；L3 120 秒；L4 150 秒、加入虫害/保安/探测；检测型和矿工型在 L2–L4 被隐藏”，L5 仍是旧的通用 Boss。两套承诺不能同时作为同一版的介绍文案和验收标准。以下以**执行计划中已确认的核心卖点**为对外范围基准，现有四关视为可复用内容，改造量须单独评估。若决定沿用四关教学链，应先修订上游卖点、目标人群、关卡数和测试招募文案。
>
> **2026-10-01 演变结果**：实际走的是"沿用四关教学链"——L1–L4 定位不变、时限盲测后全线 +30s（90/120/150→120/150/180），L5 重做为拔牙三阶段 Boss 关（14×14/20 雷/210s）；上游执行计划的"首关四类机器人/90 秒"承诺已同步修订（见执行计划 2026-10-01 复核）。**四类机器人问题仍未解决**：矿工全程缺席，检测仅 L4/L5 探测按钮，规则页介绍四类机器人的文案未兑现（§四.1 继续挂起）。

入口顺序：启动闪屏 → 主菜单 → 章节选择 → 关卡选择 → 局内 → 结算 → 选关。主菜单及局内还可打开多个覆盖面板。

| 页面/面板 | 当前显示什么、从哪里进入 | 当前问题或属性 |
|---|---|---|
| 启动闪屏 | LOGO、标语、加载进度条、健康提示、`v0.3 · Godot 4.6 · 单机开发版`；启动自动播放 | 版本与计划中的 v0.1 外测包不一致 |
| 主菜单 | 矿洞背景、标题、标语、总矿石；“变强商店”“开始冒险”“挖矿档案”“每日挑战”“矿工签到”“设置” | 六个功能入口同层，核心开始按钮被大量长期玩法分散注意力；无退出游戏、操作说明、反馈入口 |
| 章节选择 | 12 张章节卡，已解锁章节显示名称、模块解锁提示、星数 `x/15`；未解锁显示锁；返回主菜单 | 暴露 12 章/60 关的长期容器与当前试玩内容不匹配 |
| 关卡选择 | 当前章节的 5 张关卡卡：编号、星星或锁、目标短句；第 5 关标 `[BOSS]`；顶部总矿石、“变强”、间场提示、返回章节 | L1–L4 设置了 `no_stars`，但卡片仍用星数和 Boss 语言；L5 是旧通用关，非试玩设计 |
| 局内 HUD | 局内资金、局外矿石、积分、生命、剩余时间、暂停；目标文字、积分目标进度条、空闲/放基地/临时提示按条件出现 | 三种资源并列而没有名称解释；“清空安全格”只有文字，没有剩余数量或进度 |
| 局内底部商店 | 开墙型、标雷型、检测型、矿工型；局内升级、保安、基地、无人机、探测按关卡配置显示；放置提示；部分旧关还能见到 `DEBUG: +200 钱` | 不同关菜单变化大；检测/矿工在当前 L1–L4不可买；调试按钮未全局隔离 |
| 局内升级 | 用局内资金购买速度档；L2 两条速度轨，L3/L4 四条移动/工作轨；显示等级、下一级效果与价格 | 规则较多，缺少玩家能立即理解的“当前瓶颈/升级收益”反馈 |
| 教学覆盖层 | 棋盘或按钮聚光、高亮框、短句、步骤数、跳过/下一步；L1–L4 有各自脚本 | 可复用，但教程内容目前讲的是两类机器人、升级、局外成长和虫害链 |
| 暂停 | 当前章节/关卡、资金/积分/生命/剩余时间；继续、重开、设置、放弃；ESC 提示 | “放弃”会走单独的收益折算；需与“90 秒到点正常结算”区分 |
| 确认框 | 用于放弃、继续挑战离开、清档；标题、说明、确认/取消 | 清档文案列出矿石、关卡、升级、统计、签到，试玩版若隐藏签到应同步改文案 |
| 结算 | 胜利/本次挖掘结束、新纪录、星星或试玩数据、时间、矿石奖励、开格分、标旗分、人机操作占比、时间加分、总分；再来一局、返回选关、分享、部分关继续挑战 | “分享成绩”只弹“开发中”；试玩关无星，普通关仍有星；没有清楚呈现关卡目标完成度与采矿附加分的固定分项 |
| 局外变强 | 总矿石；起始金币、起始生命、移动速度、工作速度、开局送机器人 5 条轨，每条两级、效果和价格；从主菜单和选关进入 | 已能影响 L3/L4；L1/L2 不吃局外加成，需明示生效范围或调整规则 |
| 挖矿档案 | 总局数、胜率、最佳通关、最高连胜；12 章星数、总星数、3 星通关数 | 与试玩关不评星的规则冲突；“胜率”对到点正常结算但未过关的语义不够准确 |
| 每日挑战 | 日期、宣称“全球同图”、盘面规格、今日/历史最佳、每周徽章、宝箱、刷新倒计时、开始按钮 | 日期种子尚未真正进入雷位生成；对外承诺不成立 |
| 矿工签到 | 首次启动可能自动弹出；连续 7 天奖励、领取、刷新时间 | 首次启动打断核心试玩链；偏长期留存，不提供本轮核心验证数据 |
| 设置 | 音乐、音效、音量、震动、网格线、全屏、重看教程、清档；页面注明音频占位 | 音频开关目前不产生音频效果；“重看教程”实际只提示进第 1 关 |

视觉方面，现有深灰矿洞、铜框、琥珀和青色提示已经能支撑测试版。菜单层级的问题主要在**内容范围和信息优先级**，不需要另起一套画风。

## 二、建议的测试版信息架构

```text
启动（版本号）
  → 主菜单：继续试玩 / 选择关卡 / 玩法说明 / 设置 / 反馈与退出
  → 单章 5 关选择：已完成、当前可玩、未解锁；每关目标与新机制
  → 关前卡片：目标、时间、可用设备、首次提示、开始
  → 局内：棋盘 + 资金/目标/积分/时间 + 按关显示的设备与升级
  → 暂停：继续、规则/操作、重开、退出本局
  → 结算：达标状态、进度、分数来源、矿石、下一关/重玩/选关
  → 第 5 关完成：试玩结束、感谢及反馈入口
```

| 当前页面 | 测试版处理 | 应显示的重点 |
|---|---|---|
| 闪屏 | 保留，缩短 | 游戏名、准确版本 `封闭试玩 v0.1`；加载中才显示进度；移除“单机开发版”误导版本字样 |
| 主菜单 | 精简并调整顺序 | 主按钮“继续试玩/开始试玩”，次按钮“选择关卡”；下方“玩法说明、设置、反馈、退出”。“变强”可在通关间场或选关顶部出现，不抢首次开始入口 |
| 章节选择 | 本轮隐藏 | 仅一组试玩关，无需先点章节；未来多章时再恢复。若保留单章包装，也只显示“试玩矿区 1/1”，不展示 11 个锁章 |
| 关卡选择 | 保留并重做卡片 | 5 关横向/纵向清楚编号、短名称、核心考题、通关条件、已完成/当前/未解锁；锁卡显示“通关上一关解锁”；不显示星数和 `[BOSS]`，除非实际有对应规则 |
| 关前说明 | 新增轻量卡片 | “本关要做什么”“新增工具”“时限与结束规则”三项，首关可直接并入教学。规则数字只展示当前真实配置 |
| HUD | 保留并调整分组 | 资金（可花）、目标进度（是否达标）、积分（结算分）、剩余时间/生命；局外矿石放到间场，不占局内黄金位置；清空目标显示“已开安全格 x/y” |
| 商店/升级 | 保留，逐关开放 | 只显示本关能用的设备；按钮写清当前价格、用途和不可买原因；购买后立即反馈钱和进度变化；永久/局内升级用不同标题 |
| 教学/规则 | 保留并补常驻帮助 | 首关只提示新规则和第一笔购买；随时可从暂停重看“鼠标操作、机器人职责、矿脉流程、计分” |
| 暂停/确认 | 保留 | 退出本局后会得到什么要与真实结算一致；重开是否放弃本局收益需明示；ESC 返回 |
| 结算 | 保留并重排 | 顶部先写“目标达成 / 本次挖矿结束，目标未达成”；进度数字；开格、正确标雷、采矿、剩余时间分项；本局资金不当作积分；矿石收益；主按钮“下一关”或“重玩本关” |
| 局外变强 | 有条件保留 | 若本轮确实要测试永久投资，放在 L2→L3 间场，标明购买后哪些关生效；否则先隐藏，以免污染局内投资实验 |
| 档案 | 简化或隐藏 | 如保留，显示 5 关完成度、每关最佳积分/用时和机器人贡献；移除 12 章星数与胜率词汇 |
| 每日挑战/签到 | 隐藏入口与自动弹窗 | 避免未经验证的“全球同图”和签到奖励影响测试资金；后续独立玩法再开放 |
| 设置 | 只留真实生效项 | 全屏、网格线、操作说明、清档；接入音频后再显示音乐/音效/音量；震动确认生效后保留 |
| 分享 | 暂时隐藏 | 当前仅有“开发中”提示，测试反馈入口应提供真实可用的方式 |
| 试玩完成页 | 新增 | 明确“已完成封闭试玩全部关卡”，显示总用时、个人最常用投资/最高分（有数据才展示）、反馈入口与返回选关 |

页面次序原则：首次启动最多两步进首关；每次结算都有清楚的下一步；任何看得见的入口都应有真实结果。

### 建议的 5 关内容表（供下一轮数值与关卡设计落地）

此表是**页面和内容职责**，不是已实现的数值承诺。时间、资金、目标阈值须按真人盲玩校准；若坚持上游“每局 90 秒”，现有 L1/L3/L4 的时限均要调整。

| 关 | 玩家要学会/验证什么 | 首次展示 | 关卡页写法 |
|---|---|---|---|
| 1 新矿区上手 | 手动扫雷获得启动资金，亲手买开墙/标雷，让机器人推进；在同一关完成检测与一次采矿得分 | 四类机器人和“资金≠积分”；采矿为附加分 | “让机器人接手扫雷；完成目标并运回首批矿石” |
| 2 速度选择 | 买更多机器人还是升级现有机器人，比较清盘速度 | 局内升级与时间加分 | “用投资提速，在时限内达到扫雷目标” |
| 3 再投资 | 从扫雷/采矿所得资金追加设备，验证收益滚动 | 矿石收益 → 再投资；若保留局外成长可在此之前引入 | “先回本，再扩大机器人队伍” |
| 4 基地布局 | 增建基地及摆放位置影响机器人移动和矿工运距 | 第二基地、布局成本 | “同样的设备，摆放决定效率” |
| 5 综合关 | 无新系统，综合运用前四关选择，完成试玩闭环 | 较复杂但可推理的盘面；完整结算与结束页 | “综合矿区：用自己的投资方案冲高分” |

第 1 关四类机器人不等于必须买齐四台。为了让它们“看得见且可亲手购买”，需要安排可推理的已标雷、可检测的矿脉、可运回的矿石，以及足够但有限的启动资金。若首关信息负荷过高，可以保留四类设备可见，把引导拆成“先自动扫雷，后尝试检测/采矿”的两段，用购买选择验证玩家是否主动接上产业链。

## 四、需要先拍板及验收的事项（2026-10-01 标注状态）

1. **范围基准** ⏳ 仍挂起：L1–L4 教学链已沿用并落地，但"首关四类机器人"未兑现——矿工全程不可买，检测仅 L4/L5 探测按钮；规则页四类机器人介绍与实际不符。**外测前必须三选一**：①规则页与商店只讲实际可买的三类（改文案，最便宜）；②把探测/矿工以某种形态提前进 L1–L2；③保持现状接受落差。招募文案已按"沿用教学链"口径对齐（执行计划 2026-10-01 修订）。
2. **过关定义** ✅ 已落地：L1/L2 清空安全格、L3 积分 300（REACH_SCORE，盲测观察项）、L4 开 160 格、L5 处理全部雷——均为扫雷进度口径；采矿附加分不参与过关。
3. **到点与放弃** ✅ 已落地：到点/命尽=强行停止并正常结算（非失败、给矿、可重玩、不解锁）；暂停面板"重开/返回选关"走确认框并明示收益结算。
4. **移除误导入口** ✅ 基本完成：12 章/星数/[BOSS] 标签/每日同图/签到自动弹窗/分享/Debug 加钱/F5 换肤均已收起或移除；音频设置已真实生效。**遗留**：反馈入口（`feedback_url` 空=隐藏，渠道未定）。
5. **关卡可达性** ✅ 已处置：L5 有专门设计；L4 模拟 0/200 清完报警已通过"时限 150→180s + 目标打折为开 160 格（≈77%）"处置，盲测实测通关率仍是关键数据。
