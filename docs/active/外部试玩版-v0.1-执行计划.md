**目标玩家（已确认）**：有一定扫雷经验、熟悉数字推理和标雷的玩家。扫雷是吸引他们进入游戏的题材与入门技能；局内主要玩法是投资和布置机器人，让机器人自动开安全格、标雷，玩家在必要时用自己的扫雷判断帮助机器人继续工作。外测招募与教学设计均以这类玩家为基准。

**核心决策（已确认）**：正确投资是主要乐趣。玩家根据当前瓶颈、剩余时间和资金，决定何时买哪种机器人、是否升级、何时增建基地以及放在哪里；机器人自行执行任务。投资的主要目的在于让机器人扫雷更快、获得更多积分；购买只扣局内资金，不扣通关积分。布局影响作业效率。试玩版不以划分作业区域、逐个设定任务优先级等微观调度为主。

**玩法侧重（待外测验证的设计假设）**：机器人扫雷是主玩法，采矿提供附加得分和可继续投资的资金。**2026-10-01 现状**：检测与矿工未按原设想进入第一关——检测以 L4/L5「探测」按钮形态出现（100/次，3×3 确认雷），矿工暂未进入试玩五关（规则页仍介绍四类机器人，承诺未兑现，见[范围分析](外部试玩版-v0.1-页面与关卡范围分析.md) §四.1 待拍板）；以棋盘上的开格、标雷和机器人协作为通关主线的部分已落地。通过盲玩验证这种侧重是否比采矿主导更有吸引力。**2026-10-08 拍板**：矿工不做常驻（定位=未来某一关的关卡小机制），本轮外测不存在采矿附加分——「采矿主导」对照口径就此移除，侧重按「机器人扫雷为主线」单一口径验证。

**单局节奏（已确认，2026-09-30 盲测批次修订）**：时限**按关配置**，不再统一 90 秒——L1 教学关无时限；L2 120s / L3 150s / L4 180s / L5 210s（原 90/120/150/180，实机盲测后全线 +30s，提交 903757f）。通关目标提前达到时，按剩余时间增加结算分数（×3/秒）；到点立即退出并正常结算、保留当局获得的收益，显示"时间到"，不显示"失败"；未达标可重玩，达标后才解锁下一关。剩余时间正是追高分的空间。**已落地**：到点/命尽=强行停止并正常结算（非失败态、给矿、可重玩、不解锁）。

## 目标与验收边界

先交付一个可供目标玩家独立游玩的 Windows 封闭试玩包。玩家不需要安装 Godot；解压后能启动，第一关就体验「扫雷判断 → 亲手购买开格/标雷机器人 → 看机器人推进棋盘 → 检测与采矿获得附加分 → 结算」，随后在关卡中学习再投资与布局，并能反馈遇到的问题。建议以 5 关、约 15–25 分钟作为第一轮内容目标，实际时长由盲玩结果校准。

封闭试玩通过后，再推进公开 Demo、商店页与宣传素材。公开 Demo 的质量门槛高于第一轮外测包；Steam 官方也分别提供受控 Playtest 与公开 Demo 的发布方式。

## 调研依据

- [Steamworks：Demos](https://partner.steamgames.com/doc/store/application/demos)：Demo 应提供有质量的核心玩法样本；公开试玩影响玩家购买判断。
- [Steamworks：Steam Playtest](https://partner.steamgames.com/doc/features/playtest)：受控外部测试可单独于公开 Demo 运行。
- [shapez 2 开发者的 Demo 公告](https://www.reddit.com/r/shapezio/comments/1942jp1/shapez_2_demo_announcement/)：限定内容范围，提供教学、随时可查的帮助和反馈入口。
- [Dome Keeper 开发者的 Demo 更新](https://steamcommunity.com/app/1637320/discussions/0/3418809548714284918/)：试玩阶段集中修复问题、调整平衡与教学。
- [Godot：导出项目](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_projects.html)与[许可说明](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html)：建立可重复的 Windows 导出与随包声明。
- [14 Minesweeper Variants 的开发者商店页](https://store.steampowered.com/app/1865060/14_Minesweeper_Variants/)与[Tametsi 的开发者商店页](https://store.steampowered.com/app/709920/Tametsi/)均强调新规则的逻辑学习和无需猜测的关卡。**对本项目的推断**：面向扫雷玩家时，应明确盘面推理质量与猜雷规则，并把教学时间用于本项目新增的机器人系统；是否完全排除猜雷仍在第 1 步讨论。
- [DemonCrawl 的开发者商店页](https://store.steampowered.com/app/1141220/DemonCrawl/)介绍自动扫雷模式，让玩家转而关注道具策略与经济；[《扫雷R》的开发者商店页](https://store.steampowered.com/app/4368600/)则以技能组合快速清理雷区为卖点。**对本项目的推断**：机器人扫雷加投资具有可理解的卖点，但这些作品不能证明扫雷老玩家会喜欢采矿主导；需要本项目的盲玩检验。
- [Factorio 开发日志 #327](https://www.factorio.com/blog/post/fff-327)讨论手动操作到自动生产、再到自动物流的渐进体验；[开发日志 #284](https://www.factorio.com/blog/post/fff-284)讨论自动化需要明确目的与资源压力。**对本项目的推断**：用短暂的手动扫雷建立需求，再让机器人接管重复劳动，并以资金、产出和运输反馈支撑运营决策。
- [任天堂《Super Mario 3D World》官方说明书](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/wii_u_6/super_mario_3d_world_3/ElectronicManual_WiiU_SuperMario3DWorld_EN.pdf)说明通关时按剩余时间奖励分数。**对本项目的推断**：提前达标时显示时间换分能让速度与高分直接关联；到点也结算已有收益是本项目的规则。
