## 1. 定位一句话

第一关学会"买机器人"，这一关学会"让机器人变快"：开局就买得起升级，钱多到不断面临"再加一台，还是全体提速"的选择。

## 2. 教学目标

玩家离开本关时应理解的事（按出场顺序）：

1. 真实规则首登场：120 秒时限（v1.3）、3 条命、到点/命尽即不过关（可重玩）
2. **升级 = 花钱让全体同类机器人变快**（可重复买、每轨三档、买完立刻见效）
3. 钱的用法变多：机器人（翻倍价）/ 升级 / 基地——没有标准答案
4. 时间加分进结算：剩余秒 ×3

## 4. 全流程剧本

| # | 触发 | 发生什么 | UI / 文案 |
|---|---|---|---|
| 0 | 进关 | 预设基地、预开、倒计时与命首次亮相；商店开着，升级行可见 | "120 秒，3 条命，清空安全格。"（v1.3 同步） |
| 1 | 开局 | 玩家有 5 次免 CD 操作；开局已送 opener + marker，起始 100 恰好够买双轨 Lv1 升级 | 商店升级行高亮："机器人可以更快。" |
| 2 | 首次升级生效 | 买完 Lv1 机器人迈步间隔 2.0→1.6s，肉眼可见变快 | "更快了。"（跳字即可） |
| 3 | 中段钱涨 | 钱到 70/100/200 时对应按钮亮起；玩家自选：Lv2/Lv3、第 2 台机器人、建基地——**考题时刻，无标准答案** | 无文案 |
| 4 | 冲刺 | 高速军团清盘；零散格玩家用 3s CD 收尾 | 无文案 |
| 5 | 清空安全格 | 胜利 → 结算 | 四行：开格分 / 标旗分 / 人机占比 / "剩余 X 秒 +3X 分" |

## 5. 边界情况与处理

| 情况 | 处理 |
|---|---|
| 到点未清完 | 不判负：正常结算、保留局外收益，但**不算过关**、不解锁 L3，可重玩 |
| 3 命尽 | 强行停止并正常结算（同到点，非失败态），保留局外收益，不算过关，可重玩 |
| 只加机器人不升级 / 只升级不加机器人 | 两条路线都应能过关（验收 §8.3） |
| 升级购买时机器人正在行走 | 全局即时生效，含在途机器人 |
| 5 次免 CD 未用完就买机器人 | 不冲突，并行使用 |
| 拒绝升级硬点 CD | 120s 内 ≈ 5 免费 + ~35 次 CD 操作，远不够清 172 格 → 到点重玩，不死锁 |
| 踩雷 | -1 命 + 该格坍塌（视为已开可走） |
| 标错旗 | 无奖励无惩罚（少挣 5 钱），不扣命；旗可撤 |

## 6. 教学文案（定稿）

1. 开局："120 秒，3 条命，清空安全格。"
2. 开局商店高亮："机器人可以更快。"
3. 首次升级生效："更快了。"
4. （约 30s 仍未买任何升级）："升级：所有机器人提速。"

文案原则：全关 ≤ 4 句，每句 ≤ 15 字；升级效果不用文字解释，用速度变化和跳字自证。

## 7. 盘面验收标准（转交执行侧）

固定盘面需**同时**满足（不指定具体布局，由执行侧烘焙；工具原型 `tmp/level1_board_finder.py` 换参数复用）：

1. 全程可用现有 2 条基础规则推完：无歧义（不被迫猜）、不需要子集推理
2. 密度 24/196 ≈ 12.2%
3. 预开约 35-45% 格（含洪水连锁）
4. 开局（预开后）存在 ≥5 个秒推级可动作目标（可推旗或规则 1 可开格），让 5 次免费操作有活干
5. 至少出现一次 ≥6 格连锁展开（机器人高光）
6. 最后打开的格子距基地 ≥3 格（玩家收尾节拍）

## 8. 经济与节奏验收（L2 特有，转交执行侧）

1. 起始 100 + 赠送一对（v1.3）：开局即从"要不要升级"开始，首升级零门槛
2. 终身预算闭环（v1.3 口径）：全清收入 292 + 300（L3 起始基准）= 592 ≥ 双轨全满 440 + 增购机器人 + 余量；本关内 292 + 100 ≈ 392 买不满双轨全满——"升级到底还是添机器"的取舍贯穿全程
3. **双路线可行**：solver 模拟"全升级满 + 2 台"与"3-4 台 + 部分升级"两条策略均能在 120s 内清完（模拟基线为 90s 版，+30s 后余量更宽）
4. 升级体感断层：每档速度差在同类任务往返时间上 ≥15%，肉眼可辨
5. 命充裕度：按 2 规则正确推进 0 踩雷，3 命纯作失误缓冲
6. 价位抉择密度：Lv3（100）≈ 第 2 台机器人（100）≈ 基地（80）落在同一价位带

## 9. 实现需求清单（转交执行侧）

1. 升级两轨改价 50/70/100、扩为三档速度（现行 `upgrade_panel.gd` 为 100/200 两档、另有折扣轨需按关卡隐藏）
2. 速度档位值参数化（2.0/1.6/1.3/1.0 初值）
3. 开局 N 次免 CD 的一次性机器人 → 通用 CD 系统（与 L1 的耗尽机制同源，关卡可配）
4. 命系统：踩雷 -1 命、命尽=强行停止结算（非失败）、重玩流程（试玩版首次出现）
5. 时限与时间加分接入结算（剩余秒 ×3，系数关卡可配）
6. 商店白名单：opener / marker / 基地 / 两轨速度升级；折扣轨隐藏
7. 剧本控制器：开局升级行高亮、30s 未升级兜底提示
8. 关卡参数化：起始资金 / 时限 / CD / 免费次数 / 命数 / 商店价目表
