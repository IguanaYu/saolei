## 1. 第五关想传达什么

- 整个外部试玩版要让玩家看到「扫雷 + 自动化投资」未来能扩展成丰富的关卡内容。第五关承担展示高潮：打完以后，玩家期待后续的敌人、棋盘变化、机器人与投资组合。
- 用户偏好类似《马里奥》的三阶段／三滴血 Boss：每阶段有一件容易理解的事，Boss 出招，玩家利用已有能力应对，甚至借 Boss 的攻击反过来伤它。
- Boss 本体在棋盘外缘，像爬在地图上；攻击伸入棋盘。用户没有要求炮台、瞄准、投掷或让机器人定向攻击 Boss。
- 三阶段随棋盘状态变化：开局未开格多，攻击未开区域；中段已开地面增多，攻击通路和机器人；末段围绕剩余墙体、旗子和收尾路线。
- 玩家或机器人正确标雷、玩家处理 Boss 招式，均可以对 Boss 造成伤害；最终找出所有地雷后 Boss 失败。这是方向，伤害和阶段门槛尚未定。

这与[页面布局与实施计划](../外部试玩版-v0.1-页面布局与实施计划.md)中「第五关无新系统」「虫害、保安、探测不进入五关」的旧范围提案冲突。用户现在提出第五关 Boss 和相应机制；待设计定稿后同步主计划、关卡数据和界面文案。目前 `ch01_s05` 仍是旧的存活／禁标雷模板，不能视为本方案实现。

## 2. 用户提出的三阶段骨架

| 阶段 | Boss 的动作 | 玩家可做的事 | 预期作用 |
|---|---|---|---|
| 第一阶段：墙体尚多 | 放出 **2 只史莱姆**。它们在未开墙体上缓慢移动，走过处留下黏液；黏液让开格变慢。走到已开地面后，黏液让机器人移动变慢 | 正常扫雷、推进到史莱姆附近，再点击杀死它们；机器人帮助开格 | 迫使玩家继续开路，而非只盯 Boss 血条 |
| 第二阶段：已有较大开区 | 从棋盘外向**已开地面**落下定时炸弹。玩家点击炸弹，它飞回去炸 Boss；未点击则数秒后爆炸，形成持续数秒、以落点为中心的一格十字火区。火区挡路，区内机器人不能动 | 及时点弹；若落弹爆炸，可亲自清火、让保安清理，或等待火自然退散 | 玩家在反击与维持机器人通路之间做时间和投资选择 |
| 第三阶段：预计已开约 70% | 向剩余未开墙体抛锁，向已开通路伸出挡路触手；落弹等旧招也可继续出现 | 解锁、清触手、继续开格与标雷；正确标雷或处理招式持续伤 Boss | 最后一段扫雷与运营收尾；全部雷位找出后击败 Boss |

「已开约 70%」是用户描述的预期局面，不是硬性阶段阈值。具体用 Boss 血量、关键招式完成、已开比例，还是组合条件切阶段，待设计。

## 3. 玩家实际能控制的东西

以当前代码为基准，供反推 Boss 攻击时使用：

| 控制面 | 玩家能做什么 | 边界 |
|---|---|---|
| 棋盘操作 | 选格开格、插／撤旗、数字格和弦；现有敌害可点击、障碍可点击清除 | 玩家有效操作受免费次数和 CD 约束；猜雷可能损失生命 |
| 投资 | 决定何时买哪种机器人、购买数量、局内升级；在可用位置放机器人和基地 | 机器人价格随同类购买次数上涨；钱与积分分开 |
| 间接引导 | 手动开格或标雷创造机器人可推理的目标；初始放置和基地位置影响路程 | 机器人自主找最近的确定目标；玩家目前不能给机器人下达前往某区、攻击某敌人的命令 |
| 检测与矿工 | 购买、初始放置；通过标旗和矿脉形成工作机会 | 检测机器人自主找旗；矿工自主找最近矿脉并回最近基地，玩家不能指定运输目标 |
| 保安（当前 L4 实现） | 可购买，自动巡逻和清理虫、锁、网、黏液 | 只在已开区寻路；当前尚不认识第五关的新炸弹、火区和触手 |

因此，Boss 招式宜落在玩家已有的回应范围：继续开格、手动关键操作、清障、调整投资和基地。指定机器人追击某个弱点、投掷炸弹等需要全新控制层，当前构想没有依赖它们。

相关实现：[机器人自主选目标](../../../scripts/robot.gd)、[矿工自主采运](../../../scripts/robots/miner_robot.gd)、[保安行动](../../../scripts/robots/guard_robot.gd)、[局内放置与点击](../../../scripts/main.gd)。

## 4. 候选招式库

以下均为**备选**，不是建议在一关里全部投放。名称、伤害、数量和持续时间都可改。

### 4.1 作用于未开墙体／开格前沿

| 招式 | 场上发生什么 | 可回应的方式／趣味点 |
|---|---|---|
| **钻岩史莱姆**（用户核心提案） | 两只史莱姆在未开墙体上爬，沿途留下开格减速黏液；到了已开地面，黏液拖慢机器人 | 玩家开路接近并点杀；保安只有在目标进入可达已开区后才能发挥作用 |
| **孵化卵** | Boss 把卵粘在未开墙体；倒计时后孵出史莱姆 | 开到卵附近先点掉，或承担孵化后的虫害 |
| **墙内蜂巢** | 能看到墙内巢的搏动；巢存活时定期放小虫到已开区 | 玩家追溯小虫来源，推进前沿毁巢；保安负责已出来的小虫 |
| **孢子钉** | 一颗孢子钉进未开墙体，逐渐向周围扩散黏液 | 开到源头附近拔掉，或绕开慢区 |
| **钻地背鳍** | 墙下有可见的移动轨迹，经过处留黏液，偶尔在已开区边缘露头 | 玩家开路追击，并在露头窗口点击 |
| **岩壳雨** | 几块未开格被砸上硬壳，正常开格前要多一次开凿 | 手动敲壳、增加开格产能或先从另一侧推进 |
| **塌方预告** | 某条墙体先出现明显裂纹；过一段时间才落下岩壳 | 玩家可抢先处理有把握的格子；形成可预见的时间压力 |
| **巨齿啃墙** | Boss 从地图边缘啃过墙体，留下岩屑与明显裂纹／线索 | 攻击拖慢附近机器人，同时可能暴露可利用的信息；可沿线开路再清岩屑 |
| **墙内计时源** | 可见的墙内器官暂时加长玩家操作 CD | 玩家推进到源头点掉；机器人仍可继续作业，形成手动／自动化选择 |

### 4.2 作用于已开地面／机器人通路

| 招式 | 场上发生什么 | 可回应的方式／趣味点 |
|---|---|---|
| **定时落弹**（用户核心提案） | 炸弹落在已开地面；点击即反弹伤 Boss，放任则爆成短暂十字火区 | 反弹、手动／保安清火，或等它退散；「落弹」要明显区别于棋盘原有地雷 |
| **滚雷** | 炸弹沿已开通路缓慢滚向基地 | 点击弹回 Boss；保安可拦截；抵达基地则短暂停工 |
| **弹跳爆弹** | 落弹在已开地面之间跳动，落点提前用阴影预告 | 玩家抓准点击窗口；漏掉留下火区 |
| **磁吸球** | 落在已开地面，把附近机器人吸在原地 | 玩家点碎或保安清理；其他机器人／手动操作仍可推进 |
| **磁钩** | Boss 钩住一台机器人，逐渐把它拖离工作位置 | 点击或保安剪断钩索；漏处理损失路程，不永久损失机器人 |
| **捕虫网** | 一张网罩住某台机器人，使其停工，但不盖住棋盘数字 | 玩家／保安解救，决定是否立即救这台机器人 |
| **遮眼雾** | 遮住几个已开数字，机器人暂时少了推理依据 | 玩家点散、保安清除，或从其他可见数字继续推理 |
| **踏地冲击** | 已开地面先出现大爪影；Boss 踏下后把范围内机器人震回最近基地 | 在预告期打断、承受位移，或靠基地位置减少返程 |
| **倒挂钟摆** | Boss 的尾巴按可见节奏扫过一条已开通路，推回经过的机器人 | 点击根部令它停一轮，或从另一侧布置基地 |
| **时间砂漏** | 落下一座小砂漏，范围内玩家操作 CD 延长，机器人仍正常工作 | 点碎、让保安处理，或暂时依靠自动化 |
| **吸金口／盗矿口** | 附着在基地附近，截取下一次矿工卸货或部分收入 | 玩家／保安拆除；仅适合有明显采矿路线的配置，不应让未买矿工的玩家遇到无感攻击 |
| **黏液潮** | 从 Boss 所在边缘缓慢扫过已开地面，留下短期减速带 | 玩家清源头、保安清理局部、投资速度或等其消退 |

### 4.3 作用于剩余墙体／残局路线

| 招式 | 场上发生什么 | 可回应的方式／趣味点 |
|---|---|---|
| **锁链投射**（用户核心提案） | Boss 给剩余未开墙体上锁，暂时不能开也不能标 | 玩家点击解锁；保安在可达射程内拆锁 |
| **触手栅栏**（用户核心提案） | 触手横跨已开通路，阻止机器人经过；玩家仍能操作棋盘 | 点断根部、保安清理，或从另一侧增建基地 |
| **双头锁链** | 两块未开格被同一条链连接，点断中间扣环即可一起解锁 | 一次动作恢复多个工作目标，形成显眼的拆解反馈 |
| **夺旗蛾** | 飞过已开区并暂时卷走若干旗，机器人可能因缺旗停工 | 玩家／保安击落后旗自动归位；已得奖励不被重算 |
| **基地钳** | 钳住一个基地，暂时阻止矿工卸货或新机器人从此出发 | 点击／保安解救，或利用第二基地 |
| **回收触手** | 抓一台机器人，数秒后将其扔回基地 | 点根部解救；漏掉只损失作业时间 |
| **蓄力锚点** | Boss 在已开地面插数个锚点，开始蓄力大范围阻路攻击 | 玩家／保安拆掉任意锚点即可打断；拆得早保住更多工作时间 |
| **雷纹导线** | Boss 把发光导线铺过剩余墙体；导线范围内正确标雷使电流反噬 Boss | 玩家推理或标雷机器人找到雷，借 Boss 的装置打伤它 |
| **节拍脉冲源** | 一个可见器官按节拍让附近机器人短暂停工 | 玩家点击源头、手动补关键动作或改投资，形成最后阶段的节奏压力 |

## 5. 跨招式组合灵感

- **火清黏液**：玩家也许会选择不反弹落弹，让火区烧掉第一阶段留下的黏液；代价是机器人暂时不能通行。
- **火烧触手**：第三阶段若继续落弹，火区可以烧断挡路触手。反弹伤 Boss 与让炸弹在场内爆开清路成为两种可理解的选择。
- **Boss 攻击露线索**：巨齿啃墙或塌方可以制造开路信息，玩家利用 Boss 自己造成的局面推进扫雷。
- **保安的分工**：可考虑让保安自动灭火／拆障，但由玩家亲自点击反弹炸弹，保留第二阶段最直接的参与感。保安的具体能力仍待定。
- **普通扫雷与招式伤害并存**：正确标雷提供稳定伤害，处理史莱姆、反弹落弹、剪断触手给大额伤害与强反馈。具体是否用连续血条、三段血，或「每段血 + 关键事件」尚待比较。

## 6. 早期探索过的其他 Boss 结构

这些提案出现在三阶段骨架明确之前，保存在此供后续取用，**不覆盖用户现在的方向**。

| 提案 | 核心想法 | 讨论后看到的限制 |
|---|---|---|
| 扫雷即开火 | 开安全格／正确标雷给炮台充能，自动射击 Boss | 用户没有要求开炮；仅把进度映射成血条，缺少 Boss 攻击被反用的互动 |
| 三弱点区 | Boss 身体部位与棋盘区域绑定，区域扫雷后破甲 | 当前机器人自动找最近确定目标，玩家不能可靠指定军团攻某区 |
| 挖矿造炮弹 | 矿工运输为大伤害蓄弹 | 可能使检测和矿工成为固定购物清单，挤压多种投资路线 |
| 破盾爆发窗口 | 扫雷破盾、短时间提高后续扫雷伤害 | 有节奏变化，但玩家需要一个清楚的操作回应，避免只看数值上涨 |
| 数字格反弹炸弹 | Boss 的炸弹压住已开的数字；解决该数字附近的扫雷局面便自动反弹 | 有扫雷关联，但用户后来提出的「点落弹／漏接留火」更直接、动作更鲜明 |

调研时见到的近邻例子：[Spell Sweeper](https://store.steampowered.com/app/1800120)把开格、插旗用于战斗；[Peglin](https://store.steampowered.com/app/1296610/peglin/)让核心操作产生伤害。它们只说明「核心操作转化为战斗反馈」有可理解的先例，不能替本项目验证上述招式的可玩性。

## 7. 还没拍板的关键规则

1. **阶段触发和伤害**：三段血如何吸收普通正确标雷与机制伤害；两只史莱姆、反弹炸弹、最终雷位完成是否各自为必经阶段事件；避免玩家太快标雷而跳过整段演出。
2. **第一阶段可攻击距离**：若玩家必须开路接近史莱姆，应明确何时允许点击，避免在未开墙体深处隔空点死。点击史莱姆还应优先于点击其下的未知格。
3. **黏液如何减慢开格**：玩家点击、机器人工作、零格洪水开区分别如何计算；在已开地面则是移动减速。要让减速来源和清理方式可见。
4. **落弹与普通地雷**：落弹只作为 Boss 攻击落到已开地面，不改变棋盘真雷和数字；预告、反弹窗口、点击 CD、同时在场上限与火区时长需模拟。手动清火、保安清火和等火退散的成本应不同。
5. **火区与保安寻路**：火区若使机器人不能经过或把区内机器人冻住，保安仍需有可达的清理位置；临时阻路不能形成永久死锁。
6. **最终「所有雷」的口径**：当前踩中的雷会坍塌并无法再插旗；检测后的正确旗会转为矿脉并撤旗。因此目标宜定义为「全部雷位已处理／已确认」，并明确正确旗、矿脉、确认雷、坍塌雷如何计数，或修改相关行为。
7. **残局可能已无未开墙体**：第三阶段的锁必须有目标可投；若棋盘提前开得很快，触手／基地钳等已开区招式可承接阶段，不应突然无招可出。
8. **可推理性与时长**：若要求找出所有雷，需设计或筛选可解盘面，并验证有限时间内三阶段加起来能完成。试玩计划原以 90 秒为目标，Boss 关的时长、阶段转场是否停表，都需要实际模拟和盲玩校准。
9. **范围**：第五关是否第一次开放保安；L4 原除害关与新版布局关的关系；新 Boss 能力是只在第五关试一次，还是后续关卡可复用，待与主计划统一。

下一轮可从候选库里选三到五招，先画出「Boss 预告 → 落点 → 玩家可回应 → 成功／失手后果」的完整循环，再决定血量、时间与实现顺序。

## 8. 第二场图鉴：按「攻击层 × 转化出口」组织

本场提炼出的设计语法（可继续量产同类设计）：

> **Boss 每招攻击盘面某一层（显示／标记物／经济／劳动成果／机器人，永不碰棋盘真值），并留一个「转化出口」——威胁物经玩家之手变成伤害。** 转化出口必须经过玩家的三种瞄准之一：
> - **推理瞄准**（标哪）：正确标旗、detector 确认
> - **入口瞄准**（点哪开）：开格位置、洪水走向
> - **布局瞄准**（放哪）：机器人与基地的放置
> - 外加**亲自档**：玩家直接点击（消耗 CD）
>
> 该语法是方法论 §4 压力源六问与 §5 验证四问的正面应用；「炸弹人扔回库霸王」是所有转化的原型。

### 8.1 显示层（信息攻击——「机器人瞎了，玩家没瞎」）

| 生物 | 场上发生什么 | 转化／趣味点 |
|---|---|---|
| **数字吞噬蛾** | 叼走一个已开数字，格子空白数秒，依赖该数字的机器人卡壳 | 玩家凭记忆照常推理；点死蛾子数字归位＋伤害。玩家的记忆成为机器人没有的武器 |

### 8.7 可直接缝进主案的两个小改件

1. **「雷是它的牙」框架**：终幕揭示 40 颗雷是它咬进盘面的牙——标雷＝拔牙，标完最后一颗＝嘴合不上，触发斩杀演出。给「标完所有雷＝胜利」一个叙事锚点，机制零改动；
2. **攻击窗口律**：全局规则——Boss 每次伸爪／空投的瞬间，本体受击伤害翻倍。所有招式自动统一成「它出手 → 你反打」的攻防律动。

## 9. 第三场图鉴：按栖息地组织 + Boss 节拍机制

### 9.4 Boss 机制（节拍器与器官）

| 机制 | 内容 | 作用 |
|---|---|---|
| **呼吸窗口** | Boss 每波必须「换气」：盘框上开启一个器官 6 秒，期间受伤 ×3；平时打本体只有 1/3 效率 | 战斗节拍自动成型：**平时推理攒旗，窗口期倾泻输出**。怪猎 wound 循环的扫雷版 |
| **狂暴读条** | Boss 读 12 秒大招（进度条可见），全屏级别威胁 | 打断条件＝读条期间完成一次正确标旗／杀一只小怪——**你的核心动作就是打断技** |
| **踉跄** | 吃到一次大伤害（反弹雷、器官窗口爆发）后硬直 2 秒：全场小怪冻结、引信暂停 | 大操作买喘息——「刚才那波赚了」的体感来源 |
| **触手扫击** | 预警 3 秒后横扫一行／一列，扫中机器人击退＋定身 | 未开的墙列是天然防波堤——**留墙当掩体还是开掉换进度**，一个新的取舍 |
| **Boss 换位** | 波间从盘框一侧爬到另一侧，投放方向和器官位置全变 | 一条移动逻辑＋换生成点，实现极便宜，但战斗的空间感活了 |
| **金脉虹吸** | 触手直接缠上基地抽钱 | 火力抉择：打触手（保经济）还是打本体（抢进度）——集火决策 |
| **召唤预告** | 出招前手势可读：亮爪＝史莱姆、吸气＝空投雷、低吼＝虫群 | 读招＝备战（先买保安？先散开？），波与波之间有了决策间隙。纯 UI 成本 |

### 9.5 主案 P2 的一个升级件

空投雷直接落在**数字格**上：数字被压住看不见，引信在「信息被剥夺」的压力下逼你决定；抢在爆炸前点掉＝反弹伤害＋数字复位。这样空投雷和扫雷推理长在同一根骨头上。

### 9.6 组合律（免费的内容量）

每个小怪只管一招，两两嵌套自己长出新玩法：**滚石×粘液**＝打滑加速道、**水母×矿工**＝引它离开矿区、**真菌塔×锈旗×detector**＝协议攻防战。Boss 战出怪用「1 老带 1 新」公式，每个阶段都能翻出新意而不加系统。

## 10. 两场图鉴的入选候选（下轮筛选起点）
