## 1. 定位一句话

全系统期末考 + 试玩版高潮：一只趴在盘框上的巨兽把牙埋进了墙里——**你的扫雷进度就是它的血条**，拔完最后一颗牙，它松爪掉下去。

## 2. 教学目标

玩家离开本关（和整个试玩版）时应理解的事（按出场顺序）：

1. **雷就是它的牙**：正确标雷/探测确认/踩塌一颗 = 拔一颗牙；扫雷推进 = 打 Boss，两个进度条是同一个
2. **Boss 的每招都落在已学能力上**：史莱姆（黏液，L4 减速虫同款）→ 炸弹/火区（点击清障，亲自档）→ 锁（L4 同款）+ 触手（点击断根）——没有新控制面
3. **CD 银行第一次真正吃紧**：点杀、反弹、解锁、断触手、自己标旗全从同一个 7 层银行扣——五关里第一次「次数不够花」
4. **军团运营在干扰下的韧性**：基地选址（Boss 侧 vs 远侧）、保安分工（保安不碰炸弹/火/触手）、探测兜底（情报穿锁，P3 卡壳救急）
5. **处理完全部雷 = 斩杀演出 → 试玩完成页**：给「标完所有雷 = 胜利」一个叙事锚点，收束整个试玩版

## 3. 核心机制：牙齿 = 血条

**Boss 没有独立血条。它剩余的血量 = 尚未处理的雷数（20 颗牙）。**

| 处理方式 | 判定 | 备注 |
|---|---|---|
| 正确标雷（玩家/标雷机器人） | 旗→矿脉（现行转换，旗面消失） | 主输出口，机器人可代劳 |
| 探测确认雷（probe，100/次） | `is_confirmed_mine` 现行标记 | 花钱买牙；穿锁有效 |
| 踩雷坍塌 | 该格坍塌（现行） | 也算拔牙，但 **-1 命**——疼着拔 |

- **HUD**：目标进度行直接显示「拔牙 (X/20)」，复用现有 objective progress UI（v1.1：目标行配牙图标）；**Boss 本体血条**（v1.1 盲测后加）横贯下腹、P2/P3 门槛处白色阶段刻度——数据同源仍是牙数，无第二套血量
- **口径**：`FIND_ALL_MINES`（新目标类型）= 上述三种集合的并集计数；撤旗不回退（正确旗即时转矿脉，无从撤起）
- **为什么不用独立血条**：①扫雷即战斗，杜绝「只扫雷不打 Boss」与「只打 Boss 不扫雷」的割裂；②机器人标旗 = 团队输出，投资-战斗一体（本作核心论点）；③少一套 UI

**三阶段由牙数驱动**（扫雷进度的天然代理，对应头脑风暴 §1「三阶段随棋盘状态变化」）：

| 阶段 | 牙数区间 | 盘面预期 | 主题（每阶段一件事） |
|---|---|---|---|
| P1 墙上 | 0–5 颗已拔 | 墙体尚多 | **开路接近**：杀史莱姆，别让它糊满黏液 |
| P2 空中 | 6–11 颗已拔 | 开区已大 | **亲自档**：接炸弹，弹回去伤它 |
| P3 收尾 | 12–20 颗已拔 | 剩墙零星、接近全处理 | **清障收尾**：拆锁、断触手、拔完最后的牙 |

- 转场 = 演出 2s（Boss 后仰/换位），**不停表**，出招暂停 3s
- **速通跳阶段是技术奖励不是 bug**：牙数到线即转场，残留史莱姆/火区不消失、带入下阶段自然衔接（头脑风暴 §7-1 逐条回应见 §8）
- 防呆：探测可加速拔牙（花钱推阶段），但 20 颗全买 ≈ 2000，价格自限

## 5. Boss 与三阶段详设

每招都按头脑风暴 §7 要求给出完整循环：**预告 → 落点 → 玩家回应 → 成功/失手后果**。全部招式只碰速度层/交互层/显示层/通路层，**永不碰棋盘真值**（雷位、数字不变）。

### 5.1 P1 · 钻岩史莱姆（复用敌虫 + 黏液系统）

| 循环 | 内容 |
|---|---|
| 预告 | Boss 亮爪 1.5s（召唤预告，纯 UI/姿态），随后 2 只史莱姆从 Boss 侧盘边爬入（t=15s / 18s，初值） |
| 落点 | 沿**未开墙体顶面**爬行（~2.5s/格），偏向 frontier 方向游走；沿途墙体格染黏液（`is_slimed`，L4 现行状态） |
| 玩家回应 | **点击击杀（1 CD）**。可点击条件（2026-10-05 与 L4 敌虫/巢统一）：史莱姆所在格或邻 8 格属**玩家领土**——从基地沿已开格 8 连通（`Grid.player_territory`），**必须开路接近，不能隔墙点死**，孤立开格不算领土（头脑风暴 §7-2）。点击优先级高于其下未知格；未达时点击被拦截、不耗 CD，本体压暗提示 |
| 失手后果 | 黏液留存：3×3 内机器人移动/工作 ×2（现行语义，不叠乘）；史莱姆爬进已开地面后继续糊黏液，拖慢军团；保安可射杀进入已开区的史莱姆（现行「虫进已开区才可射杀」） |
| 成功奖励 | +10 钱 +10 分/只；Boss 硬直 3s（出招暂停） |
| 补刀压力 | P1 期间每 30s 若场上史莱姆 <2 → 补至 2 只（防止阶段拖长后无事发生）；**阶段转场后不再补充**，残兵带入 P2/P3 自然衰减 |

- 史莱姆 = 减速虫换皮（敌虫系统 + 黏液格现状），实现便宜（头脑风暴 §10「蛾/蠕虫≈虫系统换皮」同源判断）
- 墙上黏液的清理：靠近已开区后保安可清（现行：保安可打 slime 格）；深处墙体黏液随开格推进自然进入保安射程——无需新增逻辑

### 5.2 P2 · 定时落弹 + 十字火区（新实体；数字遮罩复用网）

| 循环 | 内容 |
|---|---|
| 预告 | Boss 吸气 1.5s（背脊弹舱张开）→ 落点阴影 1.2s → 落弹 |
| 落点 | **已开格，70% 优先数字格**（§9.5 升级件：数字被炸弹压住不可读，遮罩口径同织网——机器人失去该依据）；排除：基地格、机器人当前格、火区内、已有炸弹格、触手格 |
| 玩家回应 | **点击炸弹 = 反弹飞回 Boss（1 CD）**：+15 钱 +15 分，Boss 硬直 2s，下次出招顺延 +7s——反击奖励是「节奏松一口气」而不只是钱 |
| 失手后果 | 引信 5s 走完 → 爆炸：落点为中心**十字 5 格火区，持续 8s**。火区 = 机器人禁入（寻路视为障碍），点燃瞬间区内机器人被震退至最近已开安全格；玩家棋盘操作不受火影响 |
| 火区处理 | **点火区任一格 = 整片熄灭（1 CD）+5 钱 +5 分**，或等 8s 自然退散；**保安不管火**（亲自档保留给玩家，头脑风暴 §5「保安的分工」） |
| 节拍 | 首弹 t=转场+5s，此后每 18s 一颗，**同场 ≤2** |

- **火清黏液**（头脑风暴 §5 组合灵感）：火区覆盖的黏液格被烧毁——P1 拖下来的黏液债在 P2 有了第二种还法：故意漏接一颗炸弹烧掉黏液带，代价是通路被切 8s。「漏接」从失误变成可选策略
- 炸弹视觉必须与棋盘地雷**强区分**（头脑风暴 §7-4）：黑铁壳 + 燃烧引信 + 落点阴影，不进格子层

### 5.3 P3 · 锁链投射 + 挡路触手（锁复用 L4；触手为新实体）

| 循环 | 内容 |
|---|---|
| 预告 | Boss **换位**：从上侧盘框爬到右侧（2s 动画，头脑风暴 §9.4「Boss 换位」），低吼 1.5s |
| 锁链投射 | 每 25s 向**剩余未开墙**抛锁 3-5 格（随机、跳过已锁格）。锁 = L4 现行：谁都不能开/标，点击解锁 1 CD，保安射程内可拆，**探测情报穿锁**（P3 卡壳救急的正解） |
| 触手栅栏 | 每 30s 一条，**同场 ≤2**：从 Boss 所在侧沿一行/一列的连续已开格伸入 4-6 格；机器人不可经过，玩家棋盘操作不受影响。**点根部（靠盘边那端）= 整条断裂（1 CD）**+15 钱 +15 分；12s 不处理则自然缩回 |
| 落弹降频 | 每 35s 一颗、同场 ≤1（用户骨架 §2「落弹等旧招也可继续出现」）——P3 是混合压力终考 |
| 成功奖励 | 解锁/断触手的钱分见上；Boss 每吃一次硬直 2s |

- P3 的主题是**收尾意志测试**：锁锁的是最后的墙，触手切的是最后的通路，炸弹添乱——但牙一颗颗拔完的进度感始终可见（X/20 一直在涨）

### 5.4 斩杀

第 20 颗牙拔掉瞬间：全场小怪/障碍冻结 → Boss 咬合不住、盘框松爪、掉落（3s 演出，EffectsLayer 高光时刻）→ 胜利结算 → 试玩完成页。台词见 §8。

## 7. 边界情况与处理

| 情况 | 处理 |
|---|---|
| 玩家速拔 5 颗牙（P1 极短） | 到线即转场，史莱姆不消失带入 P2——跳过的是演出时长不是内容；极速清盘是技术奖励 |
| 探测速推阶段（花钱买牙） | 合法策略；全买 20 颗 ≈ 2000，价格自限；开区不足时见下条 |
| P2 开始时已开格 <8 | 炸弹无落点：该次出招顺延 10s，期间以史莱姆补位——永有招可出 |
| P3 时未开墙已清光 | 锁无目标：自动跳过该招，触手 + 降频落弹承接阶段（头脑风暴 §7-7） |
| 触手/火区围死机器人 | 二者都有时限（12s/8s），机器人 BFS 不可达时原地待命（现状）——**无永久死锁**；玩家可主动拆 |
| 炸弹落在 frontier 边上 | 合法落点（已开格即可）；爆炸火区不烧未开墙，只占已开地 |
| 踩雷 | -1 命 + 坍塌 = 拔牙（疼着拔）；命尽强停结算非失败，可重玩 |
| 到点 210s | 「它退回了黑暗里」：强停结算、保留收益、不算过关、可重玩（L2-L4 语义） |
| 史莱姆一直躲深处墙里 | 玩家不开路就杀不到；黏液只拖慢不阻断（L4 口径），时间压力兜底；它终会爬向已开区（保安可接） |
| 点穿火区/触手操作棋盘 | 玩家操作不受火/触手影响（点格照常开/标）——它们只挡机器人 |
| Boss 与棋盘真值 | 史莱姆=速度层、锁=交互层、炸弹压数字=显示层（网口径）、火/触手=通路层——**全部不碰雷位与数字**（⑥ 合规） |
| 点击优先级 | 炸弹引信 > 史莱姆 > 锁/网/黏液 > 触手根 > 格子；全部吃 1 层 CD（与 L4 §9-9 同源） |
| 保安能力边界 | 只认 L4 四类（虫>锁>网>黏液）；**不认炸弹/火/触手**——按设计不扩，亲自档留给玩家（头脑风暴 §3 缺口的正面回答） |
| 探测与锁 | 情报穿锁（L4 现行），锁本身仍需清——P3 双工具协同 |
| 暂停/设置 | 沿用现有暂停面板（P9）；Boss 演出不锁暂停 |

## 9. 盘面验收标准（转交执行侧）

固定盘面需**同时**满足（工具原型 `tmp/level1_board_finder.py` 换参数复用）：

## 10. 经济与节奏验收（转交执行侧）

> **离线模拟基线（2026-09-30，`tmp/level5_sim.py`，200 盘/路线，0.5s 逐 tick 模型）**：
> - §10.4/10.6 双路线斩杀率：**路线 A「重军团」78%（155/200）**，通关中位 168s / P90 174s——
>   基线 ≥50% PASS，但 P90 贴近 180s 上限；**路线 B「重亲自」100%**，通关中位 130s。
>   模型未含和弦/目标重排/保安清障，真人强于模型；结论：两条路线均可斩杀，重军团路线更紧。
> - §10.3 阶段时长：A 线 P1 41s / P2 47s / P3 80s——P3 超出 40-70s 目标区间（观察项：
>   P3 混合压力下最后 8 颗牙偏慢，盲测确认；对策排序：门槛 11→9 / P3 出招降频）。
>   B 线 P1 中位 3s 是"玩家秒推开局 5 面 FREE 旗"的模型直译（真人不会 3 秒标 5 旗），速通跳 P1
>   属设计接受的技术奖励（§3）。
> - §10.1 CD 预算：互动点击均值 A 24 / B 48 vs 预算 ≈72——**远未见底**；模型玩家策略保守
>   （必反弹/必清锁/必断触手），真人会漏接与偷懒，实际更紧但仍未见底风险。
> - §10.2/10.5 静态算术 PASS（终身收入 ≈696 < 满配 ≈1100，必须取舍）。

1. **CD 银行算术**（v1.1 口径）：210s ≈ 70 层回充 + 7 层满仓 + 5 次免费 ≈ 82 层预算。需求估算：玩家亲手标旗 5-10 + 点杀史莱姆 4-8 + 反弹 5-8 + 灭火 0-3 + 解锁 3-10 + 断触手 2-4 + 顺手开格 5-15 ≈ **24-58 层**——预算内但 P2/P3 高峰期会阶段性见底，「囤 7 层花存款」的节奏感知是本关核心体感（盲测重点）
2. **钱算术**：起始 300 + 开格（~176）+ 标旗（20×5=100）+ 互动奖励（~80-150）≈ 660-730；对满配（双机器人 ×2 + 4 轨全满 880 + 保安 80 + 基地 80 + 探测 2-4 次）≈ 1400+——买不齐，必须取舍；保安/探测/升级/基地四档同池竞争延续 L4
3. **阶段时长分布**（模拟目标）：P1 40-70s、P2 50-80s、P3 40-70s；若 P1 常态 >90s → 起始资金/预开比例调高，或门槛 5→4
4. **双路线可行**：solver 模拟「重投资军团（机器人标旗为主，玩家纯清障）」与「重亲自（玩家自己拔牙 + 少量机器人）」均应可在时限内斩杀（模拟基线 180s 版：A 线 78%、通关中位 168s/P90 174s——+30s 后 P90 余量打开）
5. 互动奖励占比：Boss 互动收入（80-150）应 ≈ 标旗收入的量级——「打 Boss」在钱上有正反馈但不主导
6. **全程通关率模拟基线**（同 L4 §7 的 `tmp/level4_sim.py` 方法）：初值预期 ≥50%（Boss 关允许比 L4 难，但试玩版最后一关不应卡死多数玩家）；低于 30% 触发调参（对策按代价排序：再加时限 / 门槛 5-11→4-9 / 引信 5→6s；v1.1 已先 +30s 至 210s）
