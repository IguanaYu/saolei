# 外部试玩版 · 第一关设计文档（教学关）

> **版本**：v1.1（2026-09-27 修订：标错旗改为无奖励无惩罚，原 -3 分废除；数值为初值，以盲测校准）
> **上游**：[外部试玩版-v0.1-执行计划.md](../外部试玩版-v0.1-执行计划.md) 第 1 步
> **性质**：内容设计文档——定"玩什么、教什么"。具体盘面烘焙与代码实现由执行侧完成，验收标准见 §7。

## 1. 定位一句话

目标玩家（有扫雷经验）的第一分钟：先用熟悉的扫雷确认"我会"，然后次数用完，亲手买下第一台常驻机器人，看军团把棋盘推完，自己收尾。

## 2. 教学目标

玩家离开本关时应理解的事（按出场顺序）：

1. 左键开格、右键标旗——就是扫雷（零新知识，胜任感确认）
2. 我的每次点击都是**一台一次性机器人**，次数（CD）有限且会耗尽
3. 花钱买的**常驻机器人不占我的次数**，会自己走路干活
4. 我的扫雷动作直接变成购买力（标旗/开格给钱）
5. 结算长什么样：开格分、标旗分、"你的操作 vs 机器人的操作"占比

## 3. 参数总表

| 项 | 值 | 备注 |
|---|---|---|
| 盘面 | 10×10，10 雷，**固定地图** | 约为经典扫雷初级局规格；验收标准见 §7 |
| 预开 | 约 45-55% 格可见 | "地图已经是打开的"体感 |
| 基地 | 预设放好，开局不放基地 | 放基地这个决策推到第 2 关教 |
| 时限 | **无** | 教学关不计时，HUD 隐藏倒计时 |
| 命 | **无限制** | 踩雷仅该格坍塌（视为已开可走），无失败状态 |
| 起始资金 | **75**（初值） | 原则：免费阶段挣到的钱 + 起始资金，在耗尽那一刻**恰好够买一台 opener + 一台 marker（100）**；执行侧按此原则微调 |
| 免费阶段 | 无 CD，可自由点击 | 触发耗尽 = **第 5 面正确旗 或 第 8 次点击**，先到为准 |
| CD | 耗尽后 **30s**/次；**首台机器人购买后恢复 3s** | CD 概念在耗尽瞬间才揭示（此前不显示） |
| 商店 | 仅 opener、marker，**不限购**，翻倍价 50/100/200（2026-10-08 撤「各限购 1 台」：局外「开局送机器人」赠机会占满限购计数，教程购买步必卡死；翻倍价+有限资金即天然上限） | 其余按钮锁死，钱不可能花错 |
| 目标 | 清空全部安全格（90 格） | 经典完局感 |
| 计分 | 标准：开 +1 钱 +1 分；标对 +5 钱 +5 分；标错旗无奖励无惩罚 | 无时间加分（本关无时限） |
| 结算 | 开格分 / 标旗分 / 人机操作占比 | 无星级；首通矿石 200 |
| 解锁 | 通关解锁第 2 关 | — |

## 4. 全流程剧本

| # | 触发 | 发生什么 | UI / 文案 |
|---|---|---|---|
| 0 | 进关 | 盘面预开、基地就位、无 CD 概念 | 仅一句："左键开格，右键标旗"。钱可见，奖励跳字让玩家看见"标旗在挣钱" |
| 1 | 第 5 面正确旗或第 8 次点击 | **次数耗尽**：点击无效，光标出现 30s 恢复环（CD 首次亮相） | "指挥次数用完了" → 高亮商店："雇一台常驻机器人——它不占你的次数" |
| 2 | 玩家购买 | 用自己挣的钱买 opener / marker（顺序自由） | **首购完成瞬间 CD 30s → 3s**："次数恢复：3 秒/次" |
| 3 | 机器人出发 | 走路、开格、标旗；中段触发一次大连锁（机器人高光时刻） | 无文案，奖励跳字自证 |
| 4 | 玩家 CD 恢复 | 远处零散格：机器人走过去要时间，玩家点击瞬发——自然形成"军团干 bulk、我补零头" | 无文案 |
| 5 | 最后安全格打开 | 胜利 → 结算 | 三行：开格分 / 标旗分 / "你的操作 X 次 · 机器人的操作 Y 次" |

## 5. 边界情况与处理

| 情况 | 处理 |
|---|---|
| 标错旗 | 无奖励无惩罚（只少挣 5 钱），旗可撤；极端差几块钱 → 用 30s 长CD行动补齐（顺带二次教学"次数珍贵"） |
| 只开格从不标旗 | 第 8 次点击兜底触发耗尽 |
| 只买一台（如只买 opener） | 后段无新旗 → 规则 1 断粮 → 机器人停摆 + 空闲警告 → 玩家用 3s CD 自己标旗救场——恰好演练"救场"角色，仍可通关 |
| 拒绝购买硬等 | 每 30s 恢复 1 次，可以磨完（不死锁，守可交互原则）；等 15s 未购提示升级一次："机器人只要 {实时最低价}"（有赠机时为翻倍价 100） |
| 机器人抢先清完 | 正常通关；"玩家收尾"是典型情况不是硬保证 |
| 踩雷 | 格子坍塌 + 浪费一次操作，无其他惩罚（无命限制） |
| 中途放弃/重开 | 走标准暂停-放弃流程，无奖励，可重来 |

## 6. 教学文案（定稿）

1. 开局："左键开格，右键标旗。"
2. 耗尽："指挥次数用完了。"
3. 耗尽后高亮商店："雇一台常驻机器人——它不占你的次数。"
4. （等 15s 仍未购买）："机器人只要 {实时最低价}。"（默认 50；局外赠机抬价后为 100）
5. 首购完成："次数恢复：3 秒/次。"

文案原则：全关文字 ≤ 5 句，每句 ≤ 15 字；机器人行为不用文字解释，用动作和跳字自证。

## 7. 盘面验收标准（转交执行侧）

固定盘面需**同时**满足（不指定具体布局，由执行侧烘焙）：

1. 全程可用**现有的 2 条基础规则**推完：无歧义（不被迫猜）、不需要子集推理（机器人不停摆）
2. 开局（预开后、未放任何旗）即可直接推出的旗**恰好 5 面左右**，且每面由单个数字即可判定（秒推级）
3. 预开约 45-55% 格（含洪水连锁）
4. 放好 5 面旗后，存在规则 1 可开格（免费阶段有开格可做）
5. 机器人阶段至少出现一次 **≥6 格的连锁展开**（机器人高光）
6. 最后打开的格子距基地 ≥3 格（玩家收尾节拍）
7. 附注：验证工具原型在 `tmp/level1_board_finder.py`，可复用或升格为关卡烘焙工具；第 2-5 关同套标准换参数

## 8. 实现需求清单（转交执行侧）

1. 关卡数据支持固定布局（雷位 / 预开区 / 基地位置烘焙，不走随机生成）
2. 关卡参数化：无时限、CD 数值、免费次数、商店白名单与限购数、无命限制
3. CD 系统：全局单 CD、光标恢复环、耗尽/恢复事件（接入剧本控制器）
4. 玩家操作 = 一次性机器人：瞬发生效 + 0.5s 飞落视觉
5. 剧本控制器：耗尽触发、商店高亮、首购恢复 CD、15s 升级提示（扩展现有 tutorial_guide）
6. 结算页：开格分 / 标旗分分列 + 人机操作占比统计（兼作盲测埋点）
7. 修现有 bug 的依赖项：引导事件竞态（本关无计时，天然规避计时问题，但事件丢弃 bug 仍需修）

## 9. 待盲测校准项

- 起始资金微调（原则不变：耗尽时恰好够买两台）
- 免费次数（5 旗 / 8 次）与 30s 长CD 的痛感强度
- 耗尽提示文案是否足以让所有测试者完成首购
- 玩家是否在阶段 4 主动收尾（人机占比数据）
