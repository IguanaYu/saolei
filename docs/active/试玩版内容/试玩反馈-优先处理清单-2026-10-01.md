## P1：外测前先修

### P1-01 设置页底部裁切

- [x] 修复设置内容及返回按钮的布局。（✅ 2026-10-01 实施 A 批 `6b57e74`；2026-10-02 用户实机验收通过）
- **复现**：主菜单打开设置，分别使用 1024×768、1280×960；放大后底部仍显示不全。
- **处理方向**：内容自适应，内容过长时滚动；返回按钮留在可见区域并保留边距。
- **验收**：上述窗口尺寸和全屏均能读完说明、操作全部设置并点击返回，没有文字或按钮被裁切。
- **证据**：[02](试玩证据-2026-10-01/02-settings-bottom-clipped.png)、[03](试玩证据-2026-10-01/03-settings-large-still-clipped.png)。

### P1-02 局内升级面板宽高不足

- [x] 修复购买按钮超出右边界、动态条目超出底边界。（✅ 2026-10-01 A 批；2026-10-02 用户实机验收通过）
- **复现**：第二关打开局内升级，按钮超出右框；第三关增加到五行后，最后一行与关闭按钮超出底框。全屏也存在。
- **处理方向**：以容器和内容最小尺寸组织布局，约束长文本宽度；容纳动态条目，必要时使用滚动区域。
- **验收**：第二、三关所有升级项、价格、购买和关闭按钮都在面板内；满级、缺钱等文字状态变化不撑破布局；三种显示模式均可操作。
- **证据**：[14](试玩证据-2026-10-01/14-level2-upgrade-buttons-outside-panel.png)、[17](试玩证据-2026-10-01/17-upgrade-fullscreen-overflow.png)、[20](试玩证据-2026-10-01/20-level3-upgrade-carries-over-and-overflows.png)。

### P1-03 局内浮层跨关残留

- [x] 在结算、退出及新关开始时收起并重置局内浮层。（✅ 2026-10-01 A 批，含放置预览/光标/提示行；2026-10-02 用户实机验收通过）
- **复现**：第二关保持局内升级打开直到超时，再选第三关并开始，旧升级面板继续盖住关前卡和棋盘。
- **处理方向**：统一关卡退出/初始化的浮层清理；重点核对 `scripts/main.gd::_start_level_with()`。
- **验收**：保持升级面板打开后分别超时、重玩、返回菜单、选择另一关，下一页面及开局没有旧面板；重新打开升级显示当前关的数据。
- **证据**：[20](试玩证据-2026-10-01/20-level3-upgrade-carries-over-and-overflows.png)。

### P1-04 棋盘、商店和教学高亮重叠

### P1-05 商店文字变化挤出右侧卡片

- [x] 约束商店卡片宽度及状态文本。（✅ 2026-10-01 B 批，流式布局；2026-10-02 用户实机验收通过）
- **复现**：第一关购买开墙机器人，卡片状态文字改变，右侧矿工卡及锁定说明被挤出窗口。

- **证据**：[08](试玩证据-2026-10-01/08-shop-horizontal-overflow-after-purchase.png)、[26](试玩证据-2026-10-01/26-level4-enemies-and-expanding-shop.png)。

### P1-06 结算“下一关”跳回第一关

- [x] 修正下一关目标 ID 的计算与跳转。（✅ 2026-10-01 C 批 `fd2891c`，substr 缺陷实为所有关都跳回第 1 关；2026-10-02 用户实机验收通过）
- **复现**：第一关通关，结算点击“下一关”，出现第1关关前卡；菜单的“继续试玩”却指向第2关。
- **处理方向**：核对 `scripts/main.gd::_on_next_level()` 的 `substr(-1)`，优先使用明确的关卡顺序与 ID 映射。
- **验收**：第一至四关达标后的按钮分别进入第二至五关；菜单继续与结算跳转一致；第五关末关行为符合现有试玩完成流程，不出现不存在的第六关。
- **证据**：[09](试玩证据-2026-10-01/09-level1-success-results.png)、[10](试玩证据-2026-10-01/10-next-button-shows-level1-again.png)。

### P1-07 首玩关前卡按 ESC 出现空选关页

- [x] 初始化返回目标选关页，再显示它。（✅ 2026-10-01 C 批，统一选关入口；2026-10-02 用户实机验收通过）
- **复现**：新启动后从菜单直接开始，关前卡按 ESC，左侧没有关卡，右侧只有“01/尚无记录”；从菜单点击“选择关卡”才恢复。
- **处理方向**：统一关前卡返回与菜单选关入口；核对 `scripts/main.gd::_handle_escape()` 的章节设置及刷新。
- **验收**：首次启动和继续存档，两条入口进入关前卡后按 ESC，均回到完整、章节正确、成绩可读且可选择的关卡列表。
- **证据**：[11](试玩证据-2026-10-01/11-empty-level-select-after-escape.png)、[12](试玩证据-2026-10-01/12-level-select-normal.png)。
