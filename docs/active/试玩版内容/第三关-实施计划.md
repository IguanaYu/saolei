## 3. 工作包分解

### WP1 机器人节奏分离（全局引擎改造，手感不变约束）

**目标**：`robot.gd` 的统一 tick 拆为移动间隔与工作间隔两条轨；opener/marker 吃双轨，detector/miner 保持单间隔不变。

1. [game_state.gd:19-22](../../scripts/autoload/game_state.gd#L19-L22) 升级等级变量改为 4 轨：`opener_move_level / opener_work_level / marker_move_level / marker_work_level`（L2 若已按 `*_speed_level` 落地则机械改名扩展）；`detector/miner_speed_level` 保留。
2. 新增查询：
   - `get_move_interval(type)` / `get_work_interval(type)`，读当前关卡 LevelData 的 `upgrade_move_levels` / `upgrade_work_levels`（默认均 `[2.0, 1.6, 1.3, 1.0]`），`mini(level, size-1)` 钳制防局外越界；
   - **工作表为空 = 本关无工作轨 → 工作表取移动表**（L1/L2 手感不变的实现机制）；
   - `get_speed_interval(type)` 保留给 detector/miner。
3. [robot.gd:80-85](../../scripts/robot.gd#L80-L85) `accumulate_and_maybe_tick()`：按"下一 tick 将做什么"选间隔——已有目标且与目标相邻（切比雪夫距离 1）→ 工作间隔；否则移动间隔。每次 accumulate 重读（升级即时生效含在途，现模式保留）。
4. 子类 [detector_robot.gd](../../scripts/robots/detector_robot.gd) / [miner_robot.gd](../../scripts/robots/miner_robot.gd) 不动：基类里 detector/miner 分支继续走单间隔。

**验收**：默认值下 L1/L2 逐 tick 行为与改造前完全一致（双表同值）；L3 上升工作轨后，邻接连作节奏独立变快。

### WP4 目标型胜利 + 时间加分锁定 + 继续挑战（核心新系统）

**状态机**：`正常局 →（过线）→ 结算 →（可选）继续挑战 → 玩家自行离开`。

1. **过线路径**（[main.gd:556-560](../../scripts/main.gd#L556-L560) 扩展，通用化）：
   - `REACH_SCORE` 达标瞬间：`time_bonus = int(GameState.time_left) * lvl.time_bonus_per_sec`；`add_score(time_bonus)`；`result_stats["time_bonus"]`、`result_stats["crossing_elapsed"] = GameState.elapsed`；HUD toast `过线！+3X 分`；然后 `_end_game("win")`。
   - 结算照常走 win（发奖/解锁/埋点**只发生这一次**，`game_active` 门控已有）。时间加分计入结算分与最高分（承 L2 Q4）。
2. **继续挑战**（新字段 `GameState.continue_mode: bool`，`allow_continue` 关的结算面板多一个按钮）：
   - 按下 → 隐藏结算、`game_active=true`、`continue_mode=true` 回盘面；
   - [main.gd:317-332](../../scripts/main.gd#L317-L332) `_process`：`continue_mode` 下**跳过 time_left 递减**（冻结）；
   - [main.gd:530-536](../../scripts/main.gd#L530-L536) `_on_mine_stepped`：`continue_mode` 下**不扣命**（防"胜利后又失败"坏状态）；踩雷仍坍塌浪费动作；
   - [main.gd:556-560](../../scripts/main.gd#L556-L560)：`continue_mode` 下 score 变化**不再触发二次 win**；分数自然累加于结算分之上（HUD 可见）；
   - CD 照常计（乱插旗刷分自限依赖此，设计 §5）。
3. **继续中退出**：暂停菜单离开 → **不走放弃流程**（不二次发矿、不记 abandon），直接回选关；`record_game_result` 不重复调用，仅当最终累计分更高时刷新 `best_score`；埋点补 `continued=true / continue_gain`（见 WP10）。
4. 「下一关」按钮 = 现有返回选关行为，不动。

**验收**：过线即跳结算四行+时间加分；继续后倒计时数字定格、踩雷不扣心、分数继续涨；暂停离开无双重矿石；再进一局状态干净（`reset_state` 清 `continue_mode`）。
