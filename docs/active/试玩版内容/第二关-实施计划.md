## 3. 工作包分解

### WP1 升级系统参数化（§9.1/9.2，核心改动）

**目标**：升级轨的价格、档位数、速度值、可见性全部由 LevelData 注入；默认值 = 四档全局（Q3 已定：2.0/1.6/1.3/1.0 + 价 50/70/100，旧关同步换新档，属有意变更）。

1. [level_data.gd](../../scripts/data/level_data.gd) 新增字段（默认值即新全局默认）：
   - `upgrade_speed_prices: Array = [50, 70, 100]`（长度 = 可购档数，去掉 -1 哨兵）
   - `upgrade_speed_levels: Array = [2.0, 1.6, 1.3, 1.0]`（长度 = 档数+1，含 Lv0）
   - `upgrades_hidden: Array = []`（如 `["discount"]`）
2. [game_state.gd:326-333](../../scripts/autoload/game_state.gd#L326-L333) `get_speed_interval()`：改读当前关卡的 `upgrade_speed_levels`，`level` 用 `mini(level, levels.size()-1)` 钳制（防局外 global_speed 越界）；`reset_state()` 时缓存一份。
3. [upgrade_panel.gd](../../scripts/ui/upgrade_panel.gd)：
   - 删 `SPEED_PRICES/-1` 哨兵逻辑，价格与档位从 `GameState.get_current_level()` 读；
   - 满级判定 `lvl >= prices.size()`（替换硬编码 `lvl >= 2`，[upgrade_panel.gd:90](../../scripts/ui/upgrade_panel.gd#L90)）；
   - `_ready`/`_refresh_all` 按 `upgrades_hidden` 隐藏折扣行；
   - 行内文案沿用 `"Lv%d (%.1fs)"` 格式，四档自动兼容。
4. 折扣轨价格不动（L2 隐藏、L3+ 再说）。

**验收**：全局默认即三档 50/70/100、速度 2.0→1.6→1.3→1.0（旧关同此新默认，Q3）；L2 折扣行不可见；购买后**在途**机器人下个 tick 即变快。

### WP2 时限到点语义改造（§9.5 前半，影响面最大）

**目标**：到点与命尽 = "**强行停止并结算**"——与胜利同一套正常结算流程，不是失败态（Q2 已定）；不算过关、不解锁、可重玩。

1. [results_panel.gd:114-120](../../scripts/ui/results_panel.gd#L114-L120) `timeout` 与 `lose`（命尽）两个分支统一改造：
   - 标题统一"**本次挖掘结束**"（不出现"失败/时间到"字样；lose 保留"剩余生命 0"行作上下文）；
   - 增加矿石结算行（口径见 §7-Q1 待定，暂按"积分折算 score/10"实现，做成常量便于改）；
   - 展示 `_add_playtest_rows()` 统计三行（无时间加分行）——盲测看重玩局数据（Q2 已定显示）；
   - 不调用 `mark_cleared`/`claim_first_clear`（现状已如此，保持）；重玩按钮已有（`restart_requested`），保持。
2. [save_system.gd:221-234](../../scripts/autoload/save_system.gd#L221-L234) `record_game_result()`：`timeout`/`lose` 均不再清零 `cur_streak`（对齐"不是失败"；连胜实际变为累计通关数，试玩期无实际影响，正式版再议）。

**影响面**：全局——正式关 1-2~12-5、每日挑战的到点行为同时改变。这正是 v0.1 第 4 步要求的方向，但**回归清单必须覆盖旧关**（§6）。

### WP3 时间加分（§9.5 后半）

2. **旧关（1-2 及以后）**：到点/命尽新语义（"本次挖掘结束"、结算给矿、不断连胜、不解锁）；升级面板换全局四档新默认（价 50/70/100、速度四档，有意变更非回归）。
3. **每日挑战**：timeout 路径、结算行、连胜口径。
4. **通用**：14×14 盘面 UI 布局（L1 已验证 10×10，确认 CaveEnv 边框重排）；暂停期间 CD/倒计时停摆；放弃流程。
5. **边界**（设计 §5）：升级时在途机器人即时变快；5 次免费未用完就买机器人并行不冲突；拒买硬点 CD 90s 内约 30 次操作远不够清 172 格 → 到点重玩不判负。

## 7. 决策记录（2026-09-27 拍板）与遗留问题

- **Q2 到点/命尽结算形态（已定）**：与胜利同一套正常结算——"**强行停止并结算**"，不是失败态；统计三行照常显示；不算过关、不解锁、可重玩。连胜不清零（连胜实际=累计通关数，正式版再议）。
- **Q3 速度档位（已定）**：四档 2.0/1.6/1.3/1.0 + 价格 50/70/100 设为**全局默认**，旧关同步换新档（有意变更）。
- **Q4 时间加分（已定）**：计入总分与最高分统计（结算显示同一个分数）。
- **Q5 检测/矿工（已定）**：商店**隐藏**（对齐"试玩版不做采矿"既定决策，`shop_hidden` 含 detector/miner）。
- **Q1 到点/命尽的矿石口径（待定）**：暂按"积分折算 score/10"（与自由模式一致）实现，做成常量；等讨论结果出来改一处即可。备选：固定 30 矿 / 0 矿仅统计。
