## 1. 定位一句话

第一次带着"局外变强"的成果回来：花掉攒的矿石，在中级大盘上体验"不用扫完也能赢"——够分就走，想留就留。

## 2. 教学目标

玩家离开本关时应理解的事（按出场顺序）：

1. **积分目标**：过关 = 积分达标，不必清全图；冲线越早，剩余秒 ×3 越高
2. **局外成长**：矿石能永久变强（第一次间场购买，进场即见效果）
3. **吞吐量三杠杆**：走路快（移动升级）、干活快（工作升级，本关首登场）、基地近（第二基地）——大盘走路成本上升，三者都真正划算
4. 胜利后可**继续挑战**：倒计时冻结，分数继续涨

## 4. 间场与全流程剧本

### 4.1 间场（L2 结算后 → L3 进关前，关卡列表页）

- 关卡列表页顶部：矿石余额 + 「变强」商店入口高亮；L3 格子带"新"标
- 商店试用阵容与价格：

| 轨道 | 成本 | 效果 |
|---|---|---|
| 起始金币 | 50 / 100 | 每级 +50 起始资金 |
| 起始生命 | 80 / 160 | 每级 +1 命 |
| 移动速度 | 100 / 200 | 开局直接送同级移动档（1 级=1.6s/格，2 级=1.3s/格）；原「全局速度」更名 |
| 工作速度 | 100 / 200 | 开局直接送同级工作档（开格/标记连作间隔 1.6s / 1.3s） |
| 开局送机器人 | 100 / 200 | Lv1 送 opener，Lv2 再送 marker |
| 安全区扩大 | — | **隐藏**（固定预开地图下无用） |

- 预算：首通 L1+L2 共 **400** 矿石，对商店总价 **1290**——买不齐，必须取舍；想买齐 → 重玩刷矿石，正是循环设计
- 盲测埋点：记录购买组合与顺序（L3 起玩家数值分化，分析时按方案分组）

### 4.2 局内剧本

| # | 触发 | 发生什么 | UI / 文案 |
|---|---|---|---|
| 0 | 进关 | 大盘首见；目标进度条（当前分 / 300，**开局即 30-38%——预开格自带分**）；局外效果即刻可见（送的机器人在场 / 速度已是高档） | "积分 300，不用扫完。" |
| 1 | 开局 | 5 次免 CD + 起始 300（或局外白得的机器人），节奏同 L2 | 无 |

## 5. 边界情况与处理

| 情况 | 处理 |
|---|---|
| 到点未过线 | 强行停止并结算（保留收益、非失败态），不算过关、可重玩 |
| 命尽 | 同上 |
| 过线后继续中踩雷 | 不扣命；格子坍塌浪费动作 |
| 标错旗 | 无奖励无惩罚；旗可撤；同一格正确奖励仅首次发放、撤旗不退分（防刷） |
| 乱插旗刷分 | 每次插旗吃 3s CD，40 雷盘全插的净收益极差——CD 自限 |
| 继续玩后退出 | 暂停菜单离开，分数 = 当前累计 |
| 不买局外直接进 L3 | 数值同 L2 冷启动 + 更大的盘：120s 内仍应可过线（验收 §8.4） |

## 6. 教学文案（定稿）

1. 间场："矿石能变强。"
2. 进关："积分 300，不用扫完。"
3. 过线："过线！"

文案原则：全关 ≤ 3 句；局外效果不用文字解释，进场即见。

## 7. 盘面验收标准（转交执行侧）

固定盘面需**同时**满足（工具原型 `tmp/level1_board_finder.py` 换参数复用）：

1. **核心区**（预开 + 可推区域）2 规则可解，且在该覆盖量内即可达成门槛（对应扫约 70-85% 的雷 + 相应开格）；**门槛含预开起始分**（初始分 = 预开格数 P，模拟器同口径）
2. **角部允许歧义**（可猜可不猜，弃扫不影响过线）——与 L1/L2"全程可解"不同，本关故意放宽：扫进角部遇到猜点是"目标变了，别恋战"的教训
3. 密度 40 / 256 = 15.6%
4. 预开约 35-45% 格（含洪水连锁）
5. 至少一次 ≥6 格连锁展开

## 8. 经济与节奏验收（转交执行侧）

1. 起始 300 + 局外加成；过线前终身预算约 600
2. **门槛校准**：模拟"4 种局外方案 × 2 条局内策略"均能在 120s 内过线，且过线时清扫量落在"扫 70-85% 雷"区间
3. 同价抉择带保持：Lv3（100）= 第 2 台机器人（100）≈ 基地（80）
4. 不买局外也可过线（盲测必有人跳过商店）
5. 时间加分拉动力：早过线 30s = +90 分——显著，但不超过行动分主体
6. **双维度体感**：纯移动升级与纯工作升级各自在同类任务上带来 ≥15% 时间差（往返路途 vs 连续作业区），肉眼可辨
7. 升级总盘子：4 轨全满 880 > 终身预算约 600——必须取舍；"走路慢还是干活慢"可由玩家观察诊断

## 9. 实现需求清单（转交执行侧）

1. **目标型胜利系统（通用）**：过线检测 → 跳结算 → 「继续挑战」（倒计时冻结 / 加分锁定 / 继续中免命 / 分数累加于结算分）；L4 开格% 目标直接复用
2. 积分目标 HUD：当前分 / 目标分进度条
3. 关卡列表页矿石商店：`start_robot` 扶正进店（Lv1 送 opener / Lv2 加 marker）、`expand_zone` 隐藏、购买组合埋点；**新增「工作速度」矿石轨**（100/200，开局送同级工作档）；「全局速度」更名「移动速度」
4. **机器人节奏分离（全局）**：现行 `robot.gd` 统一 tick（每 tick 走一步或做一动作）拆为独立的移动间隔与工作间隔，基值均 2.0s——L1/L2 无工作轨时手感不变；邻接目标时按工作间隔连续作业
5. **局内升级扩为 4 轨**：opener/marker × 移动/工作，各 50/70/100（`upgrade_panel.gd` 参数化）
6. 重玩通关矿石 50；到点/命尽矿石口径对齐执行侧 Q1
7. 标错旗无惩罚（全局计分点改造）+ 同格奖励防重复发放
8. 折扣轨从试玩商店移除（`upgrade_panel.gd` 隐藏）
9. 到点/命尽 = 强行停止并结算语义沿用（L2 v1.1 已定）
10. 盲测埋点：局外购买组合、过线时间、是否继续、继续得分
11. **预开格算分（只计分不计钱）**：LevelData 新开关 `preopen_scores`（默认 false，L3=true），预开装载时一次性 `add_score(预开数)`——L1/L2/正式关口径不变，进度条与 REACH_SCORE 判定自动带上起始分（300 > 115 上限，不会开局误判过线）

## 10. 待盲测校准项

- 积分门槛 300 与"扫 70-85% 雷"的实际对齐度
- 120s 时限宽紧（大盘冷启动）
- 重玩矿石 50 的刷取节奏
- 玩家是否理解"不用扫完"（目标型玩法首见）
- 间场购买率与方案分布
- 「继续挑战」使用率与继续时长（"想接着扫"是核心假设的直接信号）
- 工作速度档位值与移动轨的相对价值是否平衡（一边倒则调价或调值）
- 预开自带分的理解度（开局进度 30-38% 是否被读作"白送进度"而非"目标变低了"）
