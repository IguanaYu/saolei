# 艺术指导 · 全元素贴图规格 v1

> **用途**：游戏内每一种画面元素的逐项规格与限制条件。AI 生成 prompt、手工修图、Godot 接入都以此为唯一依据。
> **创建日期**：2026-08-14
> **上位标准**：[视觉风格标准-v1.md](视觉风格标准-v1.md)（亮度五层 L0-L5 / 16色板 / 八设计轴）。本文档不重复标准，只引用层级代号并给每元素的具体限制。
> **元素清单来源**：`scripts/cell.gd`（岩石/地砖/数字/旗/坍塌/基地/矿脉）+ `scenes/ui/*`（7 个 UI 场景）+ 4 种机器人

---

## 〇、总规格（所有元素共同约束）

| 项 | 规定 |
|---|---|
| 基准格 | 16×16 px（Godot 内整数倍缩放，禁止非整数） |
| 风格 | 暖色像素矿洞风，只取 [视觉风格标准 §二] 16 色板及中间调 |
| 描边 | 需要从背景中跳出的元素：1px `#1a1410` 全轮廓 |
| 纹理 filter | nearest（全项目统一） |
| 变体 | 大面积元素 ≥4 变体；变体间明度差 ≤5% |
| 命名 | `assets/<类别>/<名称>_<变体或帧>.png`，禁止 get_children() 遍历匹配 |
| 接入 | TextureRect+AtlasTexture 必须 expand_mode=1（AGENTS.md 守则） |
| 验收 | 每批素材过 [视觉风格标准 §五] 验收清单 + PIL 亮度实测 |

**层级速查**：L5 数字/旗/矿脉光/特效 → L4 机器人 → L3 UI前景 → L2 地砖(基准100%) → L1 岩石(70-85%) → L0 画外底(50-70%)

## 一、棋盘格子类（Cell）

### 1.1 未开岩石 ★下一任务
| 项 | 限制 |
|---|---|
| 层级/亮度 | L1，地砖的 70-85%（PIL 实测） |
| 色板 | 岩石暗`#4a3826`/主`#6b5138`/亮`#8a6a4a`，受光面占比 <20% |
| 饱和度 | ≤ 地砖的 70% |
| 纹理 | 粗颗粒裂纹（低频），纹理内部明度对比 ≤12%；**禁止**高频噪点、禁止可识别图形（化石/图案=伪线索） |
| 变体 | ≥4，条带 sheet 横排（沿用 floor_bricks_sheet 格式），变体间明度差 ≤5% |
| 生成法 | AI 抠块拼接法（同地砖流程）；prompt 必带 `pixel art, dark warm brown rock, muted, coarse cracks, 16px tile, no readable shapes` + 三色号 |
| 接入 | `cell.gd` 未开分支替换 `Color(0.25,0.18,0.12)` 色块，随机铺变体 |

### 1.2 已开地砖 ✅已定稿
`assets/tiles/floor_bricks_sheet.png`，L2 基准。后续新素材一律以它的实测亮度为 100% 校准。

### 1.3 数字 1-8
| 项 | 限制 |
|---|---|
| 配色 | 经典扫雷语义色不变（`cell.gd` 现值：1蓝2绿3红4紫5棕6青7黑8灰） |
| 层级 | L5（130-160%） |
| 可读性 | 1-2px 深描边或粉白`#f5ead6`光晕底；在 4 个地砖变体上对比度 ≥4.5:1（逐变体实测） |
| 字形 | 统一字体字号，只有颜色差异；禁止装饰性字形 |
| 注意 | 数字红与旗红并存：靠位置+形状（数字居中/旗带杆）区分，不靠色差 |

### 1.4 旗（玩家标记）
L5；旗红`#e74c3c` + 深杆，1px 描边；16×16 内完成，剪影=三角旗+杆，与数字剪影明显不同。

### 1.5 矿脉
| 项 | 限制 |
|---|---|
| 层级 | L5 但**靠运动/微光而非面积**：矿金`#f0c04a` 裂纹状发光，占格面积 ≤40% |
| 动画 | 微光呼吸 2 帧（低频 ≤1Hz，符合运动分级）；采空后暗掉回 L2 |
| 语义 | 金色=收益，禁止其他元素大面积用金 |

### 1.6 坍塌（踩雷格）
警红`#c0392b` + 深洞底`#1a1410`，L1-L5 混合（危险该最抢眼）：事件瞬间高幅动画（碎裂 3-4 帧，≤0.6s），之后**常驻静态暗红塌陷纹理**，不持续闪烁。

### 1.7 基地
| 项 | 限制 |
|---|---|
| 尺寸 | 2×2 格（64×64），棋盘上唯一大型建筑=构图锚点 |
| 层级 | L2-L3；主体用地砖主/岩石主色，**屋顶或旗帜一点铜橙`#d98a3d`**标识，不整栋高亮 |
| 动画 | 放置时落下尘土粒子（事件级），之后常驻低幅（1 面旗摆动 ≤0.5Hz） |

### 1.8 充能塔（功能债，美术先占位）
1×1 格；铜橙为主体点缀色；激活时矿金光环脉冲（事件级），未激活时灰暗（L1）与激活态（L4）差一整层。

## 二、机器人（Robot）★S1.3

全类共同约束：L4（115-135%）；1px `#1a1410` 全轮廓；主体饱和度高于岩石低于特效；**颜色+剪影双编码**（灰度+剪影双测试通过）；AI 只出待机 2 帧，移动 2 帧用 Python 合成。

| 机器人 | 识别色（色板派生） | 剪影符号（必须唯一） | 发光件 |
|---|---|---|---|
| opener 开凿 | 铜橙`#d98a3d` | 正面三角钻头 | 钻头尖 1px 矿金 |
| marker 标旗 | 旗红`#e74c3c`（与旗同源，语义联动） | 背上小旗杆 | 无 |
| detector 探测 | 数字蓝`#3d7dd8` | 顶部天线+圆盘 | 天线顶 1px 粉白，探测时脉冲 |
| miner 运矿 | 岩石亮`#8a6a4a`+矿金斗 | 前伸矿斗 | 载货时斗内矿金点 |

补充限制：
- 尺寸 16×16（矿斗/钻头允许超出到 20×20 内，但不许遮住相邻数字中心区）
- 状态气泡（UX.4）：粉白底+深字，≤半格，出现 ≤1.5s
- 4 色在色相环间隔不足 90°（橙/红接近）→ **形状编码必须强**：剪影测试是硬验收项

## 三、UI（7 个场景）

### 3.1 主题总则
| 项 | 限制 |
|---|---|
| 底板 | L0-L1 深色（深洞底/岩石暗），暗底托亮字 |
| 边框 | 双线：外岩石主`#6b5138` 内铜橙`#d98a3d`，宽 2px+1px |
| 文字 | 粉白`#f5ead6`；正文 L3，关键数字 L5 |
| 按钮 | 常规=岩石亮底+粉白字；主行动=铜橙底+深字；**警红只给危险确认** |
| 禁止 | 大面积警红/矿金；高饱和大色块；玻璃拟态/渐变（破坏像素风） |
| 字体 | 像素字体（S1.5 定），数字加 1px 描边 |

### 3.2 各场景要点
| 场景 | 特有限制 |
|---|---|
| HUD | 核心数字（钱/命/能量）左上视线起点，L5+跳动动画；图标用色与对应实体同源（钱=矿金、命=旗红仅图标级） |
| Shop | 商品缩略图直接复用格子/机器人素材（同源不重画）；买不起=压暗 60%+锁图标，禁止变灰到不可辨 |
| UpgradePanel | 升级前后对比用数字+小箭头，不靠颜色变化表达等级 |
| MainMenu | 标题字 L5 矿金描边；背景允许用岩石纹理平铺 + 一台大号 miner 剪影（唯一允许的装饰性大元素） |
| ChapterSelect/LevelSelect | 缩略图复用棋盘截图而非重画；当前项=铜橙框脉冲，锁定项=灰暗+锁图标 |
| ResultsPanel | 结算数字逐行跳出（事件级运动，每行间隔 ≤0.15s），收益汇总用矿金 |

## 四、特效/反馈（S2）

| 特效 | 层级 | 时间预算 | 色板 | 限制 |
|---|---|---|---|---|
| 开格尘土粒子 | L4 | ≤0.4s | 岩石亮 | 粒子 ≤6 个/格，禁止全屏 |
| +1 跳字 | L5 | ≤0.6s | 粉白/矿金 | 数字素材复用 HUD 字体 |
| 矿脉采空碎裂 | L5 | ≤0.6s | 矿金 | 3-4 帧 |
| 坍塌爆裂 | L5 | ≤0.6s | 警红 | 屏震幅度 ≤4px、≤0.3s |
| 矿脉微光 | L4 | 常驻 | 矿金 | ≤1Hz 呼吸 |
| 机器人移动 | L2-L4 | 常驻 | — | 2 帧摆动，无位移残影 |

总原则：**同一时刻屏幕上 L5 事件特效 ≤2 处**；超过就排队或降级，防止注意力打架。

## 五、屏幕整体

| 项 | 限制 |
|---|---|
| 画外底（棋盘外） | L0 `#1a1410`，可加 ≤5% 的岩石暗纹理，无可识别图形 |
| 棋盘边框 | 岩石主色粗框，把视线"框进"棋盘 |
| 缩放 | 整数倍；窗口最小尺寸下 16px 格 ≥24 物理像素显示 |
| 扫描动线 | 棋盘内零跨格常驻元素（基地 2×2 除外）；跨格只允许瞬时特效 |

## 六、生产顺序与校准链

每批新素材**必须与上一批定稿素材并排实测亮度**，链条锚点顺序：

```
地砖(已锚定100%) → 岩石(70-85%) → 数字/旗(对比度实测) → 机器人(剪影测试)
→ 特效 → UI 主题 → 基地/充能塔 → 菜单装饰
```

> 校准链的意义：所有层级都是相对地砖的比值，先做大面积元素定基调，小元素对着校准，避免"每批都挺好的、放一起打架"。
