# 扫雷挖矿（saolei）

扫雷 × 自动化经营的混合玩法游戏：玩家用扫雷推理推进关卡，投资机器人代替自己挖矿。Godot 4.6.1 制作，PC（Steam/TapTap）方向。

## 快速运行

```bash
"E:\chormeddownload7\Godot_v4.6.1\Godot_v4.6.1-stable_win64_console.exe" --path "F:\godot_game\扫雷_增量\saolei"
```

（备选 exe：`E:\godot\Godot_v4.6.1-stable_win64_console.exe`；新增图片素材后先跑一次 `--headless --import`）
